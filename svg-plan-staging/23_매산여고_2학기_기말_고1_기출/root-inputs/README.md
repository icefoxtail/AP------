# 23 매산여고 고1 2학기 기말: 엔진 입력 1차 정리

23문항 중 18문항의 item·plan·publish 초안을 새로 작성했다. Q6·Q9·Q16·Q22는 기존 drafts의 입력 및 실패·OPEN 이력을 보존하고 중복 작성하지 않았다. Q9는 45개 격자점 전체를 나타내는 기능이 확인되지 않은 OPEN이며 기존 초안은 부분적이다. Q8은 PR #855 본문상 렌더·검수 기록이 있으나 실제 자산의 위치가 확인되지 않아 OPEN으로 유지한다.

새 초안은 JSON 문법만 확인했다. 엔진 계약 검사, 렌더, 독립 수학·학생 화면 검수 및 브랜치 반영은 하지 않았다. Q7의 k=3, Q19의 a=−1은 예시이며 Q18은 두 조각과 y=±3의 교점을 포함하는 계획이다. Q3·Q10·Q17·Q23의 보조도는 원본 그림이나 전체 경우 분류를 대체하지 않는다. 각 STATUS와 기존 시도 이력을 따른다.

이 README의 초안 수(18)는 ROOT 입력 메시지에 명시된 기록이다. 현재 작업 브랜치에는 완전한 item·plan·publish 세트를 15문항분만 복원했다. Q7 publish 조각만 별도 보존했고, Q7 item/plan과 Q10·Q18의 정확한 JSON 원문은 전달된 대화 텍스트가 잘린 구간에 있어 이 작업본에서 재구성하지 않았다. 이 수량 차이는 원래 메시지에 초안이 없었다는 뜻이 아니라, 이전 1차 추출에서 완전한 JSON이 보이는 세트만 복사했기 때문이다.
