# 공식 엔진 입력 사본

원본 1차 초안은 `../root-inputs/`에 보존하고, 엔진에 전달한 사본만 이 폴더에 둔다. 새 사본은 Q1–4, Q6, Q8–11, Q14, Q16–17, Q19–20, Q22, 총 15문항이다. Q7은 현재 운영 그림이 있고, Q5·12·13·15·18·21은 요청에 따라 기존 Claude 담당·결과를 보존했다.

Q3 사본은 문제의 `x≥1` 정의역을 명시한다. Q16은 1번과 3번 자리에 서로 다른 댄스 팀이 배정됨을 별도 대상으로 그린다. Q19는 원문의 변수 `t`를 `axisVariable`에 기록한다. 그 외 초안과 달라진 엔진 계약 보정은 없다.

엔진별 plan/model 검사를 Q1–4, Q6, Q8–11, Q14, Q16–17, Q19–20, Q22 전부 통과했다(15/15). 세부 결과는 `../evidence/plan-contract-validation.json`에 있다. 실제 SVG 조판·렌더는 글꼴 의존성 때문에 Q1에서만 두 번 시도했고, Q1 외 항목은 같은 환경 실패를 반복하지 않도록 렌더하지 않았다. 어떤 plan도 승인된 SVG/PNG로 간주하지 않는다.
