# 2022 금당고 고1 2학기 기말 — ROOT 계획 및 엔진 입력 검토

## 기준과 범위

- 최신 기준은 origin/main 5279940ce8f880fe6acfb8e227f2556781c6cbb9이다. 별도 브랜치는 이 커밋에서 만들었다.
- ROOT가 적어 준 기준 커밋 15a6dd95fd12aaf847e8b739c2b806627f770782는 현재 origin/main보다 오래됐지만, 원문 JS blob은 지정 SHA e078f4fc60ff33dd0dcee0464abc99c05277e120과 같다.
- 대상은 21문항이다. 기존 출고 그림·원본 문제 그림을 확인해 중복 후보와 원문 이슈를 분리했다.
- 이 디렉터리의 qNN 폴더는 item.json, plan.json, publish.json이 모두 있는 입력 초안만 담는다. 렌더 전이므로 전부 NOT_RENDERED다. 공식 parser, 공식 render, 브라우저·글꼴 준비, 독립 렌더 검수는 NOT_RUN이다.
- publish caption 끝에 객관식은 “정답은 ④이다.” 형식, 서술형은 “구하는 값은 …이다.” 형식으로 정답을 둔다. 정답이나 보기 번호를 그림 안에 넣지 않는다. size는 렌더 담당이 정하므로 입력에서 생략했다.

## 문항별 그림 의도와 근거

- Q01 — y=2/(x−2)−1의 중심 (2,−1), 수직·수평 점근선. 최신 main의 기존 SVG가 그래프와 P, p=2, q=−1을 이미 담고 있고 제안 입력과 같아 KEEP.
- Q02 — 실제 시작점 (−2,1), 점 (−1,2), 정의역을 읽는다. 그림은 정답 매개변수 a=2를 직접 쓰지 않도록 a=1 예시 y=√(x+1)+1과 (0,2)를 사용하고 차이를 caption에 밝힌다.
- Q03 — 일의 자리 2 또는 4를 정한 다음, 같은 카드를 제외한 세 십의 자리 후보를 연결한다. 다중 화살표는 함수가 아닌 선택 대응이다.
- Q04 — 첫 선수를 1번으로 고정했을 때 둘째 후보 2~6을 연결한다. 전체 4단계 순열 6×5×4×3을 열거한 그림은 아니다.
- Q05 — 실제 조합 항의 관계를 작은 예시 C(3,1)+C(3,2)=C(4,2) 구조로 설명한다. 실제 문제의 수치 C(9,4)+C(9,5)=C(10,5), C(8,5)−C(7,4)=C(7,5)는 그림에 옮기지 않는다.
- Q06 — f(x)=(3x−1)/(x−2), 역함수 (2x−1)/(x−3), y=x를 한 축척에 놓고 P=(3,8), Q=(8,3)을 비교한다. 기존 그림은 없으며 눈금·점 이름 겹침은 렌더에서 확인한다.
- Q07 — 1/((k+2)(k+3))의 인접 분수 차를 수직선 위 네 분수 1/6,1/5,1/4,1/3으로 예시한다. 이는 18개 항 전체를 그린 그림이 아니다.
- Q08 — f(x)=√(x−1)+1, 역함수, y=x와 (1,1),(2,2)를 나타낸다. 기존 main SVG가 같은 결정적 관계와 개별 중간값 d=√2, m=1을 이미 보여 최종 합을 노출하지 않고 있으므로 KEEP.
- Q09 — 기존 그림은 보존한다. 원문은 x≠−a인 모든 실수 x에서 합성식이 정의된다고 적었지만, 해설값 a=−2를 대입하면 제외돼야 할 x는 0이고 원문 조건 x≠2와 일치하지 않는다. x=0에서 두 함수 입력 모두 2라 정의되지 않으므로 CONTENT 의심 OPEN. 수정 가정이나 새 그림을 만들지 않는다.
- Q10 — 다섯 공에서 세 상자를 선택한 뒤 세 상자를 모두 채우는 대응 한 가지를 보인다. 3⁵, 3·2⁵, 3·1⁵를 그림에 쓰지 않는다.
- Q11 — n=3인 대표 배열 하나에서 양끝 여학생과 연속한 남학생 다섯 명을 함께 보여 준다. 현재 입력은 두 경우의 전체 배열 수 비교가 아니라 한 사례이므로 그 범위를 caption과 STATUS에 명시한다.
- Q12 — 초콜릿 1개일 때 종류 패턴 CCHCC 한 가지를 보여 준다. 2개 패턴의 6개 중 HCCCH 제외와 서로 다른 사탕의 배열은 해설에서 다룬다.
- Q13 — 집합 A의 세 부분 x<0, 0≤x<1, x>1을 나누고 x=1에서 y=−1,1을 모두 제외한다. 비경계 예시 m=−1/2 직선만 겹쳐 정답의 전체 기울기 범위를 그림에 넣지 않는다. 기존 SVG가 최종 허용 범위를 직접 보여 주어 답 노출을 피하는 교체 후보로 분류했다.
- Q14 — 원본 q14.png의 연 경계를 확인했다. 여섯 영역의 공유 변만 인접으로 세고, 한 점에서만 닿는 아래 좌우 영역은 인접으로 세지 않는다. 기존 문제 그림을 대체하지 않는 관계도다.
- Q15 — t=x−2∈[1,2]에서 양끝 (1,4),(2,1/2)을 표시한다. AUTHOR_GUIDE의 rational-spike 계열은 일차/일차 유리함수이므로 4/t³ 전체 곡선을 그린다고 입력하지 않았다. 끝점 대응은 감소 증명을 대신하지 않는다.
- Q16 — 원본 q16.png를 직접 확인했다. 빈 좌석 2,4,5,6,7,8,11 가운데 남학생 인접쌍 (4,5),(5,6),(7,8)만 추린 보조 관계도다. 원본 좌석 배치와 여학생 선택 전체는 대체하지 않는다.
- Q17 — 원함수 2x/(x−1), g(x)=√(x−2t)−t에서 t=−1인 예시를 사용한다. 이때 무리함수는 √(x+2)+1이고 두 교점은 시작점과 다르다. 기존 SVG에 답 구간 −3/2≤t≤0 및 t=0 그림이 있어 답 노출과 시작점 혼동을 피할 교체 후보.
- Q18 — f(x)=(x²+n)/6의 n=8 예시와 역함수, y=x, (2,2),(4,4)를 나타낸다. 일반식의 교점은 x=y에서 x²−6x+n=0을 만족한다. 기존 그림은 정답 n=9를 직접 표시해 교체 후보.
- Q19 — 13개 중 평행한 직선 세 개와 이를 가로지르는 다른 직선 하나를 예시로 그린다. 평행한 두 개와 나머지 한 개를 고르는 경우 및 세 평행선을 모두 고르는 경우를 설명하지만 최종 삼각형 수는 그림에 쓰지 않는다.
- Q20 — U={1,…,10}의 예에서 공통 원소 5, A−B의 1, B−A의 9와 양쪽 밖 원소를 Venn diagram에 둔다. 대칭차 크기 2 또는 3을 분리해 보려는 개념도다. 기존 main SVG의 경우표는 32,40,72를 표시하므로 새 후보의 목적은 집합 분할 설명이며 전체 수 세기는 본문 해설에 남긴다.
- Q21 — 원문 f(x)=(2x+1)/(2x−1)을 X=x−1/2, Y=y−1로 옮기면 XY=1이다. k=3에서 중심은 (1/2+3√2/2, 1±3√2/2), 반지름 제곱은 5/2와 13/2이다. 접점은 엔진의 curve-circle 교점 연산으로 표시한다. 독립 계산한 원래 좌표는 첫 원에서 (1/2+√2, 1+1/√2), (1/2+1/√2, 1+√2); 둘째 원에서 ((2+3√2+√34)/4, (4+√34−3√2)/4), ((2+3√2−√34)/4, (4−3√2−√34)/4)이다. 그 점 좌표를 소수로 근사하지 않는다.

## 엔진 계약에서 반영한 수정

- set-diagram mapping에서 한 원소에서 여러 화살표가 나가는 Q03/Q04는 함수가 아닌 선택 대응이라고 caption에 밝힌다.
- Q14 인접 관계는 방향 없는 쌍을 화살표로 한 번씩 표기한다고 알리고, 화살표 방향을 관계의 방향으로 해석하지 않게 한다. Q16도 같은 이유로 쌍 표기임을 caption에 밝힌다.
- multi-curve 입력은 정확한 계수와 명시된 창을 유지한다. Q13의 열린·닫힌 경계와 자동 점근선, Q06·Q08의 역함수·대칭축 라벨, Q21의 동일 축척·원·접점 표시는 렌더 후 독립 검토가 필요하다.
- 최종 답은 그림에 쓰지 않고 publish caption의 끝에만 둔다. 실제 렌더가 없으므로 레이아웃, parser 수용, primitive·수학 대조는 완료로 표시하지 않는다.
