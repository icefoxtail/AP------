## 수정 기록

- Q3는 수학적으로 맞는 다른 예를 전달된 전체 계획의 f(1)=−3로 맞췄다.
- Q5는 계획에 명시된 10대, 선택 8대, 미선택 2대를 모두 표시하도록 대응도를 보완했다.
- Q18 sourceConditions의 `m&gt;0`을 `m>0`으로 바로잡았다.
- Q21 예시의 축약 메뉴명을 시험지 원문의 정확한 메뉴명으로 바꿨다. 선택 예시는 A={치즈버거, 콜라, 햄버거}, B={햄버거, 사이다, 감자튀김}으로 각자 메인 메뉴를 포함하고 공통 메뉴가 한 개다.
- Q22 x좌표 1,1 예시는 최소 넓이 등호 사례가 아니므로 a=2,b=3으로 바꿨다. 넓이는 1/2·|2(−15)−3(10)|=30으로 최소에 도달하고, 구하는 값 900은 caption 끝에만 둔다.
- publish.json에는 엔진 전달 형식의 size를 추가했다. 크기 설정은 렌더 전 계획값이며 화면 검수 결과가 아니다.

## 기존 이력과 책임 경계

최신 main과 원본 JS 이력을 확인했다. 원본 JS blob은 사용자가 준 식별자와 일치한다. main에는 기존 Q4·Q8·Q22 solutionImage 참조가 있고 Q15·Q18·Q20에는 원본 문제 이미지 참조가 있다. 이 staging은 원본 JS, 이미지, 운영 자산을 수정하지 않는다. 원본 Q15·Q18·Q20 그림을 ROOT가 직접 확인했다는 사용자 제공 기록은 출처를 분리해 보존한다. 이 환경에서는 그 그림을 다시 열지 않았다.

11월 7일 SVG handoff 브랜치의 최신 변경은 강남여고 Q03, h1-2final 작업 브랜치는 2023 금당고 시험지로 확인했다. 해당 변경 경로와 이 2021 시험지 작업은 겹치지 않는다. 실제 렌더와 독립 검수는 사용자가 지정한 Claude 담당으로 남긴다.
