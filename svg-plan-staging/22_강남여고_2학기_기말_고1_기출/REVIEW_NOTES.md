# 입력 초안 사전 대조 메모

이 메모는 주어진 초안의 정적 검토이며 엔진 계약 PASS나 그림 검수 PASS가 아니다. Q1 공식 렌더 시도는 Chromium 실행파일 부재로 측정 단계에서 멈췄다.

## 확인된 범위

- 전체 원문은 24문항이며 현재 원문 blob은 제공 계획의 blob과 일치한다. 정답 필드는 원문에서 읽었다.
- Q11 기존 직접 검수 PASS, Q15 timeout, Q22 OPEN 등 사용자가 전달한 상태를 보존한다. Q5/Q15/Q18/Q22의 기존 연결 SVG는 변경하지 않았다.
- 제공된 20개의 입력 JSON은 모두 JSON 문법을 통과했다. 공식 엔진의 전체 plan 계약 검증은 브라우저 시작 전에 막혀 `NOT_RUN`이다.
- 정답 및 보기 번호는 초안 publish caption 끝에만 들어가도록 작성돼 있다. 실제 SVG 내 정답 노출 여부는 렌더 결과가 없으므로 판단하지 않았다.

## Claude 독립 검수 전에 재검토할 입력 지점

- Q2: 집합 원소 간 화살표가 함수 대응으로 오해되지 않는지 학생 화면 확인이 필요하다.
- Q4: `diagram`의 바깥 배열 열은 `묶음` 하나뿐이라 나머지 네 작품을 실제로 보이는지 입력만으로 입증되지 않는다.
- Q13: `ab→t²`, `a+b→2t` 화살표가 `a+b≥2t`를 등식으로 오독하게 만들지 검토한다.
- Q14: 제공 plan은 유리수/무리수 입력에서 첫 함수값 1/0까지만 그리며, ROOT_PLAN의 두 번째 함수 적용으로 두 값이 합쳐지는 단계는 도식에 포함하지 않는다.
- Q18: 제공 plan은 x=1,2,3,4 세로선은 정의하지만 Pₖ, Qₖ 점/라벨을 직접 정의하지 않는다. 실제 곡선 사이 길이 설명과 일치하는지 확인한다.
- Q23: 대응도는 마주 보는 좌석 번호는 담지만 위/아래 실제 배치를 나타내는 좌석도와 동등한지 확인한다. 원문 그림에서 좌석쌍이 맞는지 대조한다.
- Q9/Q19/Q21: 요약 계획만 있고 엔진 item/plan/publish JSON이 없어 현재 입력 누락으로 OPEN이다.

Q5/Q15/Q18/Q22는 기존 자산이 있으므로 재제작 판단 전에 기존 후보와 제공 plan을 실제 그림에서 비교해야 한다. Q11은 기존 PASS 이력을 승계하며 본 작업에서 덮어쓰지 않았다.
