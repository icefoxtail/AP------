## 1. 공통 디자인의 정체성

**동일한 제품 경험:** 문항을 고르는 방식, 문제 읽는 위치, 도형/그래프의 주 무대, 보조선/슬라이더, 필요할 때 여는 소형 칠판이 같은 위치와 계층에 있어야 한다. 단원이 달라도 학생이 화면 사용법을 다시 배우지 않는다.

| 화면 영역 | 시각 기준 | 일관된 기대 경험 |
| --- | --- | --- |
| 상단 헤더 | 짙은 에메랄드 배경, 작은 단원 제목, 기본/심화 선택과 제목 목록, 이전/다음 | 모든 단원에서 같은 위치와 선택 흐름 |
| 주 무대 | 검녹색 방사형 칠판, 밝은 수학 도형·그래프, 절제된 눈금·보조선 | 문제 이해에 필요한 핵심 기하가 가장 크게 보임 |
| 상단 측정 HUD | 작고 읽기 쉬운 어두운 캡슐, 노랑 계열 수식·조건 안내 | 기본 상태에 정답을 누출하지 않음 |
| 하단 조작 | 보조선 꺼짐/1/2/3/전체, 슬라이더·필요한 프리셋, 칠판 버튼 | 동일한 조작 순서, 화면마다 기능 위치를 바꾸지 않음 |
| 소형 풀이 칠판 | 에메랄드 그라데이션, 금색 테두리, Step 탭과 풀이 비교 | 학생이 문제·도형을 보며 단계별 풀이를 확인 |
| 색·표기 | 분필색 백색, 금색 강조, 청록 보조, 분홍 구분, 녹색 성립 | 색은 의미를 보조하며 단독 단서가 되지 않음 |

### 대표 디자인 토큰 (샘플에서 확인된 출발점)

| 항목 | 기준 토큰 또는 정책 |
| --- | --- |
| 본문 배경 | `#05100c` |
| 칠판 배경 | `radial-gradient(circle at 50% 45%, #122d23 0%, #091913 70%, #040d09 100%)` |
| 소형 칠판 | `linear-gradient(160deg, #132e24 0%, #0b1d17 65%, #06120e 100%)`, 금색 테두리 `#fbbf24` |
| 포인트 컬러 | 금 `#fbbf24`, 청 `#38bdf8`, 녹 `#34d399`, 분홍 `#f472b6` |
| 본문 글꼴 | Pretendard → 시스템 sans-serif fallback |
| 수학 공식 | KaTeX, 정확한 분수/근호/π·학년별 각도 단위, 복잡한 수는 `≈` |
| 권장 기본 읽기 크기 | 문제·풀이 약 `16px`, 조작·부제목은 `14px` 이상을 출발점으로 설정 |
| 조작 대상 | 주 버튼·프리셋·선택 목록은 모바일에서 가급적 `44×44 CSS px` 수준 |

이 값은 **새 실험실의 공통 출발점**이며 기존 페이지의 정상 배치를 깨는 기계적 색/픽셀 일괄 치환은 금지한다. 수학 그래프의 색은 이미 정한 의미를 우선한다.

## 2. 레이아웃 기준 — 세 기기에서 같은 사용 경험

- **PC 1200px 이상:** 좌측 큰 그래프/도형, 우측 문제 카드와 열렸을 때 풀이 칠판. 일반적 목표는 그래프:우측 패널 `68:32` 근방이지만 좁은 문항·긴 수식에 맞게 조정 가능.
- **태블릿 768~1199px:** 문제는 상단에 읽기 쉽게, 그래프와 조작·풀이 영역은 화면 폭/세로 방향을 고려해 나란히 비교할 수 있는 배치. `1024×768`도 태블릿식 사용성을 검토한다.
- **모바일 767px 이하:** 문제 먼저 → 그래프 → 보조선/슬라이더/프리셋 → 펼치는 풀이 칠판. 풀이 탭은 하나씩. 짧은 스크롤 허용, 가로 전체 페이지 넘침 금지. **프리셋 버튼을 숨기지 않는다.**
- PC/태블릿/모바일에서 단순 화면 폭 외에도 수식 길이, 칠판을 열 때의 도형 가시성, 터치 조작성으로 판정한다. 모바일 크기만 이유로 중요한 기하 조건을 제거하지 않는다.

## 3. 동일하게 유지할 화면 구조

```text
[헤더: 단원·기본/심화·문항 제목 목록·이전/다음]
[모바일/태블릿 문제 카드]
[큰 Canvas/SVG 도형·그래프]       [PC 문제 카드]
  [조건·측정 작은 배지]            [접이식 소형 칠판]
  [확대/축소/초기화(존재 시)]
[보조선: 꺼짐 | 1 | 2 | 3 | 전체 | 칠판 열기]
[필요한 슬라이더 | 의미 있는 프리셋]
[모바일 펼친 소형 칠판: Step 1/2/3/풀이 비교]
```

처음부터 모든 단계 설명·정답·비교 풀이를 여러 카드에 펼쳐 놓지 않는다. 필요한 경우에만 작은 칠판을 열어 한 단계씩 읽는다. 작은 HUD의 위치를 기준으로 도형 중심과 라벨을 배치하고 겹치면 눈에 띄는 핵심 영역부터 정리한다.

| 비교 | 공통수학 함수 | 대수 2A | 대수 2B | 통일 목표 |

**주의:** 이 비교는 실제 Git HTML·CSS·상태 핸들러의 정적 대조 결과다. 세 페이지를 동일 기기에서 렌더링해 시각적 일치도를 판정한 것은 아니므로 실기기 PASS로 간주하지 않는다.

## 5. 참고본을 그대로 복사하지 말아야 하는 이유

사용자가 제공한 `AP_Math_design_reference_compact.html`은 **디자인을 보기 위한 2문항 발췌본**이다. 예전 소스에는 모바일 프리셋 숨김, 상대적으로 작은 글씨/버튼, 일부 단계 전환·답 노출 차이가 있다. 따라서 다음을 구분한다.

- **계승:** 화면 영역 순서, 검녹색 칠판·분필 분위기, 문제-도형-작은 칠판의 밀도, 문제 선택 UI.
- **계승 금지:** 발췌본의 2문항만 있는 DB, 정답·계산, 예전 숨김/브레이크포인트·버튼 최소치, 특정 문항의 가정·애니메이션, 잘못된 소숫값·단위 표시.
- **최종 판단:** 실제 수업에서 학생이 문제를 읽고 그래프를 조작하고 풀이를 스스로 읽는 흐름이 세 기기에서 같은가?
