## 1. 절대 기준 — '문항'이 아니라 '시각 경험'

1. 실제 중1 시험 문제 그림은 **모체 도형을 고르는 참고**다. 퀴즈·정답 맞히기·문제풀이 UI 확대가 목표가 아니다.
2. 단원은 **평면 원과 부채꼴**만 다룬다. 입체·부피·공간 묶기 제외.
3. 바깥 도형, 파내는 도형, 남는 도형, 보조선, 실제 둘레의 경계를 분리해 학생 눈에 보여준다.
4. 수학 모델 하나로 도형 좌표·중심각·반지름·호의 길이·면적·둘레·이동을 동시에 계산한다. 숫자만 바꾸고 그림은 그대로인 가짜 동작 금지.
5. **넓이**: 정확한 분할·이동·회전·상쇄·붙이기. 합동이 아닌 서로 다른 곡선 조각을 강제로 끼워 맞추는 연출 금지. 처음 전체 면을 채우고, 제거한 자리는 실제 투명한 빈 공간으로 나타낸다.
6. **둘레**: 남은 면의 진짜 경계를 추적한다. 원호뿐 아니라 필요한 직선과 내부 구멍의 경계도 포함, 보조선·삭제된 지름은 제외.
7. 학생 공통 UI는 **`선과 면 | 넓이 | 둘레 | ▶ 재생` 4버튼**. 학생 화면에서 '개미' 표현, 개미 위치, 진행률, 저장 버튼 제거. `▶ 재생`은 선택 모드의 애니메이션만 동작.
8. 넓이 빼기는 **왼쪽 큰 도형 → 가운데 − → 오른쪽 꺼낸 조각**. 중심각은 실제 작은 각호와 수치를 함께 표시, 반지름 라벨은 움직이는 조각에 종속. PC/모바일 모두 텍스트 겹침 방지, 분수의 세로 높이 확보.
9. \(\pi\)항과 유리수 항은 합산 표기할 수 있으나 동류항처럼 하나의 항으로 결합하지 않는다. 정확한 식 우선.
10. **작업 단위는 유형 하나도, 모든 챕터 한꺼번에도 아닌 '변환군 하나'**. 한 군에 **서로 중복되지 않는 대표 경험 최대 약 8개**, 꼭 8개를 채우지 않는다. 중심각 60°/90°/120° 등은 별도 유형이 아니라 동일 유형의 조절값.
11. 다른 군에서도 이미 구현한 도형 모체·경계 추적·수식 렌더러는 재사용한다. 기존 앞쪽 1~6 실험 정리는 후속 별도 단계로, 현재 작업에서 손대지 않는다.
12. 원본·기존 실험 보존. 필요한 수학적 제약을 명시하고 틀린 그림은 만들어 넣지 않는다. 과도한 범용 기하 Boolean 엔진이나 공통 프로젝트 리팩터링 금지.

## 4. 공통 애니메이션·수학 계약

- 넓이 선택 → `▶ 재생`: **큰 도형 전체 색칠 → 제거 부분 강조 → 형태·넓이 불변으로 오른쪽 이동 → 가운데 − → 왼쪽에 실제 구멍·홈·분리 영역**.
- 둘레 선택 → `▶ 재생`: **현재 남는 도형의 모든 외부·내부 경계를 실제 경로대로 추적**. 연결되지 않은 두 결과 영역은 각각 추적한다.
- 선과 면: 바깥 도형 / 제거 도형 / 남은 도형 / 각호 / 반지름 / 현 / 직선 경계를 명확히 구분.
- 시나리오별로 좌표·포함 조건·호·면적·둘레·조각 위치·라벨을 하나의 정의로 관리한다. `θ, R, r, a` 등의 변경에서 상태가 일치해야 한다.
- 자유 실험은 필요한 변수만 제공한다. 수학적 조건을 깨는 슬라이더나 모든 유형에 동일한 조절 기능을 강제하지 않는다.
- 정합성 확인: 대표값과 경계값, PC 1440×900·모바일 390×844, 기존 26개 실험 진입, 기존 ①·② 유지. **미실행 검사를 PASS로 보고 금지**.
