## 1. 사용자 결정 — 앞으로 바꾸지 않을 최상위 기준

1. **학생의 도형적·시각적 경험 우선.** 문제는 도형 예시를 수집하는 수단이며, 도형 실험은 문제 풀이 모드 없이도 독립적으로 성립해야 한다.
2. **평면만 다룬다.** 단원은 「원과 부채꼴」이다. 입체, 원기둥 묶기, 부피·겉넓이·공간 경로 배제. 평면 위의 줄/울타리 활동 영역은 후순위 후보로 허용.
3. **단일 도형에서 여러 변수를 연결한다.** 중심각 `θ`, 큰 반지름 `R`, 작은 반지름 `r`, 도형의 위치·방향·겹침 관계가 바뀌면 실제 도형, 선/면, 넓이, 둘레, 호의 길이, 필요 시 중심각 추론까지 함께 달라져야 한다.
4. **원 ↔ 반원 ↔ 사분원 ↔ 부채꼴**은 고립된 문항이 아니라 연속된 경험. 같은 크기의 반원 두 개를 합쳐 원을 만들고, 원을 반으로, 반원을 다시 반으로 나누는 *실제 분할·결합*도 보여준다. 두 반원이 동일한 원을 만들려면 반지름·지름과 결합 위치가 일치해야 한다.
5. **넓이 = 면을 확인하고 정확히 분할·제거·합성·상쇄·이동/회전.** 실제 합동 조각만 강체 이동으로 꼭 맞게 붙인다. 넓이만 같고 모양이 다른 경우 '조각 맞추기'로 속이지 않고 같은 공통 영역의 더하기/빼기를 보여준다.
6. **둘레 = 남은 도형의 실제 경계 추적.** 외부/내부 경계, 원호/직선, 점선 보조선, 내부 접합선을 구분한다. 기존 경계 추적 구현은 재사용한다.
7. **결과보다 변화의 원인을 보여준다.** `선과 면 | 넓이 | 둘레 | ▶ 재생` 상단 4버튼; 넓이 선택 후 재생은 면 애니메이션, 둘레 선택 후 재생은 경계 애니메이션. 학생 화면에서 '개미'라는 단어·개미 위치 슬라이더·지나온 비율·현재값 저장 버튼을 쓰지 않는다. 중심각 근처에는 작은 각호와 각도 라벨을 붙인다.
8. **수학 정확성/시각적 대응을 우선한다.** SVG 좌표·선의 길이·색칠 면·애니메이션·수식은 같은 수학 모델을 따른다. π를 포함한 항과 유리수 항은 *더할 수는 있지만 동류항처럼 하나로 합칠 수 없음*을 시각화한다. 교과서식 세로 분수를 충분한 **세로 높이**로 표시하고 내부 위아래 스크롤을 요구하지 않는다.
9. **한 번에 변환군 하나를 완성한다.** 작은 도형 하나씩 별도 화면으로 만들지 않는다. 한 변환군 안에서 교육적으로 구별되는 여러 배치를 클릭으로 전환하고, 그 군의 공통 애니메이션과 파생형을 함께 완성한다. 반면 서로 다른 변환군 전체를 한 번에 무리하게 구현하지 않는다.
10. **학생 화면 최우선.** 도형이 가장 크게, 반지름·각호 라벨은 대상 도형에 가까이, 움직인 조각과 설명이 겹치지 않게. 모바일에서도 조각이 화면을 벗어나지 않으며 재생 버튼은 44px 이상 터치하기 쉽게.

## 2. 설계 단위: 문항도, 거대 범용 엔진도 아닌 `도형 경험 모체`

하나의 모체 = (① 도형 정의, ② 바뀌는 변수, ③ 정확한 면/경계, ④ 가능한 실제 변환, ⑤ 관찰할 관계, ⑥ 대표 참고 그림)이다.

**연결 구조 (개념 그래프)**

```text
중심각 θ · 반지름 R, r 변화
      │
      ├─ 부채꼴 ↔ 사분원(90°) ↔ 반원(180°) ↔ 원(360°)
      │                   └─ 정확한 2등분 · 결합
      ├─ 작은 부채꼴 제거 → 고리 부채꼴 → 고리 반원/고리 원
      │
      ├─ 도형 안에 넣기: [정사각형 ⊃ 사분원] → [사분원 ⊃ 반원]
      │                                   → [큰 반원 ⊃ 작은 반원 둘]
      ├─ 겹치기: [반원∩직사각형] / [부채꼴∩정사각형]
      │                   → 공통 면적 상쇄 → 반지름/각/호 관계
      ├─ 면의 재구성: 동형 조각 이동/회전 · 넓이만 같은 영역 비교
      │                   → 삼각형 채우기(원본 도형 확정 필요) · 초승달
      └─ 경계/운동: 복합 원호·태극형 → 회전하는 도형/점의 자취
```

**중요:** 연결선은 반드시 자동 변환을 뜻하지 않는다. 중심각을 움직이면 *동심 고리 부채꼴*은 연속적으로 변하지만, '사분원 안 반원'이나 '정사각형 안 사분원'은 별도의 기하 조건과 배치 변환을 적용하는 **파생 구성**이다. 이를 중심각 하나로 모두 자동 생성할 수 있다고 주장하지 않는다.

## 2-A. 중요 설계 결정 v2 — 「도형 변환군」을 실제 구현 단위로 고정

**2026-10-28 사용자 수정 지시:** 원 → 반원 둘 → 사분원 둘 같은 하나의 분할 장면만 완성하는 방식은 너무 잘게 쪼개져 있다. 학생은 **한 화면의 「넣기·파내기」 안에서 원·반원·사분원·정사각형을 클릭해 여러 파내기 형태가 계속 전환되는 것**을 경험해야 한다.

- **메인 챕터**는 학습 경험의 묶음이다. 예: `C02 도형 안에 넣고 파내기`.
- **실제 구현 단위 = 변환군(family)**. 예: `F01 넣기·파내기 변환군` 안에 **다른 외부/내부 도형의 파생 배치 6종 이상**이 같은 화면·조작으로 들어간다. 1개 파생마다 별도 HTML/메인 탭을 만들지 않는다.
- **도형 전환**: `원 / 반원 / 사분원 / 정사각형 / 부채꼴`의 바깥 모체를 클릭해 적합한 파내기 형태로 전환한다. 같은 모체를 재클릭하거나 `이전 / 다음`으로 그 모체의 실제 다른 파생 형태를 순환할 수 있다. 현재 형태 이름·전체 도형·파낼 도형·남을 영역을 함께 표시한다.
- **불가능한 조합을 억지로 조합하지 않는다.** `정사각형 안 사분원`, `사분원 안 반원`, `반원 안 작은 반원 둘`은 바깥/안쪽 도형의 반지름·배치 조건이 다르다. 각각 **정확한 파생 시나리오**로 정의하고 같은 렌더링/재생 프로토콜을 공유한다.
- **공통 작동 원리**: `바깥 전체 면` → `파낼 내부 면 표시` → `내부 면이 오른쪽으로 빠져나감` → `남는 면 강조`의 **왼쪽→오른쪽** 연출. 가운데 `−`가 나타난다. 큰 모체는 **처음에 빈 곳 없이 전체가 색칠**되어야 한다. 재생 도중 반지름·중심각을 바꾸면 연결된 모든 좌표와 식을 갱신한다.
- **둘레는 빼는 계산이 아니다.** 파낸 뒤 남는 면의 **실제 바깥·안쪽 경계 전체**를 추적한다. 파낸 부분이 바깥 변에 닿는 유형과 완전히 내부에 있는 유형은 경계 성분이 달라진다.
- **상단 네 버튼 유지**: `선과 면 | 넓이 | 둘레 | ▶ 재생`. 도형 전환 선택지는 이 아래의 **별도 변환군 선택 영역**에 둔다. 도형 종류별 재생 버튼은 만들지 않는다.
- **여섯 개 사례를 하나의 완성 단위로 다루되**, 새 기능의 공통 부분을 먼저 만든 후 같은 작업에서 파생형들을 채워 전체 완성도를 확인한다. 각 파생마다 별도 라우터/탭/엔진을 만들지 않는다.

### F01 「넣기·파내기」 파생 구성 (최초 완성 범위)

| 선택할 바깥 도형 | 파내기 형태 | 필수 관계·수학 조건 | 학생이 확인할 차이 |
|---|---|---|---|
| 원 | 동심 작은 원 | `R>r>0`, 두 원 중심 일치 | 도넛의 안쪽 원주도 둘레에 포함 |
| 원 | 중심이 어긋난 작은 원 | 중심거리 `d`, `d+r<R` | 원을 움직여도 남는 넓이·둘레는 일정 |
| 반원 | 작은 반원 2개 | 같은 지름 위 `r₁+r₂=R` | 두 안쪽 호의 길이 합 일정, 넓이는 변화 |
| 사분원 | 지름 위 작은 반원 | 작은 반원의 지름이 바깥 사분원의 반지름 `R`, `r=R/2` | 남는 면과 곡선 안쪽 경계 |
| 정사각형 | 꼭짓점 중심 사분원 | 정사각형 한 변 `a=R`, 사분원 반지름 `R` | 정사각형의 두 변이 삭제되고 원호가 남음 |
| 정사각형 | 변을 지름으로 한 반원 | 한 변 `a`, 내부 반원 반지름 `a/2` | 직선 변이 곡선 경계로 대체됨 |
| 부채꼴 | 작은 동심 부채꼴 | `0<θ≤360°`, `0≤r<R` | 현재 ⑦ 실험의 고리형을 그대로 재사용, 360° 예외 |

이것은 **7개 별도 문제**가 아니라 **동일한 F01 변환군의 7가지 프리셋**이다. 같은 도형 종류를 다시 누르면 해당 종류 안의 다른 프리셋으로 전환한다. `원`의 동심/편심 예시를 포함해 각 프리셋마다 **확실히 달라지는 관찰**이 있다.

### 공통 수학·기하 API — 거대 범용 엔진 금지

필요한 범위의 시나리오 정의 `outerRegion(params)`, `removedRegions(params)`, `resultRegion=outer\removed`, `remainingBoundary(params)`, `areaFormula(params)`, `perimeterFormula(params)`, `constraints(params)`, `labels(params)`와 공통 재생 타임라인만 공유한다. 임의의 SVG 두 개를 넣으면 모든 교차 영역이 자동으로 처리되는 **범용 Boolean 기하 엔진을 선행 구축하지 않는다**. 초기 파생 구성은 기하학적 조건과 남는 경계의 경로를 직접 검산한 **제약 있는 프리셋**으로 만든다.

## 4. 챕터별 모체 실험과 정확한 파생 예시

### C01. 중심각·반지름 변화 및 실제 분할/결합
- **현재 작동하는 모체:** 큰 반지름 `R`, 작은 반지름 `r`, 중심각 `θ`의 동심 고리 부채꼴. `r=0`이면 일반 부채꼴, `θ=90/180/360°`이면 사분원/반원/원 또는 해당 고리형.
- **자연스러운 변화:** `θ=60/90/120/180/270/360°`, `R` 고정 `r` 변경, `r` 고정 `R` 변경, 면의 변화와 경계 변화 비교.
- **새로 필요한 경험:** 완전한 원을 지름으로 나누어 합동 반원 두 개 분리→원래 위치로 결합, 반원을 두 사분원으로 분리→결합, 마지막에 고리 모델과 연결. 이를 '별도 문제 여러 개'가 아니라 **같은 도형군의 파생 실험**으로 넣는다.
- **대표 정확식:** `0≤r<R`, `0<θ<360°`에서 면적 `S=(θ/360)π(R²-r²)`; 둘레 `L=(θ/360)2π(R+r)+2(R-r)`; **360°에서는** `L=2π(R+r)`로 바뀐다(`r=0`이면 `2πR`).

### C02. 포함·파내기
- **F01 프리셋 ①** 한 변 `R`인 정사각형 안에서 꼭짓점을 중심으로 반지름 `R`의 사분원을 그린다. 남은 모서리 면 `S=R²-πR²/4`, 경계 `L=2R+πR/2`. 학생은 사분원에 맞닿는 두 변이 남은 면의 외곽 경계가 아니라는 점을 경험한다.
- **F01 프리셋 ②** 반지름 `R`의 사분원 안에, 사분원의 가로 반지름을 **지름**으로 하는 반원(반지름 `R/2`)을 넣는다. 반원은 실제 사분원 내부에 있다. 남은 영역 `S=πR²/8`, 경계 `L=R+πR`. '반원 반지름=바깥 반지름의 절반'이라는 제약은 자동 유지한다.
- **F01 프리셋 ③** 반지름 `R`의 큰 반원 안에 작은 반원 둘(`r₁+r₂=R`)을 같은 지름 위에 둔다. 남은 면 `S=π(R²-r₁²-r₂²)/2=πr₁r₂`, 세 호의 경계 `L=2πR`(작은 반원 반지름 합 유지 시). 서로 다른 크기로 움직여도 둘레가 일정한 반면 넓이가 달라지는 것을 보여준다.
- **원/반원 연결:** 원 전체에서 정확히 같은 두 반원을 분리하는 것과 큰 반원 내부에 *다른* 두 반원을 그리는 것은 **서로 다른 구성**임을 구별한다. F01에서 원/반원/사분원/정사각형/부채꼴을 선택해 연속 비교하고, 원↔반원↔사분원 **실제 분할·결합은 다음 F02 변환군**으로 완성한다.

### C03. 겹침·상쇄
- 겹친 두 면 `A, B`의 공통부분 `C=A∩B`를 정확히 추출한다. `A\B`와 `B\A`의 넓이가 같다면 `area(A)=area(B)`이고, 전체 면이 같다면 남는 두 면도 같다.
- **참고 실제 시험형 그림(사용자 제공):** 정사각형+부채꼴의 나머지 면이 같은 조건에서 호 길이, 반지름 15/10인 두 반원의 색칠 면 같은 조건에서 중심각, 반원+45° 부채꼴의 동일 전체 면에서 색칠 면적. **이미지의 숫자/정답은 정밀 독립 검산 전까지 확정값으로 취급하지 않는다.**
- 그림의 공통 면이 복잡하면 억지로 잘라 합동인 조각처럼 이동시키지 않고 **공통부분을 양쪽에 똑같이 더하거나 빼는 동시 강조·채우기**로 표현한다.
- `θ,R`를 자유 변경하면 '두 부분 면적 동일' 조건이 깨질 수 있으므로 참/거짓 또는 '현재 조건 유지/조건 벗어남'을 명시한다. 자동으로 참이라고 고정하지 않는다.

### C04. 정확한 재구성 및 넓이 관계
- **진짜 강체 이동:** 동일한 지름의 반원이 볼록한 쪽에서 오목한 홈으로 이동하여 정확히 맞는 경우, 잘린 조각의 위치·회전만 변경하고 형태와 넓이 보존.
- **상쇄 비교:** 모양이 다른 두 색칠 면, 히포크라테스의 초승달은 합동이 아니라 **면적 등식**으로 비교. '작은 반원 둘 − 큰 반원'의 관계를 보여주고 삼각형 넓이와 연결한다. 일반 증명은 선택; 학생에게 강제하지 않는다. 직각삼각형의 변 또는 면적이 **문제 조건으로 주어진 학년 적합 예시**를 사용한다.
- **정사각형 안 반원 둘 → 삼각형:** 사용자 희망 사례. *정확한 원본 배치·분할 경로가 확인되기 전에는 임의 그림으로 제작하거나 일반 성질처럼 주장하지 않는다*.

### C05. 복합 원호와 넓이/경계 분리
- 고리/태극/아르벨로스/사분원 겹침/트랙의 공통 질문: '어떤 선이 실제 둘레인가?' '면은 무엇에서 무엇을 빼는가?'
- 반지름 변화로 바깥 호와 안쪽 호가 같은 방식으로 움직이는지, 호 길이 합이 일정한데 넓이가 달라지는지 관찰.
- 내부 보조선/붙여진 부분의 접합선은 외부 경계에서 제외. 구멍이 난 경우 내부 구멍을 둘레에 포함. 경계가 분리된 성분을 가지면 각각 추적.

### C06. 회전과 점의 자취(평면)
- 삼각형/사각형은 실제 회전 중심과 회전각으로 강체 회전. 특정 점이 그린 원호의 반지름은 중심에서 **그 점까지의 실제 거리**.
- 회전 중심이 다른 꼭짓점으로 바뀌면 경로를 분리하고 각 구간 호 길이의 합으로 이동 거리를 보여준다. 그림 위에서 임의로 그은 원호를 이동 경로라고 속이지 않는다.
- 줄·울타리 문제는 별도 옵션. 3차원 줄 묶기는 도입하지 않는다.
