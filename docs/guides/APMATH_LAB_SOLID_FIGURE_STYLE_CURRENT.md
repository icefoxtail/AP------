# 중1 입체도형 실험실 그림 기준 (CURRENT)

대상: `apmath/playground/next/labs/g7-surface-volume.html`과 `labs/g7-surface-volume/*.js`(26장면). 2026-11-03 사용자(선생님) 지시로 정했다.
판정 기준은 하나다. **학생이 PC·휴대폰 화면에서 보고 길이가 어디를 가리키는지 알고, 식이 그림의 어느 면에서 나오는지 이해할 수 있는가.**
각 항목 끝의 「이유」는 학생이 헷갈렸던 점이다.

## 1. 길이 표시

- 길이는 도형 **바깥 치수선**(양 끝 짧은 막대, 가운데 숫자)이나 **모서리 바로 옆 글자**로 쓴다. 면 안에 숫자를 띄우지 않는다.
  이유: 면 한가운데나 허공에 뜬 「3」「4」가 어느 모서리의 길이인지 알 수 없었다.
- 반지름은 중심에서 **오른쪽 앞**으로 선을 긋고 선 위(또는 끝점 바깥)에 「반지름 3」을 쓴다. 방향은 모든 장면에서 같다(`D.rightFront`).
  이유: 반지름 선 방향이 장면마다 달라 같은 것을 가리키는지 몰랐다.
- 높이는 **점선과 직각 표시**로 그리고 선 옆에 「높이 5」를 쓴다. 기둥의 높이는 가장 왼쪽 세로 모서리 바깥에 세로 치수선으로 쓴다.
  이유: 면 가운데 떠 있는 「h=5」는 어느 방향의 길이인지 알 수 없었다.
- 모선은 모서리 **바깥쪽**에 바로 붙여 「모선 5」로 쓴다.
  이유: 모서리에서 떨어진 「R=5」는 높이로 읽혔다.
- 전개도에서 이어 붙는 옆면 조각들의 길이는 **조각 아래 바깥에 치수선**을 한 줄로 두고, 그 아래에 전체를 덮는 긴 괄호로 합을 쓴다(「밑면의 둘레 = 3+4+3+4 = 14」). 밑면의 변과 옆면에서 맞붙는 변은 **같은 색**으로 칠하고 그 길이 글자도 같은 색으로 쓴다.
  이유: 전개도의 「3 4 3 4」가 면 안에 있어 밑면의 어느 변과 붙는지, 합이 어디서 나오는지 보이지 않았다.

## 2. 기호

- 숫자 우선. 허용 기호는 **r, h, l, S, V**뿐이다. R·q·p·d·w·c·a·b, 아래첨자(R₁, h₂), S₀, 「πRr」「2a²+4ah」「6a²」는 쓰지 않는다. 원뿔 옆넓이는 πrl(l = 모선의 길이).
  이유: 중1 교과서는 숫자와 말(밑넓이, 높이, 반지름, 모선의 길이)로 쓰고, 처음 보는 문자는 식을 외워야 하는 것으로 읽혔다.
- 그림 글자·칩·읽기값·제목의 식은 **숫자 식**으로 쓴다. 예: 「6×6×2 + 4×6×5 = 192」, 「밑넓이 12」, 「높이 5」. 조절 막대 이름도 말로 쓴다(「가로」「모선의 길이」).
  이유: 문자 식은 그림의 어느 값을 넣는지 연결되지 않았다.
- 정리 탭 풀이 글(KaTeX)에서는 r, h, l, S, V를 허용 범위에서 쓸 수 있으나, 풀이는 먼저 숫자와 말로 쓰고 문자 식은 괄호로 덧붙인다.

## 3. 넓이 라벨

- 면 안에 둘 때는 이름을 붙인다: 「밑넓이 12」「옆넓이 70」. 면이 좁으면 이름과 값을 두 줄로 나눈다(`D.areaLab`의 `maxW`).
  이유: 면 안의 「S=12」는 무엇의 넓이인지, 단위가 무엇인지 알 수 없었다.
- 수수께끼 같은 글(「붙은 면(제외)」 등)은 쓰지 않는다. 뜻을 말로 풀어 쓴다(「맞붙어 가려진 면은 겉넓이에서 빼요」).

## 4. 입체와 무대

- 한 실험실 안에서 같은 비스듬한 투영을 쓴다. 숨은 선은 점선이다.
- 그림은 무대 안에 꽉 차게 그리되 잘리지 않게 한다. 치수선·괄호 자리를 `fitOpt`의 `l r t b`(픽셀)로 미리 비워 둔다(기둥 전개도 `{l:84, r:40, t:40, b:112}` 등).
- 구·반구는 위아래 흰 틈이 없어야 한다. 1/4 구·1/8 구는 잎 모양이 아니라 구의 잘린 조각으로 읽혀야 한다.
- 뚫린 구멍은 「뚫릴 자리」(붉은 반투명 원기둥, 윗원 실선, 가려진 부분 점선)로 먼저 보이고, 뚫은 뒤에는 안쪽 벽(노랑)이 보이게 한다.

## 5. 겹침

- 글자끼리 겹침·맞닿음이 0이어야 한다(`label-sweep`, 태블릿 1024×768 · 휴대폰 390×844, 탐구 막대 여러 값·정리 마지막 단계·문제 탭).
- 글자와 선이 겹치지 않게 놓는다. 선 위에 글자를 둘 때는 선을 글자 자리만큼 비운다(치수선), 그 밖에는 선 옆(법선 방향)에 둔다.
- 작은 원 위에서는 반지름 글자를 테두리 끝점 바깥(`end`)에 두어 넓이 글자와 만나지 않게 한다.

## 6. 값

- π가 들어가는 값은 π 꼴(정수·기약분수 계수)로만 쓴다. 소수·근삿값 0. 막대를 움직인 상태도 같다(`pi-scan --sweep`).
- 학생 화면에 √를 쓰지 않는다. 높이가 √ 꼴이 되는 경우(원뿔의 반지름·모선만 정할 때)는 숫자 없이 「높이」라고만 쓴다.
- 각도도 정수로 쓴다.

## 7. 교수 원칙 (2026-11-03 사용자 지시)

이유: 원뿔대에서 겉넓이를 전개도 없이 입체 위의 식으로만 설명해 학생이 이해하기 어려웠다.

- **겉넓이는 반드시 전개도 그림으로 설명한다.** 펼친 면마다 치수와 넓이를 보여 주고, 「겉넓이 = 면 넓이의 합」 식이 그 면들과 바로 이어지게 한다(면 → 같은 색·같은 이름의 항 → 합). 구처럼 펼 수 없는 입체는 곡면 조각을 늘어놓는 그림으로 대신한다.
- **부피는 겨냥도(입체 그림)로 설명한다.** 원뿔대라면 큰 뿔에서 작은 뿔을 빼는 그림이다. 판 쌓기·붓기·분해처럼 입체 그림에서 식이 나오게 한다.
- 겉넓이 식(예: πR₂r₂−πR₁r₁)을 입체 그림 위에 떠 있는 글자로 두지 않는다. 식은 전개도의 면과 연결된 곳(면 이름표·조각 줄·정리 단계)에 둔다.
- 전개도와 겨냥도를 오가는 방법은 장면에 맞게 정한다. 탭이나 「구하는 것」 칩, 막대 단계를 쓰거나, 정리 단계에서 그림을 바꾼다.

## 8. 공용 도구 (이 실험실 안에서만 쓴다)

`labs/g7-surface-volume/dims.js`(scene3가 돌려주는 `D`에 붙는다, 모듈 순서 `solid3d → dims → core`). 거리·간격은 화면 픽셀이다.

| 도구 | 쓰임 |
| --- | --- |
| `D.dim(p, q, 글, {from\|side, off, color, alpha, fig\|px})` | 치수선. 모서리에서 `off`만큼 떨어진 선, 보조선, 양 끝 막대, 가운데 글자(세로에 가까우면 선 옆) |
| `D.brace(p, q, 글, {side, off, px})` | 여러 길이를 한 번에 덮는 긴 괄호와 아래 글자 |
| `D.radius(중심, 테두리, 글, {dash, end, alongFrac})` | 반지름: 선, 중심 점, 선 위(또는 끝점 바깥) 글자 |
| `D.height(발, 꼭대기, 글, {a, side, alongFrac})` | 높이: 점선, 발의 직각 표시, 선 옆 글자 |
| `D.edgeLab(p, q, 글, {from\|side})` | 모서리 바깥쪽 바로 옆 글자(모선·호의 길이) |
| `D.areaLab(점, 이름, 값, {maxW, dx, dy})` | 면 안 「밑넓이 12」(좁으면 두 줄) |
| `D.rightFront(deg)`, `D.rimPick(중심, 점들, dir)`, `D.px(p3)` | 반지름 방향·테두리 점 고르기·화면 좌표 |
| `G.pairColor(k)` | 밑면 변 ↔ 옆면 변 맞붙는 색 (violet, orange, rose, sky) |
| `G.netDraw`의 `style.edgeStyle(변, 조각)` | 전개도의 변을 같은 색으로 칠함 |

시범으로 쓴 곳: `t1.js` sv1-1(전개도 치수선·괄호·같은 색 변), `t2.js` sv2-2(모선·반지름·높이·호 = 둘레), `t5.js` sv5-1(뚫릴 자리·치수선·숫자 식).

## 10. 나머지 23장면 문제 목록 (다음 단계 입력)
