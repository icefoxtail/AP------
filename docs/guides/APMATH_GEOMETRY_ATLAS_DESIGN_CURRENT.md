# 도형의 모든 것 · Geometry Atlas 설계 CURRENT

> 기준일: 2026-11-02. 도형 실험실 2.0(`apmath/playground/next/`)을 초·중·고를 잇는 도형 프로그램으로 넓히기 위한 설계 결정 모음이다. 결정마다 선생님 말씀(이유)을 붙인다. 구현 세부는 각 작업 지시서와 `apmath/playground/next/README.md`에 둔다.

## 1. 목표 (중고등 통합 목표)

- 고등은 정석 풀이가 아니라 **도형으로 빠르게 접근하는 경험**을 준다. 이유(선생님): 기하와 벡터의 포물선·타원·쌍곡선, 원의 방정식처럼 보조도형·직각삼각형·닮음으로 쉽게 풀리는 문제가 많은데, 학원과 학교는 정석 풀이 위주라 이 경험을 줄 곳이 없다. 실험실은 처음부터 이 이유로 만들었다.
- 빠른 풀이는 **모두 보여 주고 학생이 고르게** 한다. 서술형에서도 빠른 풀이가 중요하므로, 감점 없이 쓰는 문장 틀을 함께 준다.
- 문제가 전부가 아니다. 옛 장면의 탐구 경험(움직이고 돌려 보는 그림)이 먼저이고, 문제는 그 위에 얹는다. 탐구 흐름을 해치는 문제는 넣지 않는다. 예: `alg-unit-circle` 옛 장면 1~4는 선생님이 고심해 만든 학습 장면이라 그대로 둔다.
- 교육과정에서 빠진 내용도 「이전 교육과정」 표시로 남긴다(옛 기출 학습, 재도입 대비).

## 2. 세 기둥

| 기둥 | 하는 일 | 상태 |
|---|---|---|
| 실험실 | 눈으로 보고 움직이는 장면. 탐구·정리·문제 | 실험실 54개, 고등 옛 장면 살리기 완료 |
| 노선 | 개념 노선(완행) + 빠른 풀이 노선(급행) | 개념 노선만 있음 |
| 사전 | 도형별 정의·성질·판정 조건·서술형 문장 카드 | 범위 조사 완료(초중고 196항목), 화면은 설계 |

세 기둥은 서로 링크로 잇는다. 풀이에 나온 "마름모의 성질"을 누르면 사전 카드가 열리고, 카드에서 그 성질이 쓰이는 실험실 장면과 급행 노선 역으로 간다. 데이터(카탈로그·태그)로 쌓아 앱이나 초등 확장 때도 구조가 그대로 가게 한다.

## 3. 노선: 우주 안의 기차

- 입구는 AP Math Universe(분위기·호기심)다. 실제로 고르고 이동하는 곳은 **노선도**다. 이유(선생님): 우주를 처음부터 보여 주면 주된 개념이 무엇인지 헷갈릴 수 있고, 중1부터 정리한 지금의 노선도가 직관적이다.
- 표현: 별 = 역(장면), 별자리 선 = 노선. 생김새는 우주, 읽는 법은 지하철이다. 줌 단계는 우주 → 은하(학교급·과목) → 별자리 노선도.
- 열차 두 종류:
  - **개념 열차(완행)**: 단원 순서로 모든 역에 선다(지금 노선도).
  - **빠른 풀이 급행**: 같은 별을 지나되 기술 단위로 건너뛴다. 환승역에서 중등 성질이 고등 빠른 풀이로 이어진다.
- 내 기차: 학생이 해 본 역까지 기차를 표시하는 진도 기록(앱 확장 시 학습 기록).
- 이름은 우리 것으로 짓는다(가칭 「Atlas Express」). 「은하철도 999」는 발상의 출처일 뿐이고, 그 이름·캐릭터·디자인은 쓰지 않는다.

### 빠른 풀이 급행 노선 초안 (역은 기출 빈도 조사 뒤 확정)

| 호선 | 기술 | 역 예시 (초 → 중 → 고) |
|---|---|---|
| 1 | 대칭으로 펴기 | 선대칭 → 수직이등분선·이등변 → 최단거리 → 이차곡선 정의 → 공간 펼치기 → 벡터 \|PA\|+\|PB\| |
| 2 | 닮음과 비 | 확대·축소 → 닮음·평행선 비·무게중심 → 내분점 → 지수함수 위 등비 → 삼차함수 1:√3 → 초점 현 → 벡터 넓이비 → 도형 비의 극한 |
| 3 | 직각삼각형 찾기 | 피타고라스 → 삼각비·원의 현 → 점과 직선 거리·현·접선 길이 → 단위원 → 삼수선 → 벡터 크기 |
| 4 | 숨은 원 찾기 | 원주각(지름 위 직각) → 아폴로니우스 원 → PA·PB=0 → 사인법칙 외접원 |
| 5 | 넓이로 보기 | 넓이 나누기 → 넓이비 → 곱셈공식·산술기하 → Σ 계단 → 적분·역함수 적분·포물선 넓이 4/3 → 넓이 확률 |
| 6 | 식을 도형으로 번역 | 거리(√), 기울기((y−b)/(x−a)), x²+y², 부등식 영역, 내적 = 정사영 |
| 7 | 움직여서 경계 찾기 | 개수가 바뀌는 순간은 접할 때와 끝점을 지날 때 |
| 8 | 차원 낮추기 | 전개도 → 회전체·단면 → 공간 단면·정사영·삼수선 |
| 9 | 특수한 경우로 먼저 보기 | "어디서든 일정"이면 가장 쉬운 위치에서 (모든 노선의 팁으로 둘 수 있음) |

### 역(기술 카드) 구성

1. 신호: 이 기술을 쓰라는 문제 속 단서.
2. 그림 경험: 실험실 장면 링크(재사용).
3. 정석 풀이와 빠른 풀이 나란히.
4. 서술형 문장 틀: 감점 없이 쓰는 문장. 품질은 아카이브 학생용 서술형 풀이 기준과 같게.
5. 연습: 기출 변형 2~3문항(「새 문제」 생성기 재사용).

## 4. 사전: 도형별 정의·성질 카드

- 이유(선생님): 고1도 중1·중2 도형 성질을 거의 잊어서, 모의고사 도형 문제를 기본 성질 때문에 틀린다.
- 카드 구성: 정의 / 성질 / 판정 조건 / 그림(실험실 링크) / 이 성질이 쓰이는 곳(고등 문제·급행 역) / 서술형 문장 틀.
  - 예: 이등변삼각형 — 두 변의 길이가 같은 삼각형 / 두 밑각이 같다, 꼭지각의 이등분선은 밑변을 수직이등분한다 / "△ABC는 AB=AC인 이등변삼각형이므로 ∠B=∠C".
- 풀이 속 도형 이름은 카드로 링크한다.
- 범위: 초등 54·중등 69·고등 60·교과 외 도구 13, 카드 데이터는 `geometry-dictionary.json`. 교과 외 정리(메넬라우스·체바·각의 이등분선 정리 등)는 「교과 외 도구」로 표시하고, 서술형에는 닮음·넓이비로 풀어 쓰는 안전한 문장을 함께 둔다. 초등 학년 배치와 2022 개정 잔존 여부 일부는 EVIDENCE_DEBT(교과서 대조 필요).

## 5. 화면 기준

- 주 화면은 태블릿(가로·세로)과 PC다. 이유(선생님): 도형 하나가 차지하는 면적이 크고 설명·문제·연결 정보가 함께 있어 폰에서는 한계가 있다. 학생은 태블릿이나 PC에서 눌러 보며 놀다가 문제를 보고 연결을 깨닫는다.
- 폰은 "열어서 볼 수 있다"를 보장한다. 글자 잘림 0, 문제 탭을 열면 문제 문장이 바로 보이는 것은 계속 지킨다.
- 검사 화면에 태블릿 768×1024, 1024×768을 추가한다(다음 단계).
