## 1. 목표와 범위

학생은 **단원 → 전체 목차 → 원하는 세부 학습 항목 → 시각 풀이 ↔ 직접 해보기** 순서로 학습한다. 단원 진입만으로 첫 풀이를 재생하지 않는다. 학년·단원 구분과 기존 개념·기본·심화 및 단원별 세부 유형을 보존한다.

대상은 `g7-points-lines`, `g7-parallel`, `g7-spatial`, `g7-construction`, `g7-area`, `g7-polygons`, `g7-circle-sector`, `g7-polyhedra`, `g7-surface-volume`, `g7-solids`, `g7-coordinate-graphs`, `g7-proportion`이다. 다른 학년·시험·교사 모드에 이 진입 정책을 확대하지 않는다.

기준 제작물은 **318개 장면·580개 시각 풀이·579개 기존 해설**이다. 총개수만 맞추지 말고 `lab ID → group/유형 → scene ID → short/기존 해설 ID·label`의 실제 대응과 접근 경로를 보존한다. 최신 main에 정당하게 추가된 항목도 함께 유지하며, 고정 숫자를 맞추기 위해 항목을 삭제하거나 합치지 않는다.

## 2. 목차와 항목 연결

- 기존 `apl-toc.js`와 shell의 장면·그룹·풀이 목록을 재사용한다. 목차용 콘텐츠 목록이나 별도 탐색 엔진을 중복 관리하지 않는다.
- 목차에는 단원 전체 구조와 학습 항목명을 표시한다. 기존 분류명·순서·유형을 임의로 평탄화하거나 재분류하지 않는다.
- 하나의 장면에 풀이가 여러 개면 각각 선택할 수 있어야 한다. 재생 대상이 식별되는 최하위 항목을 선택했을 때 해당 풀이를 연다. 장면과 풀이를 무조건 1:1로 가정하지 않는다.
- 분류 펼치기·그룹 선택은 탐색 동작이다. 이 동작만으로 그룹의 첫 풀이를 실행하지 않는다. 탐구용 프리셋을 모두 독립 목차 항목으로 바꾸지 않는다.
- 목차 복귀 시 선택한 항목·펼친 분류·스크롤 위치를 복원한다. 현재 항목을 시각적으로 표시하고 키보드 포커스도 적절한 위치로 돌려준다.

## 3. 진입과 재생

| 진입·행동 | 화면과 재생 상태 |
| --- | --- |
| 일반 단원 URL, 학생포털·실험실 목록에서 단원 선택 | 단원 목차, 재생 없음 |
| 기존 `#n` 등 그룹을 가리키는 링크 | 해당 분류를 찾을 수 있는 목차, 재생 없음 |
| 목차에서 세부 풀이 항목을 명시적으로 선택 | 선택한 학습 화면에서 해당 풀이 시작 |
| 유효한 시각 풀이를 명시한 직접 링크 | 지정한 학습 항목 표시, 자동재생 없이 준비·일시정지 |
| 새로고침·브라우저 뒤로/앞으로·방문 이력 복원 | 저장된 목차 또는 항목과 위치 복원, 재생은 일시정지 |
| 재생 종료 | 현재 항목의 종료 상태 유지; 다음 항목·탐구로 강제 이동 없음 |
| 유효하지 않거나 삭제된 항목 식별자 | 해당 단원 목차로 복귀; 다른 첫 풀이를 대신 자동재생하지 않음 |

명시적인 재생 선택에도 기존 동작 줄이기 설정은 존중한다. `재생·일시정지·처음부터 다시보기·진행 위치 조절`을 제공하고, 진행 위치 조절 후에는 그 위치에서 일시정지한다. 재생 중 항목을 바꾸면 이전 프레임 요청·타이머·연출을 종료한 뒤 새 항목을 표시한다.

## 4. 현재 위치와 이동

학습 화면 상단은 **뒤로가기·현재 항목명·목차**를 간결하게 제공한다. 현재 위치를 알 수 있는 단원·분류 정보는 유지하되, 동일한 전체 목차를 여러 줄로 반복하지 않는다. 해당 장면의 다른 풀이·세부 유형으로 이동하는 기존 기능을 계속 제공한다.

| 제어 | 의미 |
| --- | --- |
| 뒤로가기 | 실제 직전 목차 또는 학습 항목으로 이동. 브라우저 뒤로가기와 같은 순서 |
| 목차 | 현재 단원의 목차로 이동, 선택·펼침·스크롤 복원 |
| 이전 항목·다음 항목 | 목차의 실제 학습 항목 순서로 이동. 처음·마지막 경계는 비활성화하며 임의 순환하지 않음 |
| 풀이의 이전 단계·다음 단계 | 현재 시각 풀이 안에서 진행 위치만 이동. 다른 학습 항목으로 이동하지 않음 |
| 직접 해보기·애니메이션 보기 | 같은 학습 항목 안에서 모드 전환 |

예를 들어 `목차 → 항목 A → 항목 B` 뒤 B에서 뒤로가기를 누르면 A로, 목차를 누르면 단원 목차로 간다. 방문 이력이 없는 직접 링크의 내부 뒤로가기는 해당 단원 목차를 안전한 복귀점으로 사용한다.

History 상태는 중1 학습 전용 namespace를 사용하여 다른 shell·학생포털 상태를 덮어쓰지 않는다. **목차와 학습 항목 사이의 명시적 이동만 새 방문 이력으로 추가**한다. 재생 프레임·진행바·슬라이더·모드 전환·상태 동기화는 현재 항목의 상태를 갱신하며, 뒤로가기 횟수를 늘리지 않는다. `popstate` 복원 과정에서 새 이력을 추가하지 않는다.

## 5. 탐구와 시각 풀이 상태

- 같은 항목의 탐구 매개변수·프리셋·문제 seed·선택 상태·카메라/줌/팬을 보존한다. 애니메이션의 임시 연출 상태로 학생의 탐구 상태를 덮어쓰지 않는다.
- 직접 해보기를 누르면 재생을 중지하고 해당 항목의 기존 슬라이더·드래그·회전·프리셋·문제 탐구를 사용할 수 있게 한다. 탐구에 재진입하면 앞서 조작한 상태를 복원한다.
- 같은 조건에서 애니메이션으로 돌아오면 선택한 풀이와 진행 위치를 보존한다. 이어서 보기와 처음부터 다시보기의 동작을 구분한다.
- 학생이 탐구 조건·문제 seed·유형을 바꾸면 시각 풀이를 새 조건에 다시 연결하고 진행 위치를 초기화한다. 이전 조건의 그림·수식·정답을 새 문제에 표시하지 않는다. 카메라 이동만으로 수학적 조건을 바꾸지 않는다.
- 항목별 상태는 서로 섞이지 않아야 한다. 새 링크에 명시된 조건은 오래된 방문 기록보다 우선한다. 새로고침·이력 복원은 저장된 재생 위치를 복구해도 재생 자체를 자동 재개하지 않는다.
- 기존 탐구와 기존 해설에 접근하는 경로를 유지한다. 별도 계정 진도 저장·학습 이력 서비스 신설은 이 UX 작업의 필수 범위가 아니다.

## 6. 화면과 좌표 눈금

모바일 학습 화면의 기본 흐름은 `현재 항목 → 도형·애니메이션 → 재생 조작부 → 직접 해보기 → 항목 이동`이다. 메뉴를 숨기는 과도한 확대를 기본값으로 삼지 않는다. 선택적 전체 화면은 종료와 목차 복귀 경로를 제공한다.

- 모바일에서도 상단 뒤로가기·목차와 주요 제어에 쉽게 접근할 수 있어야 한다. 주요 터치 대상은 44px를 기본 목표로 하고, 고정 영역이 도형·라벨·드래그 핸들을 가리지 않게 한다.
- 휴대폰·태블릿·PC에서 캔버스의 실제 크기와 좌표 변환을 갱신한다. 빈 도형, 잘린 축·수식, 전체 페이지 가로 넘침, 학생포털 하단바의 실험실 조작 방해를 허용하지 않는다.
- 공통 CSS 변경은 중1 학습 경계 안에 적용한다. 기존 다른 학년·시험·교사 화면의 내비게이션과 배치를 불필요하게 변경하지 않는다.
- 순서쌍·정수 좌표 읽기·사분면·좌표 이동 등 해당 장면의 기본 화면은 **1단위 격자와 숫자 눈금**을 사용한다. P(3, 2), P(4, 3)처럼 학습에 필요한 점과 축 숫자를 확대 없이 확인할 수 있어야 한다.
- 같은 장면의 탐구와 시각 풀이가 같은 눈금 설정을 사용한다. 기존 줌·팬은 유지하고, 시간·거리·속력·기온·변화량처럼 다른 축 단위나 소수 눈금이 필요한 그래프에 1단위를 일괄 강제하지 않는다.

## 7. 구현·검증·운영 마감

공통 소유 경계는 `apl-g7-learning.js`의 중1 상태·재생, `apl-g7-learning.css`의 중1 배치, `apl-toc.js`의 기존 목차, `apl-shell.js`의 장면·그룹·URL 연동이다. 기존 상태와 API를 재사용하고, 필요한 직접 의존성만 변경한다.

1. **기준 대조:** 최신 main의 실제 등록 목록에서 장면·분류·유형·풀이 ID와 label의 대응을 확보한다. 변경 후 기존 항목의 누락·잘못된 연결·접근 불가·의도치 않은 중복이 없는지 전체 인벤토리를 대조한다.
2. **대표 흐름:** 구조가 다른 대표 단원에서 목차 선택 → 재생 중 항목 이동 → 탐구 → 풀이 복귀 → 목차/뒤로가기/앞으로가기/새로고침을 실제 브라우저로 확인한 뒤 공통 적용을 마감한다. 여러 풀이가 있는 장면·3D 조작·좌표평면을 포함한다.
3. **실제 진입 경로:** 일반 운영 URL과 학생포털·실험실 목록의 실제 링크로 첫 진입을 검사한다. 수동·디버그 진입 옵션이나 내부 함수 호출만으로 기본 목차·자동재생 정책을 검증했다고 하지 않는다. 직접 링크도 별도 확인한다.
4. **기기와 상호작용:** `390×844`, `820×1180`, `1024×768`, `1440×900`의 변경 화면을 확인한다. 좌표 읽기는 좁은 휴대폰 폭도 표적 확인한다. 실제 휴대폰 실기기 검증은 수행했을 때만 기록한다.
5. **검증 재사용:** 판본·직접 의존성이 유효한 기존 수학·시각 풀이 근거는 재사용한다. 580개 정상 풀이를 처음부터 재생·재풀이하지 않는다. 변경된 진입·탐색·복원·눈금과 직접 영향 범위는 새로 확인한다.
6. **병합·배포:** 관련 구문·회귀 검사와 필수 PR CI를 통과한 변경만 승인된 범위에서 main에 병합한다. 원격 main 반영, 배포 성공, 학생 운영 경로의 실제 동작을 각각 확인한다. CI·검증·배포 보호 장치를 우회하지 않는다.

완료 기준은 **단원 첫 화면이 목차이고, 기존 모든 항목을 선택·재생·탐구할 수 있으며, 돌아가도 학습 위치와 조건이 보존되는 것**이다. 구조 검사·수학 검증·브라우저 UX·main·배포는 각각 확인한 범위만 판정한다. 실행 로그·캡처·원시 검증 증거는 이 운영 계약에 누적하지 않는다.
