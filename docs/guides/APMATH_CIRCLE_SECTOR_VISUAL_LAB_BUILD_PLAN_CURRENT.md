## 2. S01 상세 설계: 원을 나누고 다시 합치기

### 2-1. 목표 — 새 문항이 아니라 3개의 연결된 실제 움직임

1. **원의 2등분**: 반지름 `R`의 꽉 찬 원을 지름을 따라 정확히 나눈다. 위/아래(또는 좌/우) 같은 크기의 반원 두 개가 서로 반대 방향으로 **평행이동**해 분리된다. 다시 재생/역재생하거나 결합 조작으로 원래 자리에 오면 빈틈 없이 원을 완성한다.
2. **반원의 2등분**: 하나의 반원을 중심에서 시작하는 반지름을 따라 두 사분원으로 나눈다. 사분원 둘을 떨어뜨린 뒤 다시 붙여 반원을 만든다.
3. **변화 연결**: 현재 `R`을 변경하면 원·반원·사분원들의 실제 반지름, 면적, 경계 길이와 이동 거리(화면 위치만)가 즉시 갱신된다. `90/180/360°` 선택은 현재 도형 구성을 가리키도록 기존 중심각 조절과 연동한다. 원과 반원으로 나누는 경우 `r=0`을 기준으로 한다. `r>0`이면 고리형 분할을 별도 해석하거나 안내 후 단순 분할 모드로 전환한다. **말없이 내부 구멍을 채우면 안 된다.**

### 2-2. 수학적 정의

- 원: 중심 `O=(0,0)`, 반지름 `R>0`; `D={(x,y):x²+y²≤R²}`.
- 위/아래 반원: `D∩{y≥0}`, `D∩{y≤0}`. 경계 직경 `2R`과 반원호 `πR`.
- 반원의 사분원 분할: `D∩{x≥0,y≥0}` 및 `D∩{x≤0,y≥0}`. 각각 90° 면으로 정확하게 구성.
- 넓이: `S원=πR²`, `S반원=πR²/2`, `S사분원=πR²/4`; **이동 전후 조각 넓이 불변**, 원 둘 = 반원 둘의 합 = 사분원 넷의 합.
- 각 도형 단독 둘레: 원 `2πR`, 반원 `πR+2R`, 사분원 `πR/2+2R`. **분리된 조각의 둘레 합은 합쳐진 도형의 둘레와 일반적으로 다르다.** 내부 접합선이 사라지기 때문.
- 중심각: 원 `360°`, 반원 `180°`, 사분원 `90°`. 중심각의 작은 각호는 각의 실제 중심 근처에 표시; `360°`는 원 전체임을 라벨로 표현하고 가짜 0° 각호를 그리지 않는다.

### 2-3. 학생 화면 동작/모드

- **상단 4버튼은 보존:** `선과 면 | 넓이 | 둘레 | ▶ 재생`. 새 상단 버튼 추가 금지. 기존 '처음 모양으로'는 원래 있는 초기화이므로 유지.
- 아래 도형 변환 선택 UI는 **필요 최소한**: `원 → 반원 2개`, `반원 → 사분원 2개` 두 선택지를 기존 ⑦ 탭의 내부 하위 실험으로 둔다. 새 메인 탭/별도 HTML 생성 금지.
- **선과 면:** 원 전체/반원 경계/가운데 지름(분리 전에는 내부 분할선)을 색으로 구별; 값과 시각의 대응.
- **넓이 + ▶ 재생:** 분할선이 등장 → 두 조각이 *원본 안에서 정확히 구분* → 위/아래 또는 좌/우로 평행이동해 분리 → 다시 제자리로 결합하면서 전체 면 회복. 조각의 모양·면적은 절대 변경하지 않는다. 이동 방향은 교육적 분할선에 수직으로, 최종 화면에서는 서로 겹치지 않게.
- **둘레 + ▶ 재생:** 합쳐진 원/반원의 **실제 바깥 경계**를 추적한다. 분리된 상태라면 각 조각의 지름/반지름을 포함한 외곽 경계를 **각각** 추적한다. 기존 경계 추적 규칙 재사용. 학생 화면에서 '개미' 단어 사용 금지.
- 수식: `넓이(원)=넓이(반원)×2`, `넓이(반원)=넓이(사분원)×2`; 둘레는 더하면 왜 달라지는지 그려진 내부 접합선의 소멸로 보여준다. 세로 분수/π식 충분한 행 높이, 페이지 전체 가로 넘침 금지.
- ⑦ 기존 **고리 부채꼴의 수평 빼기 연출**은 변경하지 않는다. 새로운 분할 흐름에서 별도 스테이징을 허용하되, 기존 사용자 요청의 `큰 부채꼴 (좌) → − → 작은 부채꼴 (우)` 가로 배치를 손상시키지 않는다.

### 2-4. 필수 도형·애니메이션 상태표

| 상태 | 그려야 하는 것 | 둘레 경계 | 계산에서 주의 |
|---|---|---|---|
| A. 합쳐진 원 | 꽉 찬 원 / 내부 분할선은 점선 | 원주 하나 | 중심 지름을 둘레에 더하지 않음 |
| B. 두 반원 분리 | 위·아래 반원이 각각 완전한 반원 | 각 반원호 + 각 지름 | 두 지름을 합치면 원 둘레보다 `4R` 만큼 더 김 |
| C. 두 반원 재결합 | 원으로 정확히 복원, 접합선은 점선/제거 | 원주 하나 | 넓이 보존, 둘레만 변함 |
| D. 합쳐진 반원 | 반원호 + 지름 | `πR+2R` | 안쪽 사분원 분할선은 내부선 |
| E. 두 사분원 분리 | 90° 사분원 각각 | 각 호 + 각 반지름 2개 | 두 사분원의 둘레 합과 반원 둘레 다름 |
| F. 두 사분원 결합 | 반원으로 복원 | `πR+2R` | 중간 분할선 삭제/점선 처리 |
