## 1. 실행 단위와 화면 구조 — 문항별/도형별 별도 구현 금지

**하나의 변환군 = 공통 조작 + 5~7개 파생 프리셋 + 각각의 수학 조건 + 같은 넓이·둘레 관찰 방식**. 도형마다 새 메인 탭과 새 재생 버튼을 만들지 않는다.

```
⑦ 도형 변환 실험
 ├ 변환군: [각도·고리] [넣기·파내기] [나누기·합치기] (후자는 추후)
 ├ 바깥 도형 선택: [원] [반원] [사분원] [정사각형] [부채꼴]
 ├ 파생 배치: 현재 예시명 + [이전] [다음] (같은 도형 재클릭도 다음 예시)
 ├ [선과 면] [넓이] [둘레] [▶ 재생]    ← 공통 4버튼, 기존 위치 조정 가능
 ├ 대표 도형: 왼쪽 전체 면 → 가운데 − → 오른쪽으로 빠져나오는 조각
 ├ 조건 조절: 현재 예시에 **실제로 의미 있는 변수만** 표시
 └ 관찰: 현재 실제 도형에 대응하는 선·면·넓이·둘레·관계식
```

**선택 동작 예시:** `넣기·파내기` → `원` 클릭 = 동심원 파내기 → `원` 다시 클릭 = 중심 벗어난 원 파내기 → `반원` 클릭 = 작은 반원 둘 파내기 → `사분원` 클릭 = 내부 반원 파내기 → `정사각형` 클릭 = 사분원 파내기 → `정사각형` 다시 클릭 = 반원 파내기 → `부채꼴` 클릭 = 작은 부채꼴 파내기. `이전/다음`은 전체 7개를 연속 순환하게 해 학생이 개념을 끊지 않게 한다. 클릭할 수 있는 도형별 아이콘/라벨에 접근 가능한 텍스트를 제공한다.

- 조절값 `R/r/θ/d/r₁`은 **현재 프리셋만의 허용 조건**으로 제약한다. 원↔반원↔사분원↔사각형 전환 때 내부 조각이 밖으로 튀어나오는 상태를 만들지 않는다.
- 자동 전환은 기하학적 변형을 뜻하지 않는다. 종류를 클릭하면 **명확히 새로운 유효 배치**를 선택하고, 연속적인 슬라이더 변화는 **선택된 배치 내부**에서만 수행한다. 다른 도형들이 동일 경로를 갖는다고 주장하지 않는다.
- 도형 외부에서 임의 조각을 지우는 거대 범용 SVG Boolean 엔진은 만들지 않는다. **프리셋별 정확한 면/경계 계산을 공유 인터페이스로 묶는 것**만 구현한다.

## 2. F01 「넣기·파내기」 완성 범위 — 7개 파생 프리셋

`S`는 남는 색칠 면적, `L`은 **남는 색칠 도형의 실제 전체 경계**. 호와 직선을 혼동하지 않는다.

| ID | 화면에서 선택 | 정확한 기하 조건 | 남는 넓이 S | 남는 둘레 L | 학생이 발견할 관계 |
|---|---|---|---|---|---|
| P01 | 원 → 동심원 | 큰 원 `R`, 작은 원 `r`, `0<r<R` | `π(R²−r²)` | `2π(R+r)` | 완전한 구멍은 안쪽 원주도 둘레 |
| P02 | 원 → 중심이 어긋난 작은 원 | 중심 간 거리 `d`, `d+r<R` | `π(R²−r²)` | `2π(R+r)` | 위치를 바꿔도 면적·경계 길이는 불변 |
| P03 | 반원 → 작은 반원 둘 | 큰 반지름 `R`, 같은 지름 위 반지름 `r₁+r₂=R`, 두 작은 반원은 큰 반원 내부 | `π r₁r₂` | `2πR` | 두 안쪽 호 길이 합은 같고 남는 면은 변함 |
| P04 | 사분원 → 반원 | 바깥 반지름 `R`, 수평 반지름을 지름으로 한 안쪽 반원 `r=R/2` | `πR²/8` | `R+πR` | 외부 직선 하나와 안쪽·바깥 호가 남음 |
| P05 | 정사각형 → 사분원 | 한 변 `a`, 꼭짓점 중심 `R=a` 사분원을 내부에서 제거 | `a²−πa²/4` | `2a+πa/2` | 삭제된 정사각형 두 변 대신 호가 경계 |
| P06 | 정사각형 → 반원 | 한 변 `a`를 지름으로 하여 안쪽 반원 `r=a/2` 제거 | `a²−πa²/8` | `3a+πa/2` | 변 하나가 원호로 대체 |
| P07 | 부채꼴 → 작은 부채꼴 | 공통 중심 `0≤r<R`, `0<θ≤360°` | `(θ/360)π(R²−r²)` | `θ<360°: (θ/360)2π(R+r)+2(R−r)`; `θ=360°:2π(R+r)` (r=0은 안쪽 원호 없음) | 현재 ⑦의 고리 부채꼴과 수학 모델 공유 |

**제약·예외**

- P03은 두 작은 반원의 지름 길이 합이 바깥 큰 반원의 지름과 같은 **정확한 배치**다. 작은 반원 둘이 접하고, 남는 영역은 세 원호로 둘러싸인다. `r₁=0`/`r₂=0`으로 퇴화하면 별도 경계 상태이므로 처음에는 `r₁,r₂>0`으로 제한한다.
- P04는 반원 경계의 지름이 바깥 사분원의 가로 반지름과 정확히 일치한다. 작은 반원을 바깥 호 밖으로 나가게 끌 수 없다.
- P05/P06은 파낸 도형이 바깥 변과 **부분적으로 또는 전체로 접하는 홈**이므로 바깥 변 전체가 둘레에 남는다고 계산하지 않는다.
- P02에서 `d+r<R`인 동안 한 원이 다른 원 안에 완전히 들어 있으므로 `d`를 바꿔도 둘레/넓이는 일정하다. 경계 접촉 `d+r=R`의 모양은 추후 별도 고려.
- P07 `r=0`, `θ=360°`는 정확한 퇴화·완전 원 조건으로 처리한다. `θ=360°`에 사라지는 반지름 변 두 개를 둘레에 더하지 않는다.
- 개별 프리셋의 `R,a,θ,r,d,r₁` 기본값은 중앙/모바일 크기에 맞게 선택해도 되지만, SVG와 표시 수식은 **같은 정확한 값**으로 계산한다.

## 3. F01의 공통 애니메이션 — 모든 프리셋에 동작해야 한다

### 3.1 넓이 선택 후 ▶ 재생

1. **원본 전체 면**(큰 원/반원/사분원/정사각형/부채꼴)을 **빈 곳 없이 전체 색칠**하고 작은 내부 영역을 윤곽선으로만 표시한다.
2. 제거 대상 내부 영역을 다른 색으로 칠하고, 제거 전후의 **겹치는 경계 위치**를 명확히 보여준다.
3. **작은 도형을 오른쪽으로 실제 형태와 넓이를 유지한 채 꺼낸다.** 가운데 `−` 기호를 표시한다. 화면 왼쪽에서는 빈 영역/파인 홈이 생긴다. 작은 반원 둘(P03)은 두 조각을 함께 **겹치지 않도록** 오른쪽으로 이동한다.
4. **왼쪽 남은 면**과 **오른쪽 꺼낸 면**을 비교한다. 현재 예시에 따라 `큰 넓이−작은 넓이(들의 합)=남은 넓이`를 표현한다. 조각을 마음대로 늘리거나 색칠 면적만 숫자에 맞게 바꾸지 않는다.
5. `R/r/θ/d/r₁`를 변화시키면 바깥 면·제거 면·남은 면·면적식·라벨을 **현재 상태 기준으로 재계산**한다. 재생 중 상태 변경은 초기화 또는 안전한 재시작 처리한다.

### 3.2 둘레 선택 후 ▶ 재생

- 현재 **남은 도형만**의 실제 경계를 따라간다. 완전 고리는 바깥 원주+안쪽 원주, 반원 둘을 파낸 경우는 바깥 호+두 안쪽 호, 정사각형 홈은 남아 있는 직선+새로 생긴 호, 고리 부채꼴은 바깥 호+안쪽 호+끝의 두 직선을 추적한다.
- 보조선(원 중심과 연결한 점선, 원래 지름 중 경계에서 사라진 선, 분할선)은 둘레에 포함하지 않는다. 내부 구멍은 별도의 닫힌 경계로 포함한다.
- **기존 경계 추적 로직 재사용**하되, 이동 중 마커가 글씨를 가리지 않게 한다. 학생 UI에는 `개미`라는 단어를 표시하지 않는다.

### 3.3 선과 면

- 클릭한 **현재 프리셋**의 실제 원본 면, 제거 면, 남은 면과 최종 경계·보조선을 다른 색으로 구분한다.
- 반지름과 중심각을 선/각호 가까이에 정확히 배치한다. 중심각 수치는 작은 `arc` 근처, 반지름 선과 글씨가 분리되지 않게 한다.
- 넓이와 둘레 계산은 수학적으로 정확한 π 계수·정수·세로 분수. `6+9π/4`처럼 다른 항은 합산 표기하되 합쳐서 하나의 계수로 만들지 않는다.

## 4. F01 화면 배치·모바일 설계

- **상단 공통 버튼 4개 그대로**, 아래에 도형군 선택 줄·바깥 도형 선택 줄·필요 시 예시 이름과 이전/다음 버튼. 메뉴가 많아지면 선택 영역만 가로 스크롤, **수식/도형/페이지 본체는 가로 스크롤 없이**.
- 도형 애니메이션은 **왼쪽(큰 전체/파낸 뒤 남은 도형) → 가운데 `−` → 오른쪽(꺼낸 도형)** 흐름을 유지. 폰에서도 위아래 분리 방식으로 자동 변경하지 않는다. 작은 기기에서는 SVG `viewBox`와 라벨 위치/축척을 조정해 양쪽이 모두 보이게 한다.
- 안내 글씨는 왼쪽 큰 도형 안에 고정 배치하지 않고 **도형 경계 밖 안전 영역**에 표시. 조각이 빠져나갈 때 `R/r/θ`, `−`, 수식과 충돌하지 않는다.
- 수식은 **세로 높이를 확보**하여 `\\dfrac`가 실제 분수로 보이도록 렌더링; 내부 위아래 스크롤·숫자 입력 화살표가 생기지 않도록 한다.
- 각 선택/재생 버튼은 모바일에서 터치 가능한 크기(최소 44px)로 한다.

## 6. F01 완료 조건 — 7개를 하나의 변환군으로 평가

- [ ] 원·반원·사분원·정사각형·부채꼴 바깥 도형 선택이 되고, 원·정사각형을 재클릭하면 **그 모체의 다른 프리셋으로 순환**한다.
- [ ] P01~P07 전부에서 실제 채워진 전체 면→내부 면 제거→남은 면이 정확히 나온다. 작은 도형은 **오른쪽으로 빠져나가고 중간에 `−` 표시**.
