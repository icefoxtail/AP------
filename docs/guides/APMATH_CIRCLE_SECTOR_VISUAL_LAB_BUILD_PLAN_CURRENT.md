## 1. F01 ③~⑧ 일괄 구현 계약

**한 HTML, 하나의 기존 ⑦ 도형 변환 실험, 동일한 공통 UI**를 유지하고 ③~⑧을 한 배치로 확장한다. 유형당 새 HTML/새 메인 탭/새 재생 버튼 생성 금지.

상단 고정: **`선과 면 | 넓이 | 둘레 | ▶ 재생`**

- `넓이` → `▶ 재생`: 전체 면 먼저 채우기 → 제거 조각 강조 → 조각은 오른쪽으로 실제 도형의 크기와 모양을 유지해 분리 → 두 도형 사이에 `−` → 왼쪽은 파낸 자리가 진짜 투명하게 보이게.
- `둘레` → `▶ 재생`: 남은 도형의 실제 전체 경계를 추적. 분리된 두 영역/내부 구멍 경계도 빠짐없이 추적.
- `선과 면`: 남은 면, 제거 면, 원호, 현, 직선, 반지름·중심각 각호를 시각적으로 구별.
- 라벨: 왼쪽 `큰 도형`, 오른쪽 `작은 도형/꺼낸 조각`; 움직인 도형과 라벨·반지름이 함께 이동. `−`는 두 도형 사이 가운데, 글씨끼리·도형과 겹침 없음.
- 수식: 정확한 π 계수, 분수를 위아래 충분한 높이로 표시. 수식 영역 세로 스크롤 금지. 학생 UI에서 '개미', 저장, 진행률 금지.

### ③ 큰 반원 안에 작은 반원 두 개

- 큰 반원 반지름 `R`, 같은 지름 위 작은 두 반원의 반지름 `r₁`,`r₂`로 `r₁+r₂=R` 및 `r₁,r₂>0`.
- 남는 넓이 `S=πr₁r₂`.
- 남는 둘레 `L=2πR` = 큰 호 `πR` + 작은 호 `πr₁+πr₂`; 지름선 제외.
- 조절: `R` 및 `r₁/R` 비율. 작은 두 반원은 관계를 유지하며 함께 변하고, 분리될 때 오른쪽에 겹치지 않게 배치.
- 발견: 반지름의 합 일정일 때 둘레는 일정, 넓이는 달라짐.

### ④ 사분원 안의 반원

- 바깥 사분원 반지름 `R`, 바깥 사분원의 가로 반지름을 지름으로 한 내부 반원 `r=R/2`. 내부 반원은 실제 바깥 사분원에 포함.
- 남는 넓이 `S=πR²/8`.
- 남는 둘레 `L=R+πR` (바깥 사분원호 `πR/2` + 안쪽 반원호 `πR/2` + 남아 있는 직선 `R`).
- 발견: 작은 반원의 지름이었던 직선은 파낸 뒤 경계에서 사라짐.

### ⑤ 정사각형 안의 사분원

- 정사각형 한 변 `a`, 한 꼭짓점을 중심으로 반지름 `a`인 내부 90° 사분원을 제거.
- 남는 넓이 `S=a²−πa²/4`.
- 남는 둘레 `L=2a+πa/2` (남은 정사각형 변 두 개+사분원호).
- 변을 움직이면 사분원 반지름도 함께 변경. 제거된 두 변을 둘레에 더하지 않음.

### ⑥ 부채꼴에서 삼각형 빼기 — 활꼴

- 기본값: 반지름 `R=6cm`, 중심각 `90°`인 부채꼴 `OAB`. 삼각형 `OAB`를 제거하고 **현 AB와 호 AB로 감싼 활꼴**을 남김.
- 기본 넓이 `S=9π−18`, 둘레 `L=3π+AB`. 현의 길이는 실제 좌표로 산출하되, 중1 기본 해설에서 제곱근/피타고라스 계산을 강제하지 않음. 현 길이를 조건으로 제시하거나 기호 `AB`로 보존 가능.
- 중심각을 조절한다면 삼각형 면적과 현 길이를 일반 각도에 맞게 정확히 계산하는 별도 수학 모델이 있을 때만 허용. **기본 90° 고정이어도 충분**. 가짜 슬라이더 금지.
- 발견: **현은 직선, 호는 곡선**이며 제거 뒤 둘 다 경계가 됨.

### ⑦ 정사각형 안 정삼각형·부채꼴

- 정사각형 `ABCD` 한 변 `a`, 한 변 `AB`를 공유하여 내부에 정삼각형 `ABE` 정확히 작도. 중심 `A`, 반지름 `a`인 사분원호에서 `∠BAE=60°`, `∠BAD=90°`, `∠EAD=30°`.
- 정삼각형은 **보조 도형**이고 제거하는 것은 **30° 부채꼴 DAE**임을 표시. 정삼각형 전체를 빼는 것으로 오해하지 않게 할 것.
- 남는 넓이 `S=a²−πa²/12`, 남는 경계 길이 `L=4a+πa/6` (실제 제거된 원래 변과 새 경계 대응 검산 필수).
- 발견: 변 길이 = 반지름, 정삼각형 60°·정사각형 90° → 30° 부채꼴. 중앙의 작은 각호와 라벨 필수.

### ⑧ 반원에서 삼각형 빼기

- 기본 반원 지름 `AB=10cm` (`R=5`), 원호 위 점 `C`, `AC=6cm`, `BC=8cm`, `∠ACB=90°`로 정확히 배치. 원주각 정리 증명 요구 없음.
- 남는 넓이 `S=25π/2−24`, **남는 두 분리 영역의 경계 길이 합** `L=5π+14`.
- 삼각형 분리 후 양쪽에 남는 면 두 개를 **각각 별도의 색칠 영역**으로 표현하고 양쪽 경계 성분을 각각 추적. 지름 `AB`는 제거된 삼각형의 변이므로 남은 영역 둘레에 포함하지 않음.
- 발견: 원래 하나인 도형에서 삼각형 제거 뒤 **분리된 두 영역**이 남음.
