- 시험 88회(평가원 수능·모평 32회 + 교육청 고3 44회 + 고2 12회)의 문제·정답을 모두 받았고, 이 가운데 81회에서 분류표에 오른 문항은 **706문항**이다(2022~2027학년도 공통은 시험당 약 10문항, 2017~2021학년도 가·나형은 시험당 5~9문항 내외).

- 분류 방법: 모든 행을 잘라 낸 문항 그림을 직접 보고 분류했다(`review: image`). 키워드로만 분류한 행은 없다. 정답은 평가원 정답표(텍스트·이미지)와 EBSi 정답 이미지를 눈으로 옮긴 것이다.
