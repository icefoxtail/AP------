# Existing typed-v2 renderer reuse for a complete reviewed compact

This intake repairs a current image binding for explicitly selected middle-3
second-semester rows. It reuses published independent renderer evidence. It
does not issue native, semantic, mathematical, or difficulty approval.

## Authority and immutable inputs

The public input uses `archive-4slot-existing-typed-v2-renderer-input-v1`.
An independent root acceptance of the exact input SHA uses
`archive-4slot-existing-typed-v2-renderer-acceptance-v1` and the decision
`ACCEPT_EXISTING_TYPED_V2_RENDERER_FOUR_SLOT_REBIND`. Both assert zero new
semantic approvals, zero new math QA, and zero source changes.

The prior complete compact is read from its immutable commit/path, SHA-256,
and Git blob. Its entire item array, source header, reviewer, and evidence
remain unchanged. The original native four-slot reference must match that
compact's evidence reference. Every selected vector, term mapping, current
literal quote, source identity, and original native row is verified again
mechanically; a missing current quote is a rejection, never a guessed repair.

Every row must reference a published
`archive-reviewed-renderer-continuity-evidence-v1` document and the exact
original `archive-independent-current-renderer-review-v2` document it names.
The original reviewer must be independent of the native author. Selected
original native metadata rows and their original source hashes are checked.
The independent decision is `PASS_NARROW_RENDERER_SEMANTIC_PRESERVATION`, with
actual visual inspection and no new full math or metadata approvals.

## Finite rendering delta

The original full compact source must be the independent proof's prefigure
source. The entire selected current question must equal the independently
reviewed current question. The only changed keys may be `image` and
`imageSize`, and `image` must change. Stem, choices, answer, solution, and all
producer fields therefore remain exact. The actual before/current Git blobs,
raw hashes, field presence hashes, all referenced assets, raster digest, and
complete asset count must match the published evidence. Unchanged companion
solution images are checked too.

At issuance the current source file must equal the accepted input source and
HEAD. Runtime may survive a later source-container change outside the selected
rows only if the complete identity partition remains exact and every selected
whole question and current asset is still exact. The unchanged file header is
not used to approve another row.

## Scope and output

`selected` and `untouched` form the complete canonical source denominator.
Only selected rows get a new renderer receipt. The output preserves the full
compact and appends `currentRendererRebind`; it never converts the full compact
to the C public-partial or private-partial schema.

The receipt schema is `archive-4slot-existing-typed-v2-renderer-receipt-v1` in
`archive/data/item-4slot-renderer-receipts/v1/`. The descriptor schema is
`archive-4slot-existing-typed-v2-renderer-binding-v1`. The importer requires the
explicit original compact SHA, rejects concurrent changes or conflicting
receipts, and supports byte-identical replay.

The builder rederives the entire descriptor and receipt before cache reuse.
It bypasses the old student-payload comparison only for an exact selected
receipt row with the matching before/current whole-question hashes. Every
identity, slot, asset, explicit hold, and all other row checks stay active.
Selected runtime rows say `SCOPED_REVIEWED_RENDERER` and carry the exact typed
receipt path/SHA; they never claim `UNCHANGED_STUDENT_PAYLOAD`. The Consumer
recognizes this binding only with the strict receipt type/path/hash and the
middle-3 second-semester scope. Relabeling it as an older binding while keeping
the receipt is rejected. Removing the compact descriptor restores the old
stale-payload behavior rather than promoting the row.

The initial approved package has 3 full compacts and 69 original rows:
5 renderer rebindings, 58 existing registered rows preserved, and 6 existing
stale rows preserved. The C42 intake, B private append, original source files,
dictionary, canonical identity, original native evidence, and all approvals
are unchanged. Local tests and derived Consumer results do not claim main
registration or Pages deployment.
