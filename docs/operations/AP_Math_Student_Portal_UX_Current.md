대상: `apmath/student/`, 학생이 사용하는 과제·플래너, 실험실 진입·복귀.

## 정보 구조와 이동 계약

홈 첫 화면에는 **내 시험지 / 도형·수학 실험실 / 학습 플래너 / 과제**가 모두 보인다. 휴대폰에서는 2×2, 넓은 화면에서는 4열이다. 시험지·기록 목록보다 먼저 배치하고, 홈의 최근 시험지는 최신 한 건만 간결하게 표시한다. 상세 학습 기록·클리닉·수업자료 목록은 홈에서 미리 불러오거나 길게 쌓지 않는다.

공통 메뉴는 **홈 / 시험지 / 실험실 / 플래너 / 더보기**다. 모바일 하단에 고정하고 PC에서는 상단에 둔다. `apmath/js/student-navigation.js`와 `apmath/css/student-navigation.css`가 포털, 과제, 플래너, 실험실 허브·장면, 시험지·정답·해설·클리닉 뷰어에서 같은 메뉴를 제공한다. 인쇄에는 나오지 않으며 제출 바·타이머·사진 조작을 가리지 않는다.

`더보기`는 학습 기록, 오답 클리닉, 수업자료 오답, 과제를 각각 연결한다. 포털 경로의 `view=home|exams|labs|planner|more|history|clinic|materials|assignments`를 복원하므로 하위 화면에서 원하는 기능으로 곧바로 돌아올 수 있다. 브라우저 뒤로 가기는 화면과 같은 입력 항목의 메모리 초안을 복원한다. 외부 페이지로 떠날 때는 미저장 작업 경고를 유지한다.

학생의 실험실 진입은 `playground/next/?portal=1`로 실제 실험실 목록을 바로 연다. 학년 해시와 읽기 전용 미리보기 메타데이터를 보존한다. 독립 방문자의 Universe 입구는 그대로 유지한다.

선생님 미리보기에서도 네 핵심 기능과 모든 더보기 항목을 표시한다. 시험지·과제 내용·학습 기록은 기존 읽기 전용 권한으로 확인하고 공개 실험실은 이용할 수 있다. 플래너·개인 클리닉·수업자료 오답은 학생 인증이 필요한 현행 API 때문에 내용을 조회할 수 없다는 사유를 별도 화면에 표시한다. 미리보기에서 저장된 학생 PIN을 대신 사용하거나 학생 세션을 만들지 않는다. 직접 하위 URL을 열어도 동일한 제한을 적용한다.

내비게이션 문맥은 배포 경로별 sessionStorage의 `{preview, studentId}` 메타데이터만 사용한다. 권한을 부여하지 않으며 PIN·토큰을 저장·전달하지 않는다. `studentReturnTo`는 현재 배포 프로젝트의 정확한 학생포털 경로만 허용한다. 따라서 GitHub Pages `/AP------/`에서도 미리보기 복귀가 유지되고 외부 주소·다른 프로젝트로 우회하지 않는다.

PWA 버전은 `2026.11.11.4`이며 HTML, manifest, version JSON, service worker와 정적 리소스 query를 함께 올린다.

## 보호할 기능 계약

- Worker·인증·학생 권한·실제 학생 데이터·시험지/정답/해설의 수학적 내용을 디자인 변경으로 수정하지 않는다.
- 서버 `/student-portal/exams` 목록이 시험지의 정본이다. 같은 날 재출제된 다른 assignment ID를 합치지 않는다.
- OMR 요청은 기존 `wrong_ids` 계약을 사용하고, 표시 점수는 서버 응답을 그대로 기록한다. 예상 점수는 문항 수 기준 예상임을 표시한다.
- 이미 제출된 OMR은 재제출/수정할 수 없다. 상태 미확인·취소·대체·열람 전용은 입력을 막고 열람 권한은 기존대로 유지한다.
- 동일 시험 제출 중 재진입해도 두 번째 POST를 보내지 않는다. 실패 시 선택을 보존하고 다시 제출할 수 있게 한다.
- 선생님 미리보기는 UI와 `apiPost` 양쪽에서 쓰기를 금지한다.
- async 요청은 인증 세대·resource sequence·화면 세대·draft identity를 확인한다. 이전 학생이나 이전 자료의 응답이 현재 화면/선택을 덮지 않아야 한다.
- 같은 입력 항목으로 되돌아가면 메모리의 선택을 보존한다. 로그아웃·학생 전환은 데이터를 지운다. 앱 재시작 후 초안 복원은 제공하지 않는다.
- PWA 자동 업데이트는 입력·미저장 선택·전송 중 상태를 보호한다. 앱 버전, manifest, `student-version.json`, service worker 및 정적 리소스 query를 함께 올린다.
- 플래너의 잘못된 링크·PIN 확인 화면에서는 편집 동작을 노출하지 않는다. 모바일 추가 버튼은 정상 플래너가 열린 뒤에만 표시하며, 공통 버튼 스타일이 이 기본 숨김 상태를 덮지 않아야 한다.
- 플래너는 같은 모바일/PC 레이아웃 안의 크기 변화에서 입력 DOM을 유지한다. 768px 경계를 넘나들 때에도 작성 중인 빠른 추가 제목·과목을 보존한다. 높이 변화, PC 폭 변경, 모바일 왕복 뒤 정확한 제목·과목·날짜로 한 번만 저장되는지 실제 브라우저에서 확인한다.
- 플래너의 공통 메뉴로 이동할 때 작성 중인 빠른 추가 제목이 있으면 저장하지 않고 이동할지 확인한다. 취소하면 기존 제목·과목과 현재 화면을 유지한다. 이 보호는 공통 메뉴 이동에 적용하며 브라우저 종료 뒤 초안 복원을 뜻하지 않는다.
- Archive 원본/MIXED 복습·PDF·snapshot 복원 계약은 기존 엔진을 그대로 사용한다. 원문이 없는 시험은 파일이 없는 이유를 안내하고 임의 내용을 만들지 않는다.

## 검증 방법

정적/계약 회귀:

```sh
node --test tests/student-portal-*.test.js tests/apmath-student-teacher-preview.test.js tests/apmath-dark-mode-modals.test.js
node tools/run-tests.js
```

실제 Chromium:

```sh
NODE_PATH=/path/to/playwright/node_modules node tests/student-portal-ux-browser.cjs --output=/tmp/student-portal-ux
```

`.github/workflows/student-portal-ux-browser.yml`은 정확한 PR head와 baseline을 별도 checkout한다. 실제 제품 HTML에 합성 API 응답을 연결하며 함수 교체나 로그인 화면 숨김으로 제품 동작을 대체하지 않는다. 사진 업로드·OMR POST도 합성 API만 사용한다. 결과는 screenshot/report artifact에 남으며 원시 캡처·로그를 Git에 커밋하지 않는다.

대표 화면 폭은 360/390, 태블릿 800·1280, PC 1440이며 실험실 헤더는 320도 확인한다. 정상/빈 목록/통신 실패/늦은 응답/teacher preview/unknown·cancelled·replaced·review-only/원문 없음/legacy MIXED를 구분한다. 새 결과 화면, 번호 선택, 제출 payload, 서버 점수, 뒤로가기, 모달·사진·타이머 동작도 확인한다.

추가 `tests/student-portal-accessibility-browser.cjs`는 변경하지 않은 전체 Worker를 격리된 D1에서 실행한다. 합성 학생과 담당/비담당 교사를 만들고 실제 이름·PIN 인증, 교사 세션과 권한 검증, 모바일 기능 노출·이동, OMR·플래너·과제 흐름을 검사한다. API 성공 응답을 가짜로 만드는 검사와 구분한다. 실행에는 Playwright, esbuild, Miniflare가 필요하며 CI가 동일 버전을 설치한다. 운영 DB에 검수 데이터를 만들지 않는다.

인증이 필요한 합성 동작 검증과 실제 운영 계정 검증을 혼동하지 않는다. 운영에서는 배포 SHA, 리소스 버전/내용, 공개 로그인·하위 공개 화면을 실제 브라우저로 확인한다. 학생 데이터에 테스트 제출을 만들지 않는다.

## Claude Code / Impeccable 최종 미감 검수

최신 main에서 저장소의 Impeccable 스킬을 읽고 시작한다. 이번 화면의 기준은 **네 핵심 기능이 첫 화면에 보이는 짧은 흐름, APMS 웜 체계, 모바일에서 한눈에 읽히는 상태와 행동**이다.

검토할 부분은 360/390px의 정보 밀도·줄바꿈, 800px 카드/관계 정보 배치, 1280/1440px 여백·카드 균형, 제출 전후 버튼 위계, 클리닉/기록의 긴 목록, 플래너 다크 모드, Universe 복귀 헤더다. 스타일을 다듬더라도 위 보호 계약과 실제 검증 분모를 유지한다. 변경 후 관련 브라우저 흐름을 다시 실행하고 자신의 PR·배포 근거를 남긴다.

사용 흐름을 먼저 검증한 뒤 간격·글자 크기·터치 영역을 정리한다. 실제 완료 SHA·CI·배포 결과는 PR 및 최종 보고에서 확인하며, 이 문서는 실행하지 않은 검사에 PASS를 부여하지 않는다.

운영 허브를 브라우저 확대 상태의 340 CSS px 폭으로 확인했을 때, `AP Math 실험실` 이름의 끝 글자가 다음 줄로 내려갔다. 이 좁은 폭의 헤더 줄바꿈을 다듬고, 실험실 수업 모드·테마 아이콘은 실제 터치 환경에서 확장된 터치 영역까지 확인한다. 기존 board/paper 테마와 수학 무대의 의미색은 유지한다.

GPT의 구현·검수·운영 반영을 완료한 뒤 Claude Code가 독립적으로 최종 미감을 검수한다. 후속 미감 검토를 기다리며 기능 수정이나 운영 검증을 미루지 않는다.
