# 2022 금당고 2학기 기말 q13 — 학생용 개선 해설

- 판정: UPGRADE
- 원문 핵심: \(u=-x>0\)에서 \(m=-\frac{u-1}{u(u+1)}\)라고 한 뒤, 이유 없이 \((3-2\sqrt2)-\frac{u-1}{u(u+1)}=\frac{(3-2\sqrt2)(u-1-\sqrt2)^2}{u(u+1)}\)를 사용.
- 막힘: 갑자기 완전제곱이 등장하는 이유와 양 끝 경계 기울기 포함 여부를 학생이 확인하기 어렵다.
- 원문 답: ①, \(-1\le m<-3+2\sqrt2\).

## 풀이 — 각 구간에서 교점이 **생기는** 기울기부터 찾기

직선 \(y=mx\)가 곡선 위 \((x,y)\)를 지나려면

\[
y=mx.
\]

따라서 \(x\ne0\)에서는

\[
m=\frac yx
\]

가 된다. \(x=0\)에서는 원래 곡선의 점이 \((0,-1)\)인데 직선의 점은 \((0,0)\)이므로 교점이 없다.

**① \(0<x<1\)**

\[
|x|=x,\qquad |x-1|=1-x,
\]

\[
y=\frac{x-1}{1-x}=-1,
\]

\[
m=\frac yx=-\frac1x.
\]

\(0<x<1\)이므로 \(1/x>1\)이고

\[
\boxed{m<-1}.
\]

\(m=-1\)은 \(x=1\)이어야만 하는데 \(x=1\)은 정의역에서 빠진다.

**② \(x>1\)**

\[
|x|=x,\qquad |x-1|=x-1,
\]

\[
y=\frac{x-1}{x-1}=1,
\]

\[
m=\frac1x.
\]

따라서

\[
\boxed{0<m<1}.
\]

**③ \(x<0\)**

음수 \(x\) 대신 양수 \(u=-x>0\)를 사용한다.

\[
|x|=-x=u,\qquad |x-1|=1-x=1+u,
\]

\[
y=\frac{u-1}{u+1},
\]

\[
m=\frac{y}{x}
=\frac{(u-1)/(u+1)}{-u}
=\frac{1-u}{u(u+1)}.
\]

분모 \(u(u+1)>0\)이므로 \(m\)의 최솟값을 확인하자.

\[
\begin{aligned}
m-(-3+2\sqrt2)
&=\frac{1-u}{u(u+1)}+3-2\sqrt2\\
&=\frac{1-u+(3-2\sqrt2)u(u+1)}{u(u+1)}\\
&=\frac{(3-2\sqrt2)u^2+(2-2\sqrt2)u+1}{u(u+1)}\\
&=\frac{\{(\sqrt2-1)u-1\}^2}{u(u+1)}\\
&\ge0.
\end{aligned}
\]

마지막 식은 **분자는 제곱이라 0 이상**, 분모는 양수이기 때문이다. 등호는

\[
(\sqrt2-1)u-1=0
\iff u=\frac1{\sqrt2-1}
=\sqrt2+1
\]

일 때 실제로 성립한다. 따라서 최솟값은 **포함**된다.

또 \(u\to0^+\)일 때 \(m=\frac{1-u}{u(u+1)}\to+\infty\)이고 \(m\)은 \(u>0\)에서 끊기지 않으므로, 이 구간에서 얻는 기울기는

\[
\boxed{m\ge-3+2\sqrt2}.
\]

세 구간을 합하면 교점이 생기는 기울기는

\[
m<-1\quad\text{또는}\quad m\ge-3+2\sqrt2.
\]

문제는 **교점이 없어야** 하므로 그 사이를 택한다.

\[
\boxed{-1\le m<-3+2\sqrt2}.
\]

정답은 **①**.

검산: \(m=-1\)은 첫 구간의 끝점 \(x=1\)이 제외되어 교점이 없고, \(m=-3+2\sqrt2\)는 위에서 등호가 성립해 실제 교점이 있으므로 제외된다.
