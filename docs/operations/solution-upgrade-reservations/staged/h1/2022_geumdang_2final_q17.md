# 2022 금당고 2학기 기말 q17 — 학생용 개선 해설

- 판정: UPGRADE
- 원문 핵심: \(x=\frac{y}{y-2}\), \(w=y+t\), \(R(y)=\frac{2(y^2-y-1)}{y-2}\), \(T(y)=\sqrt{R(y)}-1-y\) 등을 도입하고 증가·감소를 비교.
- 막힘: 복잡한 치환과 새로운 함수의 범위 추론이 연속으로 등장하지만, 이 문제는 **그래프가 각각 감소/증가한다는 사실과 왼쪽 끝점에서의 높이 비교**만으로 해결할 수 있다.
- 원문 답: ⑤, 3.

## 풀이 — 오른쪽 교점 하나, 왼쪽 교점 하나인지 확인하기

첫 번째 함수는 식을 먼저 나누어

\[
\begin{aligned}
y&=\frac{2x}{x-1}\\
&=\frac{2(x-1)+2}{x-1}\\
&=2+\frac2{x-1}
\end{aligned}
\]

로 쓴다.

이 그래프는 \(x=1\)을 기준으로 **왼쪽 가지와 오른쪽 가지**로 나뉘며, 각 가지에서 \(x\)가 증가하면 \(y\)가 감소한다.

두 번째 함수

\[
y=\sqrt{x-2t}-t,\qquad x\ge2t
\]

는 \(x\)가 증가하면 \(y\)가 증가한다.

따라서 감소하는 그래프와 증가하는 그래프는 \(x<1\), \(x>1\)의 각 부분에서 **많아야 한 번** 만난다.

**① 오른쪽 가지 \(x>1\)에서는 교점이 항상 하나**

\(t<\frac12\)일 때 \(x\to1^+\)이면 유리함수는 \(+\infty\)로 올라가지만 무리함수는 유한한 값을 갖는다. 반면 \(x\to+\infty\)에서는

\[
2+\frac2{x-1}\to2,\qquad
\sqrt{x-2t}-t\to+\infty
\]

이므로 대소가 뒤바뀌어 한 번 만난다.

\(t\ge\frac12\)일 때 두 번째 함수의 시작점은 \(x=2t\ge1\)이다. \(t>\frac12\)이면

\[
\begin{aligned}
\frac{2(2t)}{2t-1}-(-t)
&=\frac{4t}{2t-1}+t\\
&=\frac{t(2t+3)}{2t-1}>0,
\end{aligned}
\]

즉 시작점에서는 유리함수가 더 위에 있고, \(x\to+\infty\)에서는 무리함수가 더 위에 있으므로 한 번 만난다. \(t=\frac12\)도 시작점 \(x=1\)에서 유리함수가 정의되지 않지만 \(x\to1^+\)에서 무한히 커져 똑같이 한 번 만난다.

그러므로 **서로 다른 두 교점**이 되려면 왼쪽 가지 \(x<1\)에 교점이 정확히 하나 더 있어야 한다.

**② 왼쪽 가지에 교점이 생길 조건**

무리함수는 \(x=2t\)부터 시작하므로, 왼쪽 가지와 겹치려면

\[
2t<1\iff t<\frac12
\]

가 필요하다.

이때 \(x\)가 \(2t\)에서 \(1\)의 왼쪽으로 움직이면 첫 그래프는 감소하여 \(-\infty\)로 내려가고 두 번째 그래프는 증가한다. 따라서 **시작점에서 첫 그래프가 같거나 더 높아야** 왼쪽 교점이 한 번 생긴다.

\(x=2t\)에서 두 그래프의 높이는 각각

\[
y_1=\frac{2(2t)}{2t-1}=\frac{4t}{2t-1},\qquad
y_2=\sqrt{2t-2t}-t=-t.
\]

따라서

\[
\begin{aligned}
y_1\ge y_2
&\iff \frac{4t}{2t-1}\ge-t\\
&\iff \frac{4t}{2t-1}+t\ge0\\
&\iff \frac{4t+t(2t-1)}{2t-1}\ge0\\
&\iff \frac{t(2t+3)}{2t-1}\ge0.
\end{aligned}
\]

이미 \(t<\frac12\)이므로 분모 \(2t-1<0\). **음수를 곱하면 부등호가 뒤집힌다.**

\[
\begin{aligned}
\frac{t(2t+3)}{2t-1}\ge0
&\iff t(2t+3)\le0\\
&\iff -\frac32\le t\le0.
\end{aligned}
\]

양 끝점도 포함된다. 그때는 \(x=2t\)인 **무리함수의 시작점 자체**가 왼쪽 교점이 된다.

따라서

\[
M=0,\qquad m=-\frac32,
\]

\[
M-2m=0-2\left(-\frac32\right)=\boxed3.
\]

정답은 **⑤**.

검산: \(t=0\)일 때 \(x=0\)이 왼쪽 교점, \(t=-\frac32\)일 때 \(x=-3\)이 왼쪽 교점이다. 두 경우 모두 오른쪽 교점은 하나 더 있으므로 경계가 포함된다.
