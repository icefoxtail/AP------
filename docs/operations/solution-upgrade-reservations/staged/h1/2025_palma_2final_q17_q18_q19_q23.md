## 17번 — 일대일대응에서 왜 \(b\ge1\)인가?

- 임시 식별: \`25_팔마고_2학기_기말_고1_기출.js@ce814b292be81f43fa76ff4d33d1b707af52a098#17\`
- 문제: \(f(x)=x+c\;(x<b)\), \(f(x)=ax^2-2ax-3\;(x\ge b)\)가 실수 전체에서 실수 전체로의 일대일대응. 가능한 \(b\)의 최솟값을 \(t\)라 할 때 \(b=t\)에서 \(a+c\) 구하기.
- 원본 정답: ①, \(a+c=-4\).
- 개선 근거: 기존 해설의 \`a>0이고 b≥1이어야 한다\`는 단계에서 **\(a>0\)인 이유(위로 무한한 치역)** 와 **\(b\ge1\)인 이유(꼭짓점 양옆의 중복)** 가 한 문장으로 묶여 있음. 다음 식 \(f(1)=1+c\)도 경계 치역 연결 논리가 필요함.

### 제안 학생용 solution

\(x<b\)에서는 \(f(x)=x+c\)이므로 이 부분의 함숫값은

\[
f(x)<b+c
\]

이고 치역은 \((-\infty,b+c)\)이다.

전체 공역이 실수 전체이므로 나머지 \(x\ge b\) 부분에서 \(b+c\) 이상의 모든 값이 나와야 한다.

\[
\begin{aligned}
f(x)&=ax^2-2ax-3\\
&=a(x^2-2x)-3\\
&=a\{(x-1)^2-1\}-3\\
&=a(x-1)^2-a-3.
\end{aligned}
\]

\(x\)가 무한히 커질 때 이 식의 값도 무한히 커져야 하므로 \(a>0\)이다.

또 \(x\ge b\)에서 **같은 함숫값을 두 번 만들면 안 된다.** 이차함수의 꼭짓점은 \(x=1\)이다.

만약 \(b<1\)이면 \(0<h<1-b\)인 양수 \(h\)를 잡을 수 있다. 이때 \(1-h\ge b\), \(1+h\ge b\)인데

\[
\begin{aligned}
f(1-h)&=a(-h)^2-a-3=ah^2-a-3,\\
f(1+h)&=a(h)^2-a-3=ah^2-a-3.
\end{aligned}
\]

서로 다른 입력 \(1-h\), \(1+h\)의 함숫값이 같아져 일대일이 아니다. 따라서

\[
b\ge1.
\]

\(a>0,\ b\ge1\)이면 \(x\ge b\)에서 오른쪽 이차함수는 증가하므로 이 부분의 치역은 \([f(b),\infty)\)이다.

앞쪽 치역 \((-\infty,b+c)\)와 **겹치거나 비는 값 없이** 실수 전체를 만들려면

\[
f(b)=b+c
\]

이어야 한다.

\(b\ge1\)이므로 가능한 최솟값은 \(t=1\)이다. 실제로 \(b=1\)에서 \(a>0\), \(c=-a-4\)로 놓으면 위 조건을 만족하므로 최솟값이 가능하다.

이제 \(b=1\)을 대입한다.

\[
\begin{aligned}
f(1)&=a-2a-3=-a-3,\\
f(1)&=1+c,\\
-a-3&=1+c,\\
a+c&=\boxed{-4}.
\end{aligned}
\]

### 독립 확인

예를 들어 \(a=1,\ c=-5,\ b=1\)이면 앞쪽 치역은 \((-\infty,-4)\), 뒤쪽은 \([-4,\infty)\)로 겹치거나 빠지는 값 없이 실수 전체가 된다.

## 18번 — 곡선의 넓이가 왜 평행사변형 넓이가 되는가?

- 임시 식별: \`25_팔마고_2학기_기말_고1_기출.js@ce814b292be81f43fa76ff4d33d1b707af52a098#18\`
- 원본 정답: ③, \(17\).
- 개선 근거: 기존 해설의 \`곡선 사이의 띠를 같은 넓이가 되도록 잘라 붙이면 평행사변형 PABQ와 같은 넓이\`는 **어느 부분이 같아서 상쇄되는지** 설명되지 않음. 도형 계산도 꼭짓점과 바깥 삼각형의 대응을 구체화할 필요가 있음.
- 원본 그림 확인 필요: 이 초안은 현행 문제/해설의 \(P,A,B,Q,O\) 좌표를 이용하며 시각 검수는 NOT_RUN. 추가 SVG는 생성하지 않음.

### 제안 학생용 solution

두 그래프의 시작점과 직선과의 교점을 정리하면

\[
\begin{aligned}
O&=(0,0),\\
P&=(0,2) &&\bigl(f(0)=\sqrt0+2=2\bigr),\\
Q&=(3,0) &&\bigl(g(3)=\sqrt{3-3}=0\bigr),\\
A&=(4,4),\\
B&=(7,2).
\end{aligned}
\]

두 무리함수를 비교하자.

\[
\begin{aligned}
f(x)&=\sqrt x+2,\\
g(x+3)&=\sqrt{(x+3)-3}=\sqrt x=f(x)-2.
\end{aligned}
\]

따라서 \(f\)의 곡선 \(P\to A\)를 **오른쪽 3, 아래 2**만큼 옮기면 \(g\)의 곡선 \(Q\to B\)와 정확히 겹친다.

그러므로 곡선 \(PA\)와 선분 \(PA\) 사이의 휘어진 부분, 곡선 \(QB\)와 선분 \(QB\) 사이의 휘어진 부분은 평행이동 관계라 **넓이가 같다.** 구하는 영역에서는 앞쪽 휘어진 부분을 더하고 뒤쪽 휘어진 부분을 빼므로 서로 상쇄된다.

결국 구하는 넓이는 곡선 대신 선분을 쓴 오각형 \(PABQO\)의 넓이와 같다. 이를

\[
\text{오각형 }PABQO
=\text{평행사변형 }PABQ+\triangle POQ
\]

로 나누어 계산한다.

먼저 \(PABQ\)에서

\[
\begin{aligned}
\overrightarrow{PA}&=(4,2),&
\overrightarrow{QB}&=(4,2),\\
\overrightarrow{PQ}&=(3,-2),&
\overrightarrow{AB}&=(3,-2)
\end{aligned}
\]

이므로 마주 보는 변이 각각 평행한 평행사변형이다.

이를 둘러싼 \(0\le x\le7,\ 0\le y\le4\) 직사각형의 넓이는

\[
7\times4=28
\]

이다. 직사각형의 네 귀퉁이에 있는 직각삼각형 중 두 개는 가로 4, 세로 2이고 나머지 두 개는 가로 3, 세로 2이다.

\[
\begin{aligned}
\text{바깥 네 삼각형 넓이}
&=2\left(\frac12\times4\times2\right)
+2\left(\frac12\times3\times2\right)\\
&=2\times4+2\times3\\
&=8+6=14.
\end{aligned}
\]

따라서

\[
\text{평행사변형 }PABQ=28-14=14.
\]

또 \(PO=2,\ OQ=3\)이므로

\[
\triangle POQ=\frac12\times2\times3=3.
\]

구하는 넓이는

\[
14+3=\boxed{17}.
\]

### 독립 확인

좌표를 이용하면 평행사변형의 두 변을 \((4,2)\), \((3,-2)\)로 볼 수 있고, 실제 넓이 \(14\)와 일치한다. 곡선과 선분 사이의 상쇄를 설명하는 그림은 별도 엔진 시각 검수 대상이다.

## 19번 — 서로 다른 네 근임을 확인하기

- 임시 식별: \`25_팔마고_2학기_기말_고1_기출.js@ce814b292be81f43fa76ff4d33d1b707af52a098#19\`
- 원본 정답: ①, 모든 서로 다른 실근의 합 \(-2\).
- 개선 근거: 기존 해설은 \`네 근은 서로 다르므로\`라고만 하고 **두 번째 이차방정식의 실제 근·서로 다름**을 확인하지 않음. 근의 합도 등식으로 이어 주면 자연스러움.

### 제안 학생용 solution

그래프에서 \(f(x)=0\)의 해는 \(-2,1\)이고 \(f(0)=-2\)이므로

\[
\begin{aligned}
f(x)&=a(x+2)(x-1),\\
-2=f(0)&=a\cdot2\cdot(-1)=-2a,\\
a&=1.
\end{aligned}
\]

따라서

\[
f(x)=(x+2)(x-1)=x^2+x-2.
\]

\((f\circ f)(x)=0\)은 \(f(f(x))=0\)이다. \(f(t)=0\)이 되는 \(t\)가 \(-2\) 또는 \(1\)이므로

\[
f(x)=-2\quad\text{또는}\quad f(x)=1
\]

을 풀면 된다.

① \(f(x)=-2\)일 때,

\[
\begin{aligned}
x^2+x-2&=-2,\\
x^2+x&=0,\\
x(x+1)&=0,\\
x&=0\quad\text{또는}\quad x=-1.
\end{aligned}
\]

② \(f(x)=1\)일 때,

\[
\begin{aligned}
x^2+x-2&=1,\\
x^2+x-3&=0,\\
x&=\frac{-1\pm\sqrt{1+12}}2
=\frac{-1\pm\sqrt{13}}2.
\end{aligned}
\]

이 두 근은 \(\sqrt{13}>0\)이므로 서로 다르다. 또한 \(x=0,-1\)에서는 \(x^2+x-3=-3\ne0\)이므로 ①의 근과 겹치지도 않는다.

따라서 서로 다른 네 실근의 합은

\[
\begin{aligned}
0+(-1)
+\frac{-1+\sqrt{13}}2
+\frac{-1-\sqrt{13}}2
&=-1+\frac{-2}2\\
&=-1-1\\
&=\boxed{-2}.
\end{aligned}
\]

### 독립 확인

②의 두 근의 합은 \(-1\), ①의 두 근의 합도 \(-1\). 두 근 집합은 겹치지 않아 전체 합이 \(-2\)이다. 원본 그래프의 세 점 판독은 최종 시각 검수 필요.

## 23번 — 판별식과 근의 조건을 한 번에 보이기

- 임시 식별: \`25_팔마고_2학기_기말_고1_기출.js@ce814b292be81f43fa76ff4d33d1b707af52a098#23\`
- 원본 정답: \(\dfrac13\le k<\dfrac{11}{6}\).
- 개선 근거: 기존 해설은 판별식, 근의 합·곱, 두 근의 부호를 순서대로 써서 학생에게 추상적임. **교점의 \(y\)좌표 자체를 근의 공식으로 표현**하면 \(y\ge0\) 제한과 서로 다른 두 점 조건이 직접 연결됨.

### 제안 학생용 solution

무리함수 위의 점은

\[
y=\sqrt{2-3x}
\]

이므로 반드시 \(y\ge0\)이다. 양변을 제곱하면

\[
\begin{aligned}
y^2&=2-3x,\\
3x&=2-y^2,\\
x&=\frac{2-y^2}{3}.
\end{aligned}
\]

이 값을 직선 \(y=-\dfrac12x+k\)에 대입한다.

\[
\begin{aligned}
y&=-\frac12\cdot\frac{2-y^2}{3}+k,\\
6y&=-(2-y^2)+6k,\\
6y&=y^2-2+6k,\\
y^2-6y&=2-6k,\\
(y-3)^2-9&=2-6k,\\
(y-3)^2&=11-6k.
\end{aligned}
\]

따라서 교점의 \(y\)좌표 후보는

\[
y=3+\sqrt{11-6k}
\quad\text{또는}\quad
y=3-\sqrt{11-6k}
\]

이다.

**서로 다른 두 점**이 되려면 두 값이 달라야 하므로

\[
\begin{aligned}
\sqrt{11-6k}&>0,\\
11-6k&>0,\\
k&<\frac{11}{6}.
\end{aligned}
\]

또 두 점 모두 무리함수 위에 있으려면 **두 \(y\)좌표가 모두 0 이상**이어야 한다. 큰 값은 이미 양수이므로 작은 값만 확인한다.

\[
\begin{aligned}
3-\sqrt{11-6k}&\ge0,\\
\sqrt{11-6k}&\le3,\\
11-6k&\le9,\\
-6k&\le-2,\\
k&\ge\frac13.
\end{aligned}
\]

두 조건을 합치면

\[
\boxed{\frac13\le k<\frac{11}{6}}.
\]

\(k=\dfrac13\)에서는 \(y=0,6\)으로 서로 다른 두 교점이므로 포함한다. \(k=\dfrac{11}{6}\)에서는 \(y=3\) 한 값만 나와 제외한다.

### 독립 확인

\(y\ge0\)일 때 \(x=(2-y^2)/3\)은 각 \(y\)에 대해 하나의 \(x\)만 결정하므로, 서로 다른 두 \(y\)값은 서로 다른 두 교점과 대응한다. 제곱 과정에서 사용한 \(y\ge0\) 제한도 위에서 확인하였다.
