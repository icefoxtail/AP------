# 2022 금당고 2학기 기말 q10 — 학생용 개선 해설

- 판정: UPGRADE
- 원문 핵심: "사용할 상자를 ... _5C_3=10" 뒤 곧바로 "3^5−_3C_12^5+_3C_21^5=150".
- 막힘: 포함배제의 덧셈·뺄셈 이유가 없어서, 왜 96을 빼고 3을 다시 더하는지 알기 어렵다.
- 원문 답: ③, 1500.

## 풀이 1 — 공의 개수로 나누어 세기

상자 5개 중 **공이 들어갈 상자 3개**를 먼저 고른다.

\[
{}_5C_3=\frac{5\times4\times3}{3\times2\times1}=10.
\]

이제 선택한 3개 상자가 모두 비지 않으면서 공 5개가 들어가는 방법을 구한다.

세 상자에 든 공의 개수는 양의 정수이고 합은 5이므로, 순서를 제외하면

\[
3+1+1=5,\qquad 2+2+1=5
\]

두 경우뿐이다.

**① (3개, 1개, 1개)**

- 공 3개가 들어갈 상자를 선택: \(3\)가지.
- 서로 다른 공 5개 중 그 상자에 들어갈 3개를 선택: \({}_5C_3=10\)가지.
- 남은 서로 다른 공 2개를 나머지 서로 다른 상자 2개에 배치: \(2!=2\)가지.

\[
3\times{}_5C_3\times2!
=3\times10\times2=60.
\]

**② (2개, 2개, 1개)**

- 공 1개가 들어갈 상자를 선택: \(3\)가지.
- 그 상자에 들어갈 공을 선택: \(5\)가지.
- 남은 4개 중 첫 번째 두 공 상자에 들어갈 2개를 선택: \({}_4C_2=6\)가지.
- 마지막 공 2개의 위치는 자동으로 결정된다.

\[
3\times5\times{}_4C_2
=3\times5\times6=90.
\]

따라서 공이 들어갈 상자 3개를 고정했을 때

\[
60+90=150,
\]

처음에 상자 3개를 고르는 경우까지 곱하면

\[
{}_5C_3(60+90)
=10\times150
=\boxed{1500}.
\]

정답은 **③**.

## 풀이 2 — 원래 해설의 포함배제를 이해하고 싶다면

선택한 세 상자에 서로 다른 공 5개를 자유롭게 넣으면 \(3^5=243\)가지이다.

이 중 비어 있는 상자가 **적어도 하나** 생긴 경우를 빼야 한다.

- 특정 상자 하나가 비는 배치: \(2^5=32\)가지, 비는 상자 선택 3가지이므로 \(3\times32=96\)을 뺀다.
- 그런데 두 상자가 동시에 비어서 **한 상자에만** 공 5개가 들어간 경우 3가지는 위에서 두 번 빠졌다. 각 경우를 한 번씩 되돌린다.

\[
3^5-{}_3C_1\,2^5+{}_3C_2\,1^5
=243-96+3
=150.
\]

\[
{}_5C_3\times150=10\times150=\boxed{1500}.
\]

검산: 두 풀이의 가운데 값이 모두 \(150\)이고 최종 답이 원문 ③과 일치한다.
