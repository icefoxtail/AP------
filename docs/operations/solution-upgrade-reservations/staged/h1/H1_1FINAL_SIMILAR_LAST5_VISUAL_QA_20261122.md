### 다음 작업 시 직접 수정해야 할 두 그림 유형

1. **효천고 유사1·2 16번 (NK-04/06):** 기출 q16 문제 그림은 아래로 열린 포물선 `f`와 상승 직선 `g`를 보여 준다. 유사1은 f가 **아래로 볼록(이차항 계수 양수)** 이라고 명시하며, 유사2는 h=f−g의 계수가 양수라고 명시한다. 따라서 기출 그림의 개형을 그대로 복사하면 관련 주어진 조건을 위반한다. 신규 문제 그림은 수학적 위치 관계를 재작도하고, 숫자 계수·정답·풀이값은 숨겨야 한다.
2. **효천고 유사2 7번 (NK-05):** 기출의 직각삼각형은 높이 **20cm**, 밑변 **60cm**지만 유사2는 높이 `h`를 구해야 하는 문제(최대 넓이 150cm²)이므로 기출의 20cm 표기는 사용할 수 없다. 세로 `a`, 높이 `h`, 밑변 60cm를 유사 발문 그대로 보여 줘야 한다.
3. 강남여고 유사2 q11·18·20 (NK-01~03): 기출 그림의 네 지점·두 곡선 관계를 참고하되 도로 개수·포물선·직선은 유사 원문을 기준으로 다시 만든다. q18/q20의 샘플 계수는 연구용이며 정답이 드러날 수 있어 그대로 문제 화면에 게시 금지.

## 수학 및 설명 상태

- 116문항의 정답/선택지를 독립 계산식과 대조한 1차 청사진을 작성했으며, 이 단계에서 기입 정답과의 불일치는 발견되지 않았다. 단, **116문항 전부 실제 단계별 풀이가 없고 `[JS 기준 풀이]` 임시 문구**이므로 학생용 콘텐츠 검수 PASS가 아니다.
- SVG의 원본 대응 역할은 `sourceQid`/명시 출처 필드 부재 때문에 같은 번호 기준 대조이며, 추후 정확한 계보를 확인해야 한다.
- 엔진 신규 그림 6개 플랜 및 해설 그림 53개는 **LINT_NOT_RUN / RENDER_NOT_RUN / PUBLISH_NOT_RUN**. 독립 시각 QA·화면 QA는 후속 코덱스 담당.
