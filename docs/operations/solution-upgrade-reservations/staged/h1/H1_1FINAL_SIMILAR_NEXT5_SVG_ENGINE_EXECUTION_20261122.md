## 패킷 상태 해석

- `DRAFT_NOT_LINTED`: JSON 초안 작성 완료, 공식 엔진 실행·스키마 적합성 미확인.
- `ENGINE_SUPPORT_CHECK`: 표현 기법 자체가 현재 엔진에서 지원되는지 검증이 더 필요한 초안, 렌더 성공을 가정하지 말 것.
- `REPLACE_EXISTING_SVG`: 원래 연결된 파일이 있으므로 결과 교체 전/후 비교와 안전한 마이그레이션 필요.
- `CONTENT_DEPENDENCY_HOLD__PROBLEM_IMAGE`: GN 문제 그림 초안은 있더라도 콘텐츠 정리 후 적용.
- `CONTENT_BLOCKED__NO_PLAN`: 강남여고 해설 역할 13곳, 풀이 작성 전 기획을 진행하지 않음.
