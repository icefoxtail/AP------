- qid 16 / 기존 정답 **③, \(\dfrac{11}{3}\)** / 수식 중심 학생용 초안·독립 검산 완료, 출고/Golden/Negative/렌더 **NOT_RUN**.
- 문제 핵심: \(\displaystyle f(x)=\begin{cases}\sqrt{x-p}&x\ge p\\|\frac1x+q|&x<p\end{cases}\)이고, 수평선과 교점이 2개인 높이가 정확히 \(0<t\le3\)인 \(p,q\)에 대해 가능한 \(p-q\)의 **모든 값의 합**.
- 원문 풀이의 문제: “빠진 구간의 두 끝점에서 0까지의 거리가 0과 3이어야 한다”는 결론까지 설명이 건너뛴다. 학생은 왜 경계가 0이어야 하고 왜 3이 포함되는지 알기 어렵다. **실제로 어떤 높이에서 교점이 한 개 더 생기는지** 경우표를 만들면 분명해진다.

## 완성 해설

**① 제곱근 그래프에서는 높이 \(t\ge0\)에 교점이 항상 한 개다.**

\[
\begin{aligned}
\sqrt{x-p}&=t\\
x-p&=t^2\\
x&=p+t^2\ge p.
\end{aligned}
\]

따라서 \(t\ge0\)에서 오른쪽 조각은 언제나 정확히 한 번 만난다. 전체 교점이 2개가 되려면 왼쪽 조각

\[
y=\left|\frac1x+q\right|\quad(x<p,\ x\ne0)
\]

이 **딱 한 번** 더 만나야 한다.

**② 우선 \(p=0\)을 배제하자.**

\(p=0\)이면 왼쪽 구간이 \(x<0\)이므로 \(1/x<0\)이다. \(x\)가 큰 음수일 때에는 \(1/x\)가 0에 가까워지고, \(x\)가 0의 왼쪽에 가까워질수록 \(1/x\)는 절댓값이 아주 큰 음수가 된다.

이를 \(u=\dfrac1x+q\)로 쓰면 가능한 값은

\[
u<q.
\]

그런데 높이 \(t>0\)가 충분히 크면 \(-t<q\)이고 \(t>q\)이므로 \(|u|=t\)는 왼쪽 조각에서 \(-t\)라는 해를 항상 **하나** 갖는다. 이러면 \(t>3\)인 높은 수평선에서도 전체 교점이 2개라서 조건에 어긋난다.

\[
\boxed{p>0}.
\]

**③ \(u=\dfrac1x+q\)가 가질 수 있는 범위를 두 갈래로 적자.**

\(x<p\)이면서 \(p>0\)이므로 \(x<0\) 또는 \(0<x<p\)이다.

\[
\begin{aligned}
x<0 &: \quad \frac1x<0
       \ \Longrightarrow\ u<q,\\
0<x<p &: \quad \frac1x>\frac1p
       \ \Longrightarrow\ u>q+\frac1p.
\end{aligned}
\]

따라서

\[
\boxed{u<q\quad\text{또는}\quad u>q+\frac1p}.
\]

즉 \(q\)부터 \(q+\frac1p\)까지는 \(u\)가 될 수 없는 **빈 구간(양 끝 포함)** 이다.

높이 \(t\)와 왼쪽 그래프의 교점은

\[
\begin{aligned}
\left|\frac1x+q\right|&=t\\
|u|&=t\\
u&=t\quad\text{또는}\quad u=-t
\end{aligned}
\]

중에서 위의 허용 범위에 들어가는 값의 개수이다.

**④ \(t=0\)에서는 전체 교점이 2개가 아니어야 한다.**

\(t=0\)에서 제곱근 조각은 이미 1개이므로, 왼쪽에서는 \(u=0\)이 불가능해야 한다.

\[
q\le0\le q+\frac1p.
\]

그런데 \(q<0<q+\frac1p\)로 **둘 다 엄격**하면, \(t>0\)이 아주 작을 때 \(+t,-t\)가 모두 빈 구간에 들어가 왼쪽 교점이 0개이다. 문제는 **모든** \(0<t\le3\)에서 왼쪽 교점이 1개여야 하므로 안 된다.

따라서 빈 구간의 한쪽 끝은 반드시 \(0\)이다.

\[
\boxed{q=0\quad\text{또는}\quad q+\frac1p=0}.
\]

**⑤ 두 경우를 실제로 세자.**

**경우 A: \(q=0\)**

\[
u<0\quad\text{또는}\quad u>\frac1p.
\]

- \(0<t\le\frac1p\): \(-t<0\)만 허용, \(+t\)는 불가능 → 왼쪽 1개 + 제곱근 1개 = 2개.
- \(t>\frac1p\): \(-t,+t\) 모두 허용 → 왼쪽 2개 + 제곱근 1개 = 3개.

따라서 \(\{t\mid g(t)=2\}=(0,\frac1p]\)이다. 문제에서 이 범위가 \((0,3]\)이므로

\[
\begin{aligned}
\frac1p&=3\\
p&=\frac13,\qquad q=0,\\
p-q&=\frac13.
\end{aligned}
\]

**경우 B: \(q+\frac1p=0\)**

\[
q=-\frac1p,\qquad
u<-\frac1p\quad\text{또는}\quad u>0.
\]

- \(0<t\le\frac1p\): \(+t>0\)만 허용, \(-t\)는 불가능 → 왼쪽 1개 + 제곱근 1개 = 2개.
- \(t>\frac1p\): \(-t,+t\) 모두 허용 → 왼쪽 2개 + 제곱근 1개 = 3개.

마찬가지로 정확히 \(0<t\le3\)이 되려면

\[
\begin{aligned}
\frac1p&=3\\
p&=\frac13,\\
q&=-\frac1p=-3,\\
p-q&=\frac13-(-3)=\frac{10}{3}.
\end{aligned}
\]

**⑥ 가능한 값을 모두 더하자.**

\[
\begin{aligned}
\text{모든 }(p-q)\text{의 합}
&=\frac13+\frac{10}{3}\\
&=\boxed{\frac{11}{3}}.
\end{aligned}
\]

### 학생이 꼭 확인할 경계

- \(t=0\)에서는 왼쪽 교점이 없어야 하므로 \(g(0)=1\)이다.
- **\(t=3\)에서는 여전히 두 개**여야 한다. \(u\)의 빈 구간 끝점은 허용되지 않으므로 \(t=1/p=3\)일 때 새로운 교점은 **아직** 생기지 않는다.
- \(t>3\)이면 ±t가 둘 다 허용되어 \(g(t)=3\)이다.

### 독립 검산

- \((p,q)=(1/3,0)\)일 때 \(U=(-\infty,0)\cup(3,\infty)\): \(0<t\le3\)은 왼쪽 −t 한 개, \(t>3\)은 ±t 두 개.
- \((p,q)=(1/3,-3)\)일 때 \(U=(-\infty,-3)\cup(0,\infty)\): \(0<t\le3\)은 왼쪽 +t 한 개, \(t>3\)은 ±t 두 개.
- 양쪽 모두 \(t=0\)은 왼쪽 0개, 제곱근 한 개. 정답 \(11/3\) 일치. 미분·극한 계산 불필요.
