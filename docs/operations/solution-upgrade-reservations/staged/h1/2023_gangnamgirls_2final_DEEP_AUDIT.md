### Q1 — KEEP

**문제 원문**

```text
등식 ${}_nP_2-{}_7C_2=21$을 만족시키는 자연수 $n$의 값은? [3.8점]
```

**보기 원문**

```text
① $7$
② $6$
③ $5$
④ $4$
⑤ $3$
```

**answer 원문**

```text
①
```

**기존 solution 원문 전체**

```text
[키포인트] 순열과 조합을 식으로 바꾸어 자연수 $n$을 구한다.
조건 정리: ${}_nP_2=n(n-1)$이고 ${}_7C_2=21$이다.
풀이 방향: 주어진 등식에 두 값을 대입하여 이차방정식을 푼다.
정석 풀이: $n(n-1)-21=21$이므로 $n(n-1)=42$이다. 따라서 $n^2-n-42=0$, 즉 $(n-7)(n+6)=0$이다. $n$은 자연수이므로 $n=7$이다.
따라서 정답은 ①이다.
```

**판정 이유와 실제 계산식 증거**

순열 n(n−1)과 조합 21을 대입해 (n−7)(n+6)=0으로 인수분해하고 자연수 조건으로 음의 근을 배제한다.

```text
두 함수 $f(x)=2x+1$, $g(x)=3x^2$에 대하여 $(g\circ f)(-1)$의 값은? [3.8점]
```

**보기 원문**

```text
① $3$
② $4$
③ $5$
④ $6$
⑤ $7$
```

**answer 원문**

```text
①
```

**기존 solution 원문 전체**

```text
[키포인트] 합성함수는 안쪽 함수부터 계산한다.
조건 정리: $(g\circ f)(-1)=g(f(-1))$이다.
풀이 방향: 먼저 $f(-1)$을 구한 뒤 그 값을 $g$에 대입한다.
정석 풀이: $f(-1)=2(-1)+1=-1$이고, $g(-1)=3(-1)^2=3$이다.
따라서 정답은 ①이다.
```

**판정 이유와 실제 계산식 증거**

합성 순서 f(−1)=−1, g(−1)=3이 명시되어 입력과 출력이 뒤섞이지 않는다.

```text
함수 $f(x)=2x+a$에 대하여 $f^{-1}(4)=2$일 때, 상수 $a$의 값은? [3.8점]
```

**보기 원문**

```text
① $-1$
② $0$
③ $1$

```

**answer 원문**

```text
②
```

**기존 solution 원문 전체**

```text
[키포인트] $f^{-1}(4)=2$는 $f(2)=4$와 같은 뜻이다.
조건 정리: $f(x)=2x+a$이다.
```

### Q5 — KEEP

**문제 원문**

```text
함수 $y=\dfrac{k}{x}$ $(k\gt0)$에 대한 다음 설명 중 옳지 않은 것은? [3.8점]
```

**보기 원문**

```text
① 역함수는 $y=\dfrac{k}{x}$ $(k\gt0)$이다.
② 점근선의 방정식은 $x=0$, $y=0$이다.
③ 그래프는 제1, 3사분면에 있다.
④ 정의역, 치역은 모두 실수 전체의 집합이다.
⑤ $k=1$일 때의 그래프보다 $k=2$일 때의 그래프가 원점으로부터 더 멀리 떨어져 있다.
```

**answer 원문**

```text
④
```

**기존 solution 원문 전체**

```text
[키포인트] $y=\dfrac{k}{x}$의 정의역과 치역에서는 $0$이 제외된다.
조건 정리: $k\gt0$이면 그래프는 제1, 3사분면에 있고 두 점근선은 좌표축이다.
풀이 방향: 각 설명을 유리함수의 기본 성질과 비교한다.
정석 풀이: $x$와 $y$를 바꾸어도 $xy=k$이므로 역함수는 자기 자신이고 ①은 옳다. 점근선은 $x=0$, $y=0$이므로 ②도 옳고, $k\gt0$이므로 그래프는 제1, 3사분면에 있어 ③도 옳다. 하지만 $x=0$에서는 함수가 정의되지 않고 $y=0$도 함수값으로 나오지 않으므로 정의역과 치역은 각각 $\mathbb{R}\setminus\{0\}$이다. 따라서 ④가 옳지 않다.
따라서 정답은 ④이다.
```

**판정 이유와 실제 계산식 증거**

정의역 x≠0, 치역 y≠0의 반례가 선택지 ④를 직접 부정하며 역함수 xy=k와 점근선도 확인한다.

**보기 원문**

```text
① ㄱ
② ㄱ, ㄴ
③ ㄱ, ㄷ
④ ㄴ, ㄷ
⑤ ㄱ, ㄴ, ㄷ
```

**answer 원문**

```text
⑤
```

**기존 solution 원문 전체**

```text
[키포인트] 무리함수의 시작점, 정의역·치역과 평행이동을 함께 확인한다.
조건 정리: $f(x)=-\sqrt{2(x-2)}+3$의 시작점은 $(2,3)$이다.
풀이 방향: ㄱ~ㄷ을 각각 그래프의 성질로 판정한다.
```

### Q8 — KEEP

**문제 원문**

```text
$\dfrac{x+2y}{3}=\dfrac{4y+z}{4}=\dfrac{z}{2}=\dfrac{2x+10y-z}{a}$를 만족시키는 상수 $a$의 값을 구하면? (단, $x,y,z$ 중 적어도 하나는 $0$이 아니다.)
```

**보기 원문**

```text
① $4$
② $5$
③ $6$
④ $7$
⑤ $8$
```

**answer 원문**

```text
④
```

**기존 solution 원문 전체**

```text
네 비의 공통값을 $t$라 하자.
$\dfrac z2=t$에서 $z=2t$이다. 이를 $\dfrac{4y+z}{4}=t$에 대입하면
$4y+2t=4t$이므로 $y=\dfrac t2$이다. 이어서 $\dfrac{x+2y}{3}=t$에 대입하면
$x+t=3t$이므로 $x=2t$이다.
따라서
$2x+10y-z=4t+5t-2t=7t$이다.
만약 $t=0$이면 $x=y=z=0$이 되어 발문의 조건에 어긋난다. 따라서 $t\ne0$이다. 마지막 비의 공통값이 $t$이므로
$\dfrac{7t}{a}=t$이다. $t\ne0$이므로 양변을 $t$로 나누면 $\dfrac7a=1$, 따라서 $a=7$이다.
따라서 정답은 ④이다.
```

**판정 이유와 실제 계산식 증거**

공통비 t≠0을 비영 조건으로 증명한 뒤 z=2t,y=t/2,x=2t에서 분자 7t를 얻어 a=7로 나눈다.

### Q10 — UPGRADE

**문제 원문**

```text
$a=2+i$일 때, $\dfrac{1}{1-\dfrac{1}{1-\dfrac{1}{a}}}-\dfrac{1}{1-\dfrac{1}{1+\dfrac{1}{a}}}$의 값은?
```

**보기 원문**

```text
① $-4-2i$
② $-2-2i$
③ $0$
④ $2+2i$
⑤ $4+2i$
```

**answer 원문**

```text
①
```

**기존 solution 원문 전체**

```text
[키포인트] 복잡한 연분수는 $\dfrac1a$를 기준으로 각 항을 먼저 간단히 한다.
조건 정리: 첫째 항은 $\dfrac{1}{1-1/(1-\frac{1}{a})}$, 둘째 항은 $\dfrac{1}{1-1/(1+\frac{1}{a})}$이다.
풀이 방향: 각 항을 $a$에 대한 일차식으로 정리한 뒤 $a=2+i$를 대입한다.
정석 풀이: 첫째 항의 분모는 $1-\dfrac{1}{1-\frac{1}{a}}=\dfrac{-\frac{1}{a}}{1-\frac{1}{a}}$이므로 첫째 항은 $1-a$이다. 둘째 항의 분모는 $1-\dfrac{1}{1+\frac{1}{a}}=\dfrac{\frac{1}{a}}{1+\frac{1}{a}}$이므로 둘째 항은 $a+1$이다. 따라서 전체 값은 $(1-a)-(a+1)=-2a=-2(2+i)=-4-2i$이다.
따라서 정답은 ①이다.
```

**판정 이유와 실제 계산식 증거**

두 연분수의 핵심 변환을 한 문장에 압축하여 분모가 어떻게 약분되는지 학생이 따라가기 어렵다.

```text
집합 $X=\{1,2,3\}$에 대하여 $X$에서 $X$로의 함수 중 함수의 개수 $a$, 일대일 함수의 개수를 $b$, 상수함수의 개수를 $c$, 항등함수의 개수를 $d$라 할 때, $a+b+c+d$의 값을 구하면?

```

### Q10 수정 학생용 solution

첫째 연분수와 둘째 연분수를 각각 안쪽부터 계산한다. \(a=2+i\)이므로 \(a\ne0,1,-1\)이고 모든 분모가 0이 되지 않는다.

\[
\begin{aligned}
\frac{1}{1-\frac{1}{1-\frac1a}}
&=\frac{1}{1-\frac{a}{a-1}}\\
&=\frac{1}{\frac{a-1-a}{a-1}}\\
&=\frac{1}{-\frac1{a-1}}\\
&=-(a-1)=1-a.
\end{aligned}
\]

\[
\begin{aligned}
\frac{1}{1-\frac{1}{1+\frac1a}}
&=\frac{1}{1-\frac{a}{a+1}}\\
&=\frac{1}{\frac{a+1-a}{a+1}}\\
&=\frac{1}{\frac1{a+1}}\\
&=a+1.
\end{aligned}
\]

따라서

\[
\begin{aligned}
(1-a)-(a+1)&=1-a-a-1\\
&=-2a\\
&=-2(2+i)=-4-2i.
\end{aligned}
\]

정답은 ①이다. 검산: \(a=2+i\)를 넣으면 첫째 항 \(-1-i\), 둘째 항 \(3+i\), 차 \(-4-2i\)이다.

### Q19 수정 학생용 solution

\(a>0\)이므로 \(f(x)=2\sqrt{a(x+a)}\)의 시작점은 \(A=(-a,0)\), \(x=0\)일 때 \(B=(0,2a)\)이다.

접선 \(y=2x+b\)와 만나는 점의 \(x\)좌표는

\[
2\sqrt{a(x+a)}=2x+b
\]

를 만족한다. 접점에서는 \(2x+b\ge0\)이고, 양변을 제곱하면

\[
\begin{aligned}
4a(x+a)&=(2x+b)^2\\
4ax+4a^2&=4x^2+4bx+b^2\\
0&=4x^2+4(b-a)x+b^2-4a^2\\
0&=x^2+(b-a)x+\frac{b^2-4a^2}{4}.
\end{aligned}
\]

한 점에서 접하므로 중근 조건은

\[
\begin{aligned}
0&=(b-a)^2-(b^2-4a^2)\\
&=b^2-2ab+a^2-b^2+4a^2\\
&=a(5a-2b).
\end{aligned}
\]

\(a>0\)이므로 \(b=\frac52a\). 중근과 접점은

\[
x_C=-\frac{b-a}{2}=-\frac{3a}{4},
\qquad
y_C=2\left(-\frac{3a}{4}\right)+\frac{5a}{2}=a.
\]

\(2x_C+b=a>0\)이므로 제곱 과정의 부호 조건도 만족한다. 따라서 \(C=(-3a/4,a)\)는 실제 접점이다.

\(A\)를 기준으로 \(\overrightarrow{AB}=(a,2a)\), \(\overrightarrow{AC}=(a/4,a)\)이다. 삼각형의 넓이는

\[
\begin{aligned}
[ABC]&=\frac12\left|a\cdot a-2a\cdot\frac a4\right|\\
&=\frac12\left|a^2-\frac{a^2}{2}\right|\\
&=\frac{a^2}{4}.
\end{aligned}
\]

따라서 \(a^2/4=1/4\), \(a^2=1\), \(a>0\)이므로 \(a=1\). \(b=5/2\)이므로

\[
b-a=\frac52-1=\frac32.
\]

정답은 ⑤이다. 검산: \(a=1,b=5/2\)이면 \(A=(-1,0),B=(0,2),C=(-3/4,1)\)이고 넓이는 \(1/4\), 접선의 기울기는 2이다.
