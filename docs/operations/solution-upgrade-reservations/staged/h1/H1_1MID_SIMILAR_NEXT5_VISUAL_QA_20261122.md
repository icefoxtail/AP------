## P0 문항·정답 차단

SVG만 수정해서는 다음 오류가 해결되지 않는다.
- **매산 q11 / NO_VALID_ANSWER:** 첫 포물선 두 교점 조건은 k>2, 둘째 포물선 접점 조건은 k=−2. 교집합이 공집합인데 ⑤=2를 정답 표시한다.
- **매산 q12 / ANSWER_INVALID:** t=(x−1)²+1∈[1,5], y=(t−2)²+1에서 m=1, M=10, 합 11. 해설 끝에서 10+2=12로 바뀌었고 보기에는 11이 없다.
- **매산 q18 / FALSE_FACTOR:** 문항 다항식은 주장한 (x−z)(x−y)²와 yz(y−z)만큼 다르다. 해설의 소수 (7,5,2)를 대입하면 요구값 20이 아닌 50.
- **순천 q16 / DEGENERATE_DOMAIN:** 문항은 x≥2에서 변 x−2의 직육면체를 가정한다. x=2이면 한 변 0으로 직육면체가 아니므로 진짜 직육면체에선 x>2, 겉넓이 30은 최솟값이 아니라 하한이다. 도메인 정의 수정 필수.
- **제일 q15 / MISSING_SOLUTION:** 해설이 `[해설생성불가]`이며 수열 시작 계수는 1,3,5,7인데 마지막 항이 50i^50로 써 있어 일반항 2n−1과 모순. 문제·정답 ②부터 재작성.

## P1 이미지 및 기타 이슈

- **매산 q10:** 원본 구획을 높이 x·전체 가로 y인 큰 직사각형의 내부 칸막이로 읽으면 끈 3x+2y=180, 전체 넓이 S=xy가 맞다. 유사문항에는 y가 전체 가로임을 보여 주는 문제 그림이 빠져 있으므로 치수 정의와 칸막이 위치를 그림으로 명확히 해야 한다.
- **강남 q16:** 본문은 [그림 1] 한 기둥과 [그림 2] 세 직교 기둥을 참조하지만 현재 연결 SVG는 [그림 2]만 보인다. 2장면 복원, 겹친 중심 큐브 검증 필요.
- **순천 q5:** 해설 SVG 상단 구간 [−1,1]은 관련 있지만 하단 L=−1,R=1,T=2, 거리 3·1은 이 문제의 풀이 조건이 아니므로 삭제·실제 함수 그래프 교체.
- **순천 q22:** 유사 q22는 있으나 대응 원본 q22가 없어 원본 이미지 동등성 비교가 불가. 독립 생성문항으로 별도 출처 검증(수학 판별식 계산 자체는 맞음).
- **제일 q18:** 정사각형 안 DE=5, DF=4인 EF 위 P를 말하지만 E,F가 어느 변 위에 있는지 본문에 정확히 지정하지 않았다. 원본 대응 그림도 없으므로 조건 또는 별도 문제 그림이 필요.
- **팔마 q23:** 서논술형은 양의 실수 k=3이 정답인데 questionBank.answer가 객관식 기호 `③`로 저장됨. 제출·채점 메타데이터 정정 필요.
