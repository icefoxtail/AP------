## q02 — KEEP

**content (실제 원문)**

```text
두 집합 $A=\{x\mid ax^2-x-6=0\}$, $B=\{-2,b\}$에 대하여 $A\subseteq B$이고 $B\subseteq A$일 때 $a+b$의 값은? (단, $a,b$는 상수) [2.8점]
```

**choices (실제 원문)**

```text
1. $-3$
2. $4$
3. $8$
4. $12$
5. $16$
```

**answer (실제 원문)**

```text
②
```

**solution (실제 원문 전체)**

```text
[키포인트] 서로가 서로의 부분집합이면 두 집합은 같다.
조건 정리: $A\subseteq B$, $B\subseteq A$이므로 $A=B=\{-2,b\}$이다.
풀이 방향: $-2$가 이차방정식의 근이라는 사실로 $a$를 구하고 다른 근을 찾는다.
정석 풀이: $x=-2$를 $ax^2-x-6=0$에 대입하면 $4a+2-6=0$이므로 $a=1$이다. 따라서 방정식은 $x^2-x-6=0$, 즉 $(x+2)(x-3)=0$이므로 근은 $-2,3$이다. 따라서 $b=3$이고 $a+b=1+3=4$이다.
따라서 정답은 ②이다.
```

**판정 이유 — 읽은 계산식·그림·학생 논리 검토**

양방향 부분집합에서 A=B임을 먼저 쓰고 −2를 원래 방정식에 대입해 `4a+2−6=0⇒a=1`, 그다음 `(x+2)(x−3)=0`에서 다른 근 b3을 구해 합4를 계산한다.

## q04 — KEEP

**content (실제 원문)**

```text
어느 전시 기획자가 서로 다른 미술 작품 6개를 전시실에 일렬로 나열하려고 한다. 작품 6개 중에서 2개만 동일한 작가의 작품일 때, 동일한 작가의 작품 2개를 서로 이웃하게 나열하는 모든 경우의 수를 구하면? [3.3점]
```

**choices (실제 원문)**

```text
1. $2$
2. $64$
3. $120$
4. $240$
5. $280$
```

**answer (실제 원문)**

```text
④
```

**solution (실제 원문 전체)**

```text
[키포인트] 반드시 이웃해야 하는 두 작품을 하나의 묶음으로 처리한다.
조건 정리: 두 작품을 한 묶음으로 보면 이 묶음과 나머지 네 작품, 모두 5개의 서로 다른 대상을 배열한다.
풀이 방향: 5개 대상의 배열 수에 묶음 내부의 순서 수를 곱한다.
정석 풀이: 묶음을 포함한 5개 대상을 일렬로 나열하는 방법은 $5!$가지이다. 묶음 안의 두 작품의 순서는 $2!$가지이므로 전체 경우의 수는 $5!\times2!=120\times2=240$이다.
따라서 정답은 ④이다.
```

**판정 이유 — 읽은 계산식·그림·학생 논리 검토**

같은 작가의 서로 다른 두 작품을 한 묶음으로 보아 '묶음+나머지4개'의 5대상을 5!로, 묶음 내부의 두 순서를 2!로 세며 `5!·2!=120·2=240`으로 계산한다.

## q05 — KEEP

**content (실제 원문)**

```text
전체집합 $U$의 세 부분집합 $A,B,C$에 대하여 다음 중 집합 $(A-B)\cup(A\cap C)$와 같은 집합은? [3.4점]
```

**choices (실제 원문)**

```text
1. $A-(B\cap C)$
2. $A-(B\cup C)$
3. $(A\cap C)-B$
4. $(A\cup C)-B$
5. $A-(B-C)$
```

**answer (실제 원문)**

```text
⑤
```

**solution (실제 원문 전체)**

```text
[키포인트] 차집합을 여집합과 교집합으로 바꾸면 식을 한 번에 정리할 수 있다.
조건 정리: $A-B=A\cap B^C$이다.
풀이 방향: 분배법칙으로 $A$를 묶은 뒤 보기의 식과 비교한다.
정석 풀이: $(A-B)\cup(A\cap C)=(A\cap B^C)\cup(A\cap C)=A\cap(B^C\cup C)$이다. 한편 $A-(B-C)=A-(B\cap C^C)=A\cap(B\cap C^C)^C=A\cap(B^C\cup C)$이다. 따라서 두 집합은 서로 같다.
[시각자료 읽기] 왼쪽 식을 A∩(Bᶜ∪C)로 정리한 결과가 A−(B−C)의 전개와 같으므로 두 식은 같은 집합이다.
따라서 정답은 ⑤이다.
```

**판정 이유 — 읽은 계산식·그림·학생 논리 검토**

차집합 `A−B=A∩Bᶜ`, 분배법칙 `(A∩Bᶜ)∪(A∩C)=A∩(Bᶜ∪C)`를 실제 집합식으로 보인다. 비교 보기 `A−(B−C)=A∩(B∩Cᶜ)ᶜ=A∩(Bᶜ∪C)`까지 전개하여 선택지⑤의 동치를 증명한다.

## q06 — KEEP

**content (실제 원문)**

```text
전체집합 $U$에 대하여 두 조건 $p,q$의 진리집합을 각각 $P,Q$라 하자. 명제 $p\to\sim q$가 참일 때, 다음 중 항상 옳은 것은? [3.5점]
```

**choices (실제 원문)**

```text
1. $P\cap Q=P$
2. $P\cap Q=Q$
3. $P^C\cup Q=\varnothing$
4. $P^C\cup Q=U$
5. $P-Q=P$
```

**answer (실제 원문)**

```text
⑤
```

**solution (실제 원문 전체)**

```text
[키포인트] 명제 $p\to\sim q$가 참이라는 것은 $p$와 $q$가 동시에 참일 수 없다는 뜻이다.
조건 정리: 진리집합으로 나타내면 $P\subset Q^C$, 따라서 $P\cap Q=\varnothing$이다.
풀이 방향: 서로소라는 사실을 각 선택지에 적용한다.
정석 풀이: $P$와 $Q$가 서로소이므로 $P$에서 $Q$에 속한 원소를 빼도 제거되는 원소가 없다. 따라서 $P-Q=P$가 항상 성립한다. 다른 선택지의 등식들은 $P,Q$가 서로소라는 조건만으로는 항상 성립하지 않는다.
따라서 정답은 ⑤이다.
```

**판정 이유 — 읽은 계산식·그림·학생 논리 검토**

`p⇒¬q`가 참이면 P,Q가 서로소, 즉 `P∩Q=∅`임을 밝힌다. 따라서 P에서 Q를 빼도 제거되는 원소가 없어 `P−Q=P`를 얻어 ⑤와 직접 연결한다.

## q07 — KEEP

**content (실제 원문)**

```text
두 도시 A, B를 연결하는 도로는 4가지, 두 도시 B, C를 연결하는 도로는 $n$가지이다. A도시를 출발하여 B도시를 거쳐 C도시까지 갔다가 B도시로 돌아오는 경우의 수는 80가지이다. 자연수 $n$의 값을 구하면? (단, 한 번 이용한 도로는 다시 이용하지 않는다.) [3.6점]
```

**choices (실제 원문)**

```text
1. $5$
2. $6$
3. $7$
4. $8$
5. $9$
```

**answer (실제 원문)**

```text
①
```

**solution (실제 원문 전체)**

```text
[키포인트] 각 이동 구간의 선택 수를 곱하되, 돌아올 때 이미 사용한 도로 한 개를 제외한다.
조건 정리: A에서 B로 가는 도로는 4개, B에서 C로 가는 도로는 $n$개이다. C에서 B로 돌아올 때는 직전에 사용한 도로를 제외하여 $n-1$개를 고를 수 있다.
풀이 방향: 곱의 법칙으로 전체 경우의 수를 식으로 나타낸다.
정석 풀이: 전체 경우의 수는 $4\times n\times(n-1)=80$이다. 따라서 $n(n-1)=20$이고 $n^2-n-20=0$, 즉 $(n-5)(n+4)=0$이다. $n$은 자연수이므로 $n=5$이다.
따라서 정답은 ①이다.
```

**판정 이유 — 읽은 계산식·그림·학생 논리 검토**

A→B 4갈래, B→C n갈래, C→B는 방금 지난 도로 제외 n−1갈래라는 이유로 `4n(n−1)=80`, `n²−n−20=(n−5)(n+4)=0`, 자연수 n5를 계산한다. 되돌아오는 길의 −1이 문제 조건에서 나왔다.

```text
학생 5명의 이름표를 상자 속에 1개씩 넣은 후 임의로 1개씩 고를 때, 5명 중에서 2명만 자신의 이름표를 고르는 모든 경우의 수를 구하면? [3.6점]
```

```text
③
```

