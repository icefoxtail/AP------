조건 정리
- 다항식: $(5x-3y-z)^2$
- 구하는 값: 전개식 중 $yz$ 항의 계수

풀이 과정

$(5x-3y-z)^2 = (5x)^2 + (-3y)^2 + (-z)^2 + 2(5x)(-3y) + 2(-3y)(-z) + 2(-z)(5x)$
위 식에서 $yz$가 포함된 항은 $2(-3y)(-z)$ 뿐이다.
이를 계산하면 $2(-3y)(-z) = 6yz$가 된다.
따라서 $yz$의 계수는 $6$이다.

결론
따라서 정답은 ②이다.

**독립 검산·판정 근거:** (−3y)(−z) 교차항 두 번 ⇒ yz 계수 6. 수식과 답의 일치를 검증하여 KEEP.

조건 정리
- 이차방정식: $x^2-4x+2=0$
- 두 근: $\alpha, \beta$
- 구하는 값: $\frac{1}{\alpha} + \frac{1}{\beta}$

풀이 과정
이차방정식의 근과 계수의 관계에 의하여 두 근의 합과 곱은 다음과 같다.
$\alpha + \beta = -\frac{-4}{1} = 4$
$\alpha\beta = \frac{2}{1} = 2$

$\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta}$
위에서 구한 합과 곱의 값을 대입한다.
$\frac{\alpha + \beta}{\alpha\beta} = \frac{4}{2} = 2$

결론
따라서 정답은 ③이다.

**문제 원문:** $\frac{1-i}{1+i} - \frac{1+i}{1-i} = a+bi$일 때 상수 $a, b$에 대하여 $a-b$의 값은? (단, $i=\sqrt{-1}$) [4.0점]

**보기:** 2 | 3 | 4 | 5 | 6

**정답:** ①

**기존 해설 원문:** [키포인트]
분모의 실수화를 통해 복소수 분수식을 간단히 한 후 실수부분과 허수부분을 비교한다.

조건 정리
- $\frac{1-i}{1+i} - \frac{1+i}{1-i} = a+bi$
- $a, b$는 실수

풀이 과정
각 분수의 분모와 분자에 켤레복소수를 곱하여 실수화한다.
첫 번째 항: $\frac{1-i}{1+i} = \frac{(1-i)^2}{(1+i)(1-i)} = \frac{1 - 2i + i^2}{1^2 - i^2} = \frac{1 - 2i - 1}{2} = -i$
두 번째 항: $\frac{1+i}{1-i} = \frac{(1+i)^2}{(1-i)(1+i)} = \frac{1 + 2i + i^2}{1^2 - i^2} = \frac{1 + 2i - 1}{2} = i$
두 식을 빼서 계산한다.
$-i - i = -2i$
이 결과가 $a+bi$와 같으므로 $a+bi = 0 - 2i$이다.
복소수가 서로 같을 조건에 의해 실수부분 $a=0$, 허수부분 $b=-2$이다.
따라서 $a-b = 0 - (-2) = 2$이다.

결론
따라서 정답은 ①이다.

**독립 검산·판정 근거:** (1−i)/(1+i)=−i, 역비 i, 차−2i, a−b=2. 수식과 답의 일치를 검증하여 KEEP.

- 주어진 식: $\frac{900\times 890+9}{1023}$

$(x+5)(x-5) + 9 = x^2 - 25 + 9 = x^2 - 16$
이는 합차 공식으로 다시 인수분해된다.
$x^2 - 16 = (x-4)(x+4)$

$1023 = 3 \times 341 = 3 \times 11 \times 31$

$\frac{3^4 \times 11 \times 29 \times 31}{3 \times 11 \times 31} = 3^3 \times 29 = 27 \times 29$

결론

**문제 원문:** 양수 $m$에 대하여 이차함수 $y = -2x^2+m$의 그래프와 직선 $y=4x$가 서로 다른 두 점 A, B에서 만난다. 두 점 A, B에서 $x$축에 내린 수선의 발을 각각 C, D라 하자. 삼각형 AOC와 삼각형 BOD의 넓이의 합이 32일 때, 상수 $m$의 값을 구하시오. (단 O는 원점이다.)

**정답:** 12

**기존 해설 원문:** [키포인트]
교점의 좌표를 근으로 하는 이차방정식의 근과 계수의 관계를 이용하여 넓이의 식을 변형한다.

조건 정리
- $y = -2x^2+m$ 과 $y=4x$ 의 교점: $A, B$
- 수선의 발: $C, D$
- $\triangle AOC + \triangle BOD$ 넓이 합: $32$
- $m$은 양수

풀이 과정
두 식을 연립하여 교점의 $x$좌표를 구하는 방정식을 세운다.
$-2x^2+m = 4x \implies 2x^2+4x-m = 0$
이 이차방정식의 두 근을 $\alpha, \beta$라 하면 점 $A$는 $(\alpha, 4\alpha)$, 점 $B$는 $(\beta, 4\beta)$이다.
근과 계수의 관계에 의하여 $\alpha+\beta = -2$, $\alpha\beta = -\frac{m}{2}$이다.
삼각형의 넓이는 $\frac{1}{2} \times \text{(밑변)} \times \text{(높이)}$이다.
$\triangle AOC$의 밑변은 $|\alpha|$, 높이는 $|4\alpha|$이므로 넓이는 $\frac{1}{2}|\alpha||4\alpha| = 2\alpha^2$이다.

$\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = (-2)^2 - 2(-\frac{m}{2}) = 4 + m$
이 값이 $16$과 같으므로 $4 + m = 16$에서 $m = 12$이다.
$m=12$는 양수 조건도 만족한다.

결론
따라서 구하는 값은 $12$이다.

**문제 원문:** 이차함수 $ y = ax^2+bx+c $의 그래프와 직선 $ y = 4mx+2m^2+m $가 실수 $ m $의 값에 관계없이 항상 접할 때,<br>상수 $ a,b,c $의 값을 구하는 과정을 서술하시오.

**보기:** 서술형

**정답:** $ a = -2, b = -1, c = -\frac{1}{8} $

**기존 해설 원문:** [키포인트]
이차함수와 직선이 접할 조건인 판별식 $D=0$을 적용한 후, $m$에 대한 항등식 성질을 이용해 계수를 구한다.

조건 정리
- 함수 $y = ax^2+bx+c$ 와 직선 $y = 4mx+2m^2+m$ 이 접함
- 실수 $m$의 값에 관계없이 항상 성립

풀이 과정
두 식을 연립하여 이차방정식을 만든다.
$ax^2+bx+c = 4mx+2m^2+m \implies ax^2 + (b-4m)x + (c-2m^2-m) = 0$
이차함수와 직선이 접하므로 판별식 $D=0$이어야 한다.
$D = (b-4m)^2 - 4a(c-2m^2-m) = 0$
전개하여 식을 정리한다.
$b^2 - 8bm + 16m^2 - 4ac + 8am^2 + 4am = 0$
이 식이 $m$에 대한 항등식이므로 $m$에 대하여 내림차순 정리한다.
$(16+8a)m^2 + (4a-8b)m + (b^2-4ac) = 0$
$m$의 값에 관계없이 성립하려면 각 계수가 모두 $0$이어야 한다.
1) $16+8a = 0 \implies a = -2$
2) $4a-8b = 0 \implies 4(-2) - 8b = 0 \implies -8b = 8 \implies b = -1$
3) $b^2-4ac = 0 \implies (-1)^2 - 4(-2)c = 0 \implies 1 + 8c = 0 \implies c = -\frac{1}{8}$

결론
따라서 구하는 값은 $ a = -2, b = -1, c = -\frac{1}{8} $이다.
