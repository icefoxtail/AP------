## 2. 핵심 증거와 잘못된 판단 정정

1. 과거 감사는 코드의 `assets/images/<시험지>/...`를 **저장소 루트**에서 조회해 404를 받았으나, 저장소 내부 실제 경로는 `archive/assets/images/<시험지>/...`이다. JS에 기록된 앱 상대 경로를 Git 저장소 루트와 혼동한 오류였다.
2. HOLD 66문항에 연결된 자산 **66개**(SVG 49, PNG 17)는 정확한 파일명으로 존재하며 파일을 내려받아 전부 열고 래스터 변환했다. **렌더 오류 0개**. 인쇄 원본 14 PDF의 문항 그림/조건과 비교한 결과 경로 누락을 이유로 남길 HOLD는 없다.
3. 66개 자산 가운데 64개는 새 KEEP 56문항의 문제·해설에 연결되어 있으며, 2개는 독립 결함으로 유지된 Q20(24 수피아)/Q12(25 순천)에 연결된다. **그림의 실재 = 정답의 정확성/출시 승인**이라는 의미는 아니다.
4. 원본 수학을 재검산할 때 기존 MD의 독립 검산식을 대조하고, 중복 보기·정수 해의 반례·확률의 독립 추출 가정·공유 지문과 standalone 분리·중복 수록·도로망 DP를 별도로 확인했다.
