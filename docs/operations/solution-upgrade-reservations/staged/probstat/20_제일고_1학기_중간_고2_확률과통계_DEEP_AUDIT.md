- identity: id=`8`; sourceQid=`8`; sourceBlobSha=`e9439b30192d0468b33a1c57b506e6d64c1b7199`; 단원: 이항정리; questionType: `객관식`; 원본 답: `②`
- 원문 문제 조건 (원본 HTML 개행·이미지 태그만 정규화):

> 다음은 $n$이 홀수 일 때, 등식
> $${}_n\mathrm{C}_0 + {}_n\mathrm{C}_2 + {}_n\mathrm{C}_4 + \cdots + {}_n\mathrm{C}_{n-1} = 2^{n-1}$$
> 이 성립함을 증명한 것이다.
> 
> $$\begin{gathered} \text{이항정리에 의하여} \\ (1+x)^n = {}_n\mathrm{C}_0 + {}_n\mathrm{C}_1 x + {}_n\mathrm{C}_2 x^2 + \cdots + {}_n\mathrm{C}_n x^n \cdots (*) \\ (*) \text{ 식의 양변에 [ (가) ]을 대입하면} \\ 2^n = {}_n\mathrm{C}_0 + {}_n\mathrm{C}_1 + {}_n\mathrm{C}_2 + \cdots + {}_n\mathrm{C}_n \cdots (1) \\ (*) \text{ 식의 양변에 [ (나) ]을 대입하면} \\ 0 = {}_n\mathrm{C}_0 - {}_n\mathrm{C}_1 + {}_n\mathrm{C}_2 + \cdots - {}_n\mathrm{C}_n \cdots (2) \\ (1)\text{식과 } (2)\text{식을 서로 [ (다) ]} \\ 2^n = 2({}_n\mathrm{C}_0 + {}_n\mathrm{C}_2 + {}_n\mathrm{C}_4 + \cdots + {}_n\mathrm{C}_{n-1}) \text{ 이므로} \\ 2^{n-1} = {}_n\mathrm{C}_0 + {}_n\mathrm{C}_2 + {}_n\mathrm{C}_4 + \cdots + {}_n\mathrm{C}_{n-1} \end{gathered}$$
> 
> (가), (나), (다)에 들어갈 말로 알맞은 것을 고른 것은? [4.7점]

- 보기: ① `(가) $x=1$, (나) $x=1$, (다) 더하면` · ② `(가) $x=1$, (나) $x=-1$, (다) 더하면` · ③ `(가) $x=1$, (나) $x=1$, (다) 빼면` · ④ `(가) $x=-1$, (나) $x=1$, (다) 더하면` · ⑤ `(가) $x=-1$, (나) $x=-1$, (다) 빼면`
- 기존 solution 실제 내용:

> 첫째 식에는 $x=1$을 대입하면 $2^n=\sum_{k=0}^{n}\binom nk$를 얻는다.
> 둘째 식에는 $x=-1$을 대입하면 $0=\sum_{k=0}^{n}(-1)^k\binom nk$를 얻는다.
> 두 식을 더하면 홀수 번째 항은 서로 없어지고 짝수 번째 항은 두 배가 된다. $n$이 홀수이므로 마지막 짝수 지수는 $n-1$이다.
> 따라서 (가)는 $x=1$, (나)는 $x=-1$, (다)는 더하면이고 정답은 ②이다.

- **독립 검산·판정**: (1+1)^n±(1−1)^n를 조합하면 짝수 인덱스 계수 합 2^(n−1); 빈칸 x=1,−1 및 더하기.
