~~~text
[핵심] 큰 수의 법칙은 반복 시행 횟수가 많아질수록 관찰한 **비율**이 이론적 확률에 가까워진다는 법칙입니다. 매번 반드시 그 비율이 된다는 뜻은 아닙니다.
한 번의 성공확률이 $p$이고 서로 독립인 시행을 $n$번 할 때 성공 횟수를 $X_n$이라 하면 $X_n\sim B(n,p)$입니다. 앞면이 나온 비율처럼 성공의 상대도수는 $R_n=\frac{X_n}{n}$입니다.

$n$이 커져도 비율의 평균은 $p$이고, 분산은 0에 가까워집니다. 즉 상대도수가 $p$에서 크게 벗어나는 일이 점차 드물어집니다.
~~~
