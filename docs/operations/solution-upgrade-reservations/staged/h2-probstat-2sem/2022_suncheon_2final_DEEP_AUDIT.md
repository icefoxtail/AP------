각 유형에서 앞 두 자리 $f(1),f(2)$는 $1$부터 $u$ 사이에서 감소하지 않게 고르고, 뒤 세 자리 $f(6),f(7),f(8)$는 $w$부터 $4$ 사이에서 감소하지 않게 고른다. 중복을 허용한 비감소 선택의 수를 이용하면 다음과 같다.
(가) $(1,1,2)$: 앞 $1$가지, 뒤 $2,3,4$ 중 중복조합 $\binom{3+3-1}{3}=10$가지 → $10$.
(나) $(1,3,4)$: 앞 $1$가지, 뒤 모두 $4$ → $1$.
(다) $(2,2,4)$: 앞 $1,2$ 중 두 개 비감소 선택 $\binom{2+2-1}{2}=3$, 뒤 모두 $4$ → $3$.
(라) $(2,3,3)$: 앞 $3$가지, 뒤 $3,4$ 중 세 개 비감소 선택 $\binom{2+3-1}{3}=4$ → $12$.
(마) $(4,4,4)$: 앞 $1,2,3,4$ 중 두 개 비감소 선택 $\binom{4+2-1}{2}=10$, 뒤 모두 $4$ → $10$.
따라서 조건을 만족하는 함수는 $10+1+3+12+10=36$개이다. 확률은 $\frac{36}{4^8}=\frac9{4^7}$이므로 $a=9$이다. 유형별 경우는 가운데 세 값이 서로 다르므로 중복되지 않는다.
