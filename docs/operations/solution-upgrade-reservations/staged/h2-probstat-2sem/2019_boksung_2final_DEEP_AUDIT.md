표의 '계'는 전체 확률의 합이므로 $c=1$이고 $a+b+\frac13=1$, 즉 $a+b=\frac23$이다. 크기 $2$의 표본을 독립 추출하는 통상적 표본추출에서 $\overline X<0$이 되려면 두 값이 $(-2,-2)$이거나 $(-2,0),(0,-2)$이어야 한다. 따라서 $P(\overline X<0)=a^2+2ab=\frac{15}{36}=\frac5{12}$이다. $b=\frac23-a$를 대입하면 $a^2+2a(\frac23-a)=\frac43a-a^2=\frac5{12}$이다. $12a^2-16a+5=0$, $(2a-1)(6a-5)=0$이므로 $a=\frac12$ 또는 $\frac56$이다. $a\le\frac23$이어야 $b\ge0$이므로 $a=\frac56$은 제외하고 $a=\frac12$, $b=\frac16$이다. 따라서 $a-b+c=\frac12-\frac16+1=\frac43$이다.
~~~
