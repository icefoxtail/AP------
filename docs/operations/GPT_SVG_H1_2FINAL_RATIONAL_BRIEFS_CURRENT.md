# 고1 2학기 기말 · 유리함수 SVG 문항별 지시서

이 지시서는 작업 대상·수학·그림의 목적을 정리한 초안이다. 지시서 작성은 제작·검수·main 반영을 뜻하지 않는다. 각 문항의 최신 main 원문·현재 자산과 진행 중 PR을 재확인해 중복을 막는다. 기존 그림이 있으면 실제 렌더를 비교해 새 그림이 더 나을 때만 교체한다. 문제 그림과 해설 그림을 구분한다. 해설 그림에는 정답에 이르는 필수 조건·좌표·중간 과정과 관계를 충분히 보여준다. SVG와 PNG는 기존 엔진으로 생성하고 브라우저 프로필·출력 경로가 독립적이면 병렬 렌더한다. 공용 브랜치·페이지 쓰기는 순차 통합한다. 각 문항별 plan·publish·SVG·PNG·비교 이미지와 SHA, 실제 검증 및 NOT_RUN을 제출한다. ROOT가 직접 수학과 실제 화면을 대조한다.

- 문제: 3≤x≤4의 모든 x에서 a(x−2)²+1≤(x+2)/(x−2)≤b(x−2)²+1일 때 a의 최댓값 M과 b의 최솟값 m의 합.
- 검산: t=x−2∈[1,2]에서 t²>0이므로 a≤4/t³≤b가 모든 t에 대해 성립해야 한다. 4/t³은 이 구간에서 감소하며 (1,4), (2,1/2)를 지난다. 따라서 M=1/2, m=4, 합 9/2, 정답 ①. a의 최댓값은 곡선의 최솟값, b의 최솟값은 곡선의 최댓값이라는 방향을 바꾸지 않는다.
- 그림: 1≤t≤2 구간의 y=4/t³ 그래프와 포함된 두 끝점 (1,4), (2,1/2)를 보여 준다. 모든 t에 대해 아래 경계 a≤1/2, 위 경계 b≥4가 필요한 관계와 M+m=9/2를 읽기 좋게 정리한다. t의 정의역 밖 연장선은 실제 문제 범위와 구분한다. 식·라벨과 점선은 겹치지 않게 배치한다.
- 상태: 원문 JS 및 수학 직접 확인. 엔진의 세제곱 역수 지원·plan·렌더·검수 미실행. 미지원이면 임의 대체하지 않는다.
