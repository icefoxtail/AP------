# 미완료 목록과 재개 순서

상태는 `PAUSED_WITH_REMAINING / RESUME_READY`입니다. 전체 12시험지 286문항을 열람·검토했으며 미착수 시험지와 미열람 문항은 없습니다. 아래는 이미 찾아 둔 근거·정의·의미 미확정 항목입니다. 이 목록을 등록 대기만 남은 상태로 해석하면 안 됩니다.

| ID | 범위와 수 | 남은 판단·근거 | 다음 행동 |

R01·R02·R03 및 개별 항목은 서로 겹칩니다. 합계로 문항 수를 계산하지 않습니다. 193 SOURCE_ONLY의 QFULL 일치도 해설 근거 존재를 뜻하지 않습니다. 공식 fingerprint는 이 구형 source의 `question`을 `content`로 포함하지 않으므로 원문 question hash·UID·순서·source blob을 함께 확인했습니다.

## 정확 binding 감사의 미완료

`verification/candidate-registry-audit.json`의 716개 후보·교육과정 문맥 검사 중 정확 ACTIVE binding 340개, 누락 155개, 문맥 미확정 221개입니다. 후보 수와 UID 수를 구별해야 합니다. 누락이 하나라도 있는 UID는 126개, 문맥 미확정이 하나라도 있는 UID는 182개이며 두 집합은 겹칠 수 있습니다.

특히 45 UID의 45개 후보는 다른 문맥이 같아도 과정 문자열이 맞지 않습니다. 정본 과정명은 `중1 수학`, 일부 canonical binding은 `中1 수학`입니다. 이번 작업은 문자열을 몰래 정규화하거나 공용 binding을 수정하지 않았습니다. Codex가 정본 수정 절차와 영향 범위를 검토해야 합니다. ACTIVE 키가 존재하거나 어느 문맥의 binding이 맞는다는 사실만으로 문항 의미 적합성이 승인되지는 않습니다.

## 재개 조건

정확한 taskId와 원격 브랜치, 이전 writer CLOSED, AWCR OFFERED를 확인한 뒤 인수를 기록합니다. 새 담당자는 최신 main 및 현재 source/registry 드리프트를 먼저 확인하고, 이미 검토한 전체를 다시 시작하지 않습니다. 파일명 연도만으로 SOURCE_ONLY의 교육과정을 추정하지 않습니다. 변경된 판본이나 해결된 부채에 필요한 검사만 다시 수행합니다. 현재 사용자의 main 병합·공용 등록·배포 금지는 계속 유효합니다.

## 유형·근거 공백 집계

| 표시 범주 | 원문 항목 수 | 해당 고유 UID |
| --- | ---: | ---: |
| 기존 정의 재사용/정의범위검토 | 137 | 134 |
| binding/crosswalk 누락 | 103 | 98 |
| 신규 PT/TPL 또는 확장 제안 | 22 | 22 |
| RPM leaf 공백 | 41 | 41 |
| 내용·시각·해설근거 부채 | 311 | 239 |

원문 gaps 475건과 contentDebt 139건, 총 614개 기록을 집계했습니다. 원문 배열에 등장하는 UID는 284개이며, 정의·binding·leaf 관련 검토 항목의 합집합은 222 UID입니다. 여기에 모든 SOURCE_ONLY 193과 solved fingerprint93의 전역 근거 부채를 명시하여 전체286의 등록 보류 상태를 연결했습니다. 범주별 UID와 전역 부채는 서로 겹치므로 합산하지 않습니다.

신규·확장 표시 22건 중 PT/TPL 관련 명시 NEW_*는 18건, Condition은 3건, CrossConcept은 1건입니다. 이는 새 유형 22개가 확정되었다는 뜻이 아닙니다. 현재 22건 모두 정식 부모/정의 초안/등록 승인 등의 미비를 `NOT_READY_FOR_REGISTRATION`으로 기록했습니다. RPM 범주에는 원문 NOTE도 포함되므로 41개 전부가 leaf 부재 확정인 것은 아닙니다.
