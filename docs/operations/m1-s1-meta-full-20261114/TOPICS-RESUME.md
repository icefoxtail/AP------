# 중1 1학기 메타 재개 — 주제·난도 집계

기존 12시험지 286문항 전수 검토와 36문항 독립 표본을 재사용한 집계입니다. 이번 표에는 기존 검토 및 새 잔여판단의 명시적 변경만 반영했습니다. 새 전수 검토·재풀이는 수행하지 않았습니다.

주제·학습 level·평가 bucket의 **검토후보**와 현재 JS에 실제 저장된 메타를 구분했습니다. `UNKNOWN` 및 source 필드 부재는 숫자 난도로 환산하지 않았습니다. 표의 주제는 기존 검토의 `standardUnitKey/subUnitKey` 기준이며 RPM의 유효 부모 명칭과 구별합니다.

## 전체 규모와 주제

- 기존 전수검토 재사용: **286문항** / 독립표본 재사용: **36문항** / 추가 전수검토: **0회**.
- 원문에 정답·해설이 없는 SOURCE_ONLY: **193문항**. 기존 해설이 보존된 문항: **93문항**이며 current 판본의 최종승인 여부와 구별합니다.
- 삼산23은 기존 M1 연산 임시비교 집계에서 제외하여 선행기초 단일반복 **1문항**으로 별도 표시했습니다. 정식 route 등록은 아직 완료되지 않았습니다.

## 집계 근거와 검증

- 각 시험지의 기존 `review.json` 및 `independent-review.json`을 그대로 사용했습니다. 파일 SHA와 UID별 원래값·후보값·명시변경은 `topics-resume.json`에 기록했습니다.
- source의 현재 level·bucket은 JS 파일의 메타필드만 읽어 집계했습니다. 원문·보기·정답·해설·이미지·source 메타는 수정하지 않았습니다.
- 286개 UID가 각각 한 번만 등장하고, 시험지별 주제 개수 및 두 난도분포의 합계가 모두 해당 시험지 문항 수와 일치합니다. 주제 총합286, 독립표본 총합36을 확인했습니다.
- 16연향의 새 잔여 작업은 B 담당입니다. 새 명시적 난도 변경이 없는 한 완료된 기존 검토후보를 유지합니다.
- 이 집계는 출고 승인·등록 완료를 선언하지 않습니다. SOURCE_ONLY method 회수, source 교육과정 근거, current 판본 승인 및 registry/binding/crosswalk 반영은 인계된 후속 조건입니다.
