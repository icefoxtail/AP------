> **v2 안내 (2026-10-30):** v2 계획에서 1-B·1-C·1-D(대기열 비우기 화면, 초안 내보내기, 이전 안내 배너)는 폐기되었고, 1-A(주소 설정 통합)만 선택 과제로 남는다. 이전(도메인 연결)은 이 작업과 무관하게 진행할 수 있다. 이 지시서는 1-A를 할 때만 쓰며, 1-B~1-D 절은 기록으로만 남겨 둔다.

- 현재 금지(소유자 지시, 2026-10-30): Worker 설정, CORS(`ALLOWED_ORIGINS`), DNS, Pages 사용자 도메인은 변경하지 않는다.

- (폐기, v2) 이전 전에 옛 출처(`icefoxtail.github.io`)에서 데이터를 안전하게 비우는 장치(1-B~1-D)는 만들지 않는다. 대신 사람이 직접 안내한다(계획서 3절 "이전 당일 할 일").

- [ ] 동기화 성공 전에는 큐를 지우지 않는다.

## 5. 작업 1-C 초안 내보내기 (폐기, v2)

- [ ] 문제지 초안, Archive 설정 등 옮길 가치가 있는 AP------ 키를 JSON 파일로 내려받는다.
- [ ] 새 출처에서 그 파일을 가져오는 기능을 둔다.
- **규칙:**
  - 다루는 키는 AP------가 쓰는 키만이다. 계획서 1.4 목록과 코드에서 확인한 키를 **명시 목록**으로 만들어 쓴다. 접두어 일괄 처리나 전체 순회는 하지 않는다.
  - 목록 밖의 키는 읽지도 지우지도 않는다. `icefoxtail.github.io` 출처는 같은 계정의 다른 저장소(예: my-life-os)와 공유된다.
  - 세션(`APMATH_SESSION`)과 PIN(`PLANNER_PIN` 등) 같은 인증값은 내보내지 않는다.
