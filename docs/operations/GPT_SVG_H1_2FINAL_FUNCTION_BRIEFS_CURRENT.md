## 2023 강남여고 12번 · 그래프에서 합성
- 원문 JS: `archive/exams/original/high/h1/2final/23_강남여고_2학기_기말_고1_기출.js`, Q12. 문제 그림 `assets/images/23_강남여고_2학기_기말_고1_기출/q12.png`. 문제 그림의 실제 픽셀을 확인했다. 꺾은선은 (0,0)→(2,1)→(3,2)→(4,5)→(5,4) 순서다.
- 문제: 그래프에서 (f∘f)(a)=1인 보기의 a를 구한다.
- 검산: f(2)=1, f(3)=2, f(4)=5, f(5)=4. 0≤x≤2는 (0,0)과 (2,1)을 잇는 선분이므로 f(1)=1/2, f(1/2)=1/4. a=3이면 3→2→1이다. 나머지 보기의 결과는 각각 1/4, 1/2, 4, 5. 정답 ③.
- 그림: 원문 그래프의 점과 선분을 보존하고 입력 3에서 2, 다시 1로 읽는 순서를 색이나 화살표로 구별한다. 두 번 적용을 한 번의 점 이동으로 오해하지 않게 한다.

## 2023 매산여고 19번 · 두 일차 가지와 일대일대응
- 원문 `archive/exams/original/high/h1/2final/23_매산여고_2학기_기말_고1_기출.js`, Q19. 문제·해설 그림은 연결되어 있지 않다.
- 문제: 실수 전체에서 f(x)=−2ax (x≥0), f(x)=(a+7)x (x<0)가 일대일대응이 되는 정수 a의 개수.
- 검산: 두 기울기가 0이 아니고 같은 부호여야 두 가지의 치역이 0을 경계로 겹치지 않으면서 실수 전체를 덮는다. 양수인 경우 −2a>0 및 a+7>0에서 −7<a<0. 두 기울기가 모두 음수인 경우 a>0과 a<−7이 동시에 필요하여 불가능하다. 정수는 −6, −5, −4, −3, −2, −1로 6개.
- 그림: 대표값 a=−1의 두 반직선을 예시라고 명시해 그리고, x<0의 치역 (−∞,0), x≥0의 치역 [0,∞)를 색으로 구분한다. x=0은 x≥0 가지에 포함한다. 두 기울기의 부호 조건과 −7<a<0, 정수 여섯 개를 해설 그림에 보여준다. 예시 하나만으로 모든 a가 증명된 것처럼 표현하지 않는다. 불가능한 음수 기울기 경우도 짧은 조건 비교로 명확히 구분한다.
- 상태: JS와 해설 수학 직접 확인. 엔진 plan·렌더·검수 미실행.


## 2022 매산고 4번 · 대응도와 역함수
- 원문 `archive/exams/original/high/h1/2final/22_매산고_2학기_기말_고1_기출.js`, Q4. 문제 그림 `assets/images/22_매산고_2학기_기말_고1_기출/q4.png`의 실제 픽셀을 확인했다. 세 집합 X와 f, g 화살표가 있는 대응도다. 현재 해설 SVG 연결은 없다.
- 문제: X={1,2,3}의 두 함수 f, g의 대응도에서 (f∘g)(2)+(f⁻¹∘g)(1)을 구한다.
- 검산: 원문 대응은 f: 1→3, 2→1, 3→2; g: 1→3, 2→2, 3→1. (f∘g)(2)=f(2)=1, (f⁻¹∘g)(1)=f⁻¹(3)=1이므로 합은 2, 정답 ②.
- 그림: f와 g 대응을 각기 구별해 보이고, 두 경로 2→g(2)=2→f(2)=1, 1→g(1)=3→f⁻¹(3)=1을 서로 다른 색 또는 선형으로 표시한다. 역함수에서는 f의 화살표를 거꾸로 읽는다는 점을 명시한다. 원문에 없는 대응을 만들지 않고 두 계산과 합 2를 해설 그림에 보여준다. 작은 화면에서 교차 화살표와 숫자가 구분되게 한다.
- 상태: 원문 JS·문제 PNG 실제 확인 및 수학 검산. 엔진 plan·렌더·검수 미실행.
