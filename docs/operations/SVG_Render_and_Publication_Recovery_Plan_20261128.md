## 수리 Plan 220건의 게시 후속 조치

엔진 커밋 994a077ead326b449cb16eb8c6f6dd2d572f3ddf에서 수리 Plan 220건을 실행해 131건이 ARCHIVE_BOUND에 도달했다. 성공분은 문제 그림 103건과 해설 그림 28건이다. [PR #3470](https://github.com/icefoxtail/AP------/pull/3470)에서 문제 그림 2건과 해설 그림 6건을 반영했다. 이 PR에 포함되지 않은 렌더 성공분은 문제 그림 101건과 해설 그림 22건으로, 총 123건이다. 이 중 최신 main에 동일 결과가 이미 있는 수는 아직 확인하지 않았다. 렌더 성공에 이르지 못한 89건의 후속 처리는 별도다.

1. PR #3470에서 반영한 8건을 기준으로, 나머지 123건을 최신 main의 실제 시험지 경로·문항 ID·그림 역할별로 대조한다. 현재 연결된 SVG가 보존된 엔진 산출물과 동일하면 게시 완료로 기록하고 중복 반영을 생략한다. 시험지 본문·보기·해설이나 Plan이 이후 바뀌어 산출물과의 연결이 달라졌으면 해당 건만 재렌더한다.
2. 같은 문항·역할의 후보가 여러 개인 경우 현재 화면이 지원하는 연결 구조와 공식 Plan의 의도를 확인하고, 선택 근거가 있는 산출물만 게시한다. 게시 시도에는 문항별로 실제 게시 여부와 거절 코드를 남긴다. 확인된 해설 게시 거절 중 하나는 QUESTION_OBJECT_NOT_LOCATED였다. 다른 미반영 건의 원인은 결과를 확보하기 전까지 미확정으로 둔다.
3. 문제 그림 게시 경로에서 기존 이미지 필드·본문 이미지·시험지 상대 자산 경로를 구분한다. 기존 도구가 지원하는 경우 그 도구로 반영한다. 실제로 필요한 형식이나 신규 이미지 연결을 지원하지 않는 경우 공식 게시 도구와 회귀 검사를 보완한다. 해설 그림도 공식 게시 도구의 문항 객체 탐색을 같은 방식으로 보완한다. 발문·보기·정답·해설 본문이나 기존 그림 슬롯을 임의로 바꾸지 않는다.
4. 다시 게시할 때는 ARCHIVE_BOUND 산출물과 실제로 연결된 시험지 JS·SVG만 커밋하고, 최신 main 기준 단일 PR로 제출한다. 재처리 대상 123건은 이미 동일하게 반영된 건, 이번 게시 반영 건, 그리고 구체적 사유를 기록한 남은 건의 합으로 마감한다. 이 합계와 89건의 렌더 미통과, 별도 시각검수 및 배포 상태는 구분한다.

이 문서는 확인된 원인과 실행 계획을 기록한다. 위 수정·회귀검사·재렌더·재게시의 실행 상태는 NOT_RUN이다. 원시 렌더 로그와 SVG 산출물은 이 문서 PR에 포함하지 않는다.
