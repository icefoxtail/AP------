# 패키지 판본과 해석 주의

기존 시험지별 meta·resolver·independent·verification·공식 compact는 동결 증거다. 파일 안의 당시 상태는 이 마감 판본의 명시적 보완 사항과 함께 읽는다.

1. **E065 Q5의 2022 경로**: 기존 `EXACT_COUNTERPART_UNAVAILABLE`만 `E065.current2022-supplement.json`으로 대체한다. 실제 y=ax² 대입은 M3-RPM-135에 정확히 맞는다. 2015 소스 메타·난도·관계 판정은 그대로다. 기존 403경로 공식 보고서는 불변이며, 추가 1경로를 합친 유효 결과는 `ALL9.official-validation.effective-summary.json`이다. Q1·4·11·16은 의미 재검 후 exact leaf gap을 유지한다.
2. **E066 Q3의 문구**: author 난도 설명에 “학습수준 하는 유지”가 있으나 이는 작성자의 새 판단 하를 가리키는 오래된 문구다. 실제 원본과 최종 source의 `level`은 **중**이며 안정성 고정 원칙에 따라 변경하지 않았다. 난도 bucket은 1/B12다. 동결 설명의 문구를 고쳐 증거 SHA를 바꾸지 않고 이곳에 명시한다.
3. **독립 증거 경로**: `evidence-relocations.json`의 원래 경로→패키지 경로→raw SHA 매핑을 적용한다. 9개의 `sourceFirstNotes` 과거 이름을 실제 `independent.source-first-notes` 파일로 연결한다. E064 최초 meaning freeze도 별도 보존했다. 기록된 작업자 절대경로는 당시 provenance이며 현재 실행 경로로 추정하지 않는다. [evidence-relocations-applied.json](evidence-relocations-applied.json)의 적용 완료 판정이 제안서의 과거 COPY_PENDING 상태에 우선한다.
4. **E079 Q18·19**: 초기 작성자의 leaf-gap 제안보다 후속 root adjudication이 우선한다. 정확한 M2 닮음 길이 leaf는 존재한다. 남은 조건은 현재 학생용 해설의 AA 유도 누락이며, 소스 수리·검증 뒤에만 resolver를 실행한다.
5. **E082 Q19**: 독립 B의 exact leaf 유보 의견과 C의 채택 의견을 모두 보존했다. root는 실제 결정적 방법을 피타고라스 평면도형 길이로 판단했다. M3 target 부모와 원-원 접함 CC 등록은 별개다. 사후 후보 노출 이력을 숨기지 않아 구 검증기의 관계 provenance 실패가 남아 있다.
6. **검증 단위**: resolver·난도 PASS는 등록/소비자/수학 R1·R2·R3 전체 PASS가 아니다. `CORRECT` 및 `BRANCH_REVIEW_COMPLETE` 역시 해당 메타 검토 상태이고 소스 선결 문제의 해소를 뜻하지 않는다. 보류와 검증기 FAIL은 그대로 인계한다.
