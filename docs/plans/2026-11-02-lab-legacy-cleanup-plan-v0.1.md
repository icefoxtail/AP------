## 3. 정리 방향 (Selected direction)

**"실험실은 하나다."** 화면에서 '2.0'·'기존'·'비교'·'미리보기'라는 말을 없앤다. 버전은 내부 사정이지 학생이 고를 것이 아니다.

### 1단계 — 화면 정리 (작고 안전, 테스트에 안 걸림)
- 허브 상단 trail 줄과 푸터의 이행기 링크·"2.0 미리보기" 문구 제거. 푸터에는 꼭 필요한 것만(없으면 푸터 자체 제거).
- 통계에서 "2.0 화면 적용" 제거(실험실·장면 수는 유지).
- "기존과 비교" 버튼 제거. "2.0 실험실 체험" 제거 — 첫 방문자에게는 "이어서 하기" 자리에 학년 첫 실험실 하나를 "시작하기"로 보여 주는 것으로 대신(주 행동은 하나).
- 카드: "2.0" 배지 제거, "2.0 실험실 열기" → "실험실 열기", "기존 버전" 링크 제거.
- "기초판": 2.0 원·부채꼴에 기초 단계 대응이 있으면 그 장면으로 연결, 없으면 1단계에서는 그대로 두고(학생이 쓰는 기능이므로) 2단계에서 이식.
- `<title>`·noscript 문구 정리.
- APMS 서랍·빠른 찾기 입구를 2.0 허브 직행으로(`./playground/next/index.html`). 테스트 `tests/apms-drawer-nav.test.js:123` 기대 수정.
- 문서 개수 43→45(`PRODUCT.md:47`, `next/README.md:5,103`), README의 "기존 버전 링크로 열 수 있다" 문장 갱신.

### 2단계 — 옛 파일 처리 (중2·중3 개편이 끝난 뒤)
- 옛 실험실 URL(`playground/labs/...`)과 `teacher-hub.html`·`compare.html`은 **지우지 않고 2.0 대응 실험실로 보내는 짧은 이동 페이지로 바꾼다** — 옛 북마크·과거에 나눠 준 링크가 깨지지 않게. 원본 코드는 git 이력에 남는다(`AGENTS.md`: Git에는 운영물만).
- 카탈로그 `legacy` 필드·`catalog.test.mjs`의 legacy 존재 검사를 "옛 URL이 2.0으로 이동한다" 검사로 바꾼다.
- `labs/g7/nets-folding.html`(카탈로그 밖, 2.0 `g7-polyhedra`에 통합)·`labs/대수/index.html`도 같은 방식.
- 이유: `kit/apl-catalog.js`·`manifest.json`은 개편 세션이 자주 고치는 파일이라 지금 건드리면 충돌한다.

## 4. 경계
- 바꾸지 않는 것: 실험실 장면·해설·수학 값, 2.0 실험실 페이지, 학생 포털 입구, 카탈로그(1단계).
- 다른 세션의 중2·중3 개편과 겹치는 파일(`apl-catalog.js`, `next/labs/g8-*`, `g9-*`)은 1단계에서 건드리지 않는다. 1단계 대상 `apl-hub.js`·`apl-hub.css`·`next/index.html`은 11/01 이후 다른 수정이 없다.
