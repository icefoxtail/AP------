대상은 모두 단순한 문제 그림 또는 답안 공간이다. 약700px 원본에서 26~34px 글자는 350px 표시 시 대략13~17px이며, 소스의 긴 문단·다중 축·추가 좌표 라벨이 없어 겹침이나 잘림을 발견하지 않았다. 색은 영역 위치·경계·원문 명명과 함께 사용되므로 색만으로 답을 전달하지 않는다. 무조건 재작성하는 것보다 원문 정보와 과제를 보존하는 근거가 있으며, '새 렌더를 못 보므로 유지'라는 이유는 사용하지 않았다. 실제 서비스의 모바일 확대/배치는 별도 확인 대상이다.
