# Q18 모든 매개변수 조건의 별도 검산
원 중심을 기준으로 옮기기보다 유리함수 중심을 원점으로 옮겨 X=x−a,Y=y−(a+2),d=a²−a라 둔다. 곡선 XY=4, 원 X²+(Y−d)²=8이다.
d=0이면 X²+Y²≥2XY=8에서 등호인 (2,2),(−2,−2) 두 점만 존재한다.
d>0이면 Y<0 가지에서는 X²+(Y−d)²>X²+Y²≥8이라 교점이 없다. Y>0 가지의 거리제곱 F(Y)=16/Y²+(Y−d)²는 F''=96/Y⁴+2>0이고 양끝에서 무한대이다.
0<d<4이면 Y=2에서 F=4+(2−d)²<8이다. d≥4이면 Y=d에서 F=16/d²≤1<8이다. 따라서 엄격 볼록한 F=8은 정확히 두 양의 Y해를 갖는다.
d<0은 (X,Y,d)→(−X,−Y,−d) 대칭으로 동일하다. 따라서 모든 실수 d, 특히 d=a²−a≥−1/4에서 정확히 두 교점. r=2√2는 필요조건뿐 아니라 충분조건이다.
실행 그림은 a=0의 경계 배치 두 패널이며 이 일반 검산을 그림 하나의 증명으로 대신하지 않는다.
