1. **고2 1mid 단원/과목 연결 오류 208문항**: `CANONICAL_UNIT_INVALID`, `CANONICAL_SCOPE_INCOMPLETE`. `--units inline` 재시도에서도 남았다. 원문 경로와 내용으로 과목 ACTIVE 정의를 확인하여 판정했다. TOOL_ERROR 190과 수가 다른 이유는 PT_ONLY를 우선 표기하고 NEW_KEY 계약 오류 7건이 TOOL_ERROR에 추가되기 때문이다.
2. **PT-only 검사 미지원**: `PICK` + `templateKey:null`에서 `TPL_NOT_ACTIVE`. 재현: `19_순천여고_1학기_중간_고2_수학I.js` q6, `20_매산여고_1학기_중간_고2_수학I.js` q3. 도구를 고치거나 기준을 완화하지 않았다.
3. 원격 이미지 `https://img.wangjiedu.com/exams/images/<시험지>/<파일>`는 HTTP 403. sparse checkout에서 로컬 자산이 안 보여도 실제 `HEAD:archive/assets/images/<시험지>/<파일>` blob이 존재했다. 정확한 source path로 추출하여 해결했으며 그림 접근 실패만으로 남은 HOLD는 없다.
4. CLI push는 HTTPS 인증을 얻지 못했다. 연결된 GitHub의 blob/tree/commit 및 expected-HEAD ref 갱신으로 같은 결과 blob을 게시하고 fetch readback했다. 로컬과 원격 커밋 ID 차이는 게시 방식 때문이며 결과 blob은 동일하다.

## 원문 의심 및 HOLD 근거

- `19_강남여고_1학기_중간_고2_수학I.js` q6: 해설에서 log_(1/2)(1/2)=-1로 썼으나 실제 +1이다. 최종 크기 순서는 유지되므로 독립 풀이판정은 PICK, note에 오류 표시.

## 독립성 사건과 복구

정의 스키마 확인 중 `TPL_EXPONENT_LAW_EVALUATION` 객체 1개가 allowlist 없이 출력되어 지원문항 참조 및 대표풀이 부가필드가 한 내부 판정자에게 노출됐다. 지원문항은 담당 밖 2023년 제일고 수학I q1이며 이 checkpoint의 시험지와 겹치지 않는다. 정본 기존 PT/TPL 값이나 다른 판정 줄을 열람한 것은 아니다.

- 노출 전 이미 작성·검증한 동일 키 사용: `20_매산고_수학I` q18. 노출 시점과 선행 판정 provenance를 note에 기록했다.
- 노출 후 사용한 `19_금당고_수학I` q1의 판정은 폐기했다. 이전 선택·대표문항 내용을 제외한 안전 원문/과목 ACTIVE 정의만 fresh 판정자에게 전달하여 새 판단을 받았다. 이전 결과와 비교하지 않았다.
- fresh 결과는 원문 일치, ACTIVE·부모 확인 및 별도 검사 후 반영했고 행 note에 provenance를 기록했다.
- 담당 전체의 동일 키 사용을 기계 검색하여 추가 영향 범위를 확인했다. 이후 모든 정의 조회는 key/label/definition/parent allowlist만 사용한다.
