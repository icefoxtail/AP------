## 2. 고정된 기술 규칙 (LOOP 0에서 테스트 계약으로 확정)

아래는 운영 결정이 아니라 코드·테스트가 공유하는 금액 계산 계약이다.
실행 가능한 형태: `apmath/worker-backup/worker/helpers/billing-settlement.js` + `tests/apmath-billing-model.test.js`

| 규칙 | 내용 |
|---|---|
| 청구금액 | `max(0, 청구항목 합계 + 활성 조정금액 합계)` |
| 완료 유입 | `payment + partial_payment + carryover_in` (status=completed) |
| 완료 유출 | `completed refund + carryover_out` |
| 유효수납 | `clamp(완료 유입 - 완료 유출, 0, 청구금액)` |
| 미수금 | `max(청구금액 - 유효수납, 0)` |
| status | 청구금액>0·유효수납=0 → unpaid / 0<유효수납<청구금액 → partial / 유효수납≥청구금액 → paid / 청구금액=0 → unpaid |
| 조정 부호 | 추가 청구·교재비·특강비 = 양수, 할인·장학·감면·차감 = 음수 |
| 완료 청구의 조정 | 원행 수정 금지. 취소/반대 조정 행으로만 정정 |
| 파생값 | `payments.paid_amount/status/paid_date`는 거래·환불·이월에서만 재계산 |
