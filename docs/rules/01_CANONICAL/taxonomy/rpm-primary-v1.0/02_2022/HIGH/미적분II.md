## 확장 기록 (2026-11-23)

- 사용자 결정(2026-11-23, "세부유형칸도 당연히 늘려야지")에 따라 마플 시너지 미적분 유형 체계에 대응하는 L3 12개·L4 53개를 추가했다. 기존 행의 이름 변경·삭제 없음(add-only).
- 새 L3: 지수·로그함수의 극한, 연속과 미정계수(지수함수와 로그함수의 미분) / 삼각함수의 덧셈정리, 삼각함수의 극한(삼각함수의 미분) / 미분가능성, 이계도함수(여러 가지 미분법) / 곡선의 오목·볼록과 변곡점(도함수의 활용) / 거듭제곱함수의 적분(여러 가지 함수의 적분) / 정적분으로 정의된 함수(치환적분법과 부분적분법) / 정적분과 급수, 입체도형의 부피, 곡선의 길이(정적분의 활용).
- `삼각함수의 합성`은 교육과정 밖 표시 유형이라 `RPM_EXTENDED`(기본 출력 제외)로 둔다. `회전체의 부피`는 대응하는 마플 유형이 없으나 PT/TPL(`TPL_CALCULUS_VOLUME_REVOLUTION`)에 맞는 리프로 함께 둔다.
- 크로스워크: `H2-CALC-RPM-145` 이후 행. 마플 유형 ↔ L4 대응은 마플 유형 은행 매핑표에서 관리한다.
