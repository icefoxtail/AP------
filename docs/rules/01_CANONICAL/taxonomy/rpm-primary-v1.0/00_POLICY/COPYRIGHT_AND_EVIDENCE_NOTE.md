# Copyright / Evidence Note

이 taxonomy는 RPM의 공개 목차를 '분류 기준점'으로 사용한다.

- L1/L2: 공개 목차에서 확인되는 제목을 기준으로 함.
- L3/L4: 공개되지 않은 책 내부 전체 유형목록을 복제하지 않음.
- L3/L4는 해당 L2의 수학 내용을 JS아카이브 출제/검색 목적에 맞게 정규화한 canonical draft임.
- 실제 RPM 책 또는 정식 미리보기에서 세부유형을 추가 확인할 수 있다면,
  그때 의미가 같은지 비교하여 수정할 수 있음.
- 문제 본문/해설을 taxonomy 문서에 복사하지 않음.
