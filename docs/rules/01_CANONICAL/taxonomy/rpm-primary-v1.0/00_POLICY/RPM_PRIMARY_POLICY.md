# RPM Primary Policy — v0.3

## Authority
- Naming / hierarchy primary: RPM
- Curriculum legality / default-output guardrail: 교육부 교육과정
- Existing JS archive taxonomy: migration target

## 원칙
1. L1/L2는 해당 교육과정 RPM 공개 목차를 우선한다.
2. RPM에서 실제 유형으로 다루는 내용은 교육과정의 기본 요구 범위를 넘어도 taxonomy에서 자동 삭제하지 않는다.
3. 교육과정 적합성은 taxonomy 포함 여부가 아니라 `curriculumApplicability/defaultSelectable`로 제어한다.
4. 다른 출판사 구조를 정본에 임의 혼합하지 않는다.
5. 공개되지 않은 RPM 내부 유형명을 확인하지 않고 'RPM 원문 유형'이라고 주장하지 않는다.
6. L3/L4는 JS아카이브 검색/출제에 맞게 수학적 의미로 정규화한다.
7. canonical identity는 전체 curriculum/course/path이며 label 전역 유일성을 요구하지 않는다.

## L1/L2 표시명
RPM-primary이므로 RPM 공개 목차의 L1/L2 표시명을 사용자 취향만으로 임의 교정하지 않는다.
예: 2022 RPM 중3-1의 `제곱근과 그 실수`는 표현이 다소 어색하더라도 RPM-primary L2이므로 그대로 유지한다.
