# APMath Visual Engine Capability Matrix — 2026-10-06

This matrix is a bounded Phase 4 scope and evidence report for the current continuation branch. `SUPPORTED` is reserved for a complete input grammar, producer, independent audit, educational framing, and real-size Archive publication path. Parser acceptance or an experimental locator run alone does not grant that status.

qualify publication or provide a canonical UID result. The candidate bank content
is synthetic, although the collector used actual Chromium, measured the frozen
MathJax fragments before BUILD, loaded the exact final SVG bytes in the local

`216×180`, and full `298.140625×248.453125` CSS px. The minimum rendered label

passes. The independent `y=x³` feature-inventory unit covers merging a

## Phase 4 rational linear-over-linear fixture evidence

This separate `rational-spike-v1` route accepts only exact linear-over-linear
plans on `ALL_REALS` with the denominator's natural zero retained as an excluded
point. Exact cancellation produces one removable hole; otherwise the simple
denominator root is a vertical pole. The independent observer recomputes the
horizontal asymptote and branch directions, verifies that curve segments do not
cross the singularity, and checks the required dashed asymptote and hole
primitives on the final SVG. The hole marker is 4 intrinsic SVG px in radius,
with a 4.5 CSS px minimum diameter at the audited Archive profile; a smaller
profile is `UNSUPPORTED` for that marker.

## Phase 4 square-root affine fixture evidence

The separate `sqrt-affine-spike-v1` route accepts only an exact positive-slope
affine radicand. Natural mode samples from the exact zero of the radicand. A
closed finite source interval is allowed only when its lower endpoint is at or
above that boundary; the drawing domain must retain both interval endpoints
without expansion. The viewport may reserve blank display margin before the
endpoint to show its closed marker, but no function samples are placed in that
margin. Nonlinear, mixed, negative-slope, open-interval, below-boundary, and
expanded-domain requests are unsupported.

The positive-boundary fixture uses `y=√(2x−200)` with natural endpoint x=100.
Its viewport is `[97.1,129]`, keeping the y-axis outside the view. An independent
observer verifies the exact root/endpoint inventory, first one-sided increase,
no curve points before the radicand boundary, full tail visibility, and outlined
closed marker. The final graph sample includes a deterministic near-boundary
critical point, and the independent secant check remains capped at 0.35 CSS px.
Each actual profile must retain at least 48 CSS px from the endpoint to the tail;
small is unsupported because the 4px intrinsic endpoint marker measures only
2.625 CSS px, while medium, large, and full pass. Medium is selected, and the
local Archive capture passes with exact asset/QRious hashes and no external
requests. The screen capture and actual Archive context were visually checked.

Positive/negative coverage includes exact finite endpoint preservation, source
intervals below the radicand root, unsupported grammar/domain variants, missing
or moved/open markers, pre-root curve points, wrong curves, clipped tails, and
profiles below marker or endpoint-to-tail readability floors. The final
candidate remains controlled-synthetic and is not a canonical source result.
