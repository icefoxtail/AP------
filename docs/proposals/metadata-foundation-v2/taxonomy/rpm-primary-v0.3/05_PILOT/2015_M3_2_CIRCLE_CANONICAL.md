## 분류 원칙
- 핵심 풀이정리가 현/접선이면 `원과 직선`.
- 핵심 풀이정리가 원주각 정리이면 `원주각`.
- 복합문항은 primary 하나 + secondary concepts.
- 이 Pilot과 master가 다르면 master가 authority이며 package build는 불일치 시 FAIL해야 한다.
