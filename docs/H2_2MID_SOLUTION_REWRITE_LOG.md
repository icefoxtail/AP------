# 고2 2학기 중간 — 해설 재작성 로그

대상: `archive/exams/original/high/h2/2mid/*.js` 25개 시험지, 550문항

## 목표 형식 (3세대)

```
[키포인트] …
조건 정리: …
풀이 방향: …
정석 풀이: …
따라서 정답은 ③이다.        ← 객관식
따라서 구하는 값은 $17$이다.   ← 서술형·단답형
```

## 방식

- 원본 해설 PDF를 베끼지 않고 **문항을 직접 풀어서** 작성. 작성 전 기록된 `answer`와 대조해 검증.
- 패치는 `solution` 필드만 교체하고, 교체 후 node로 재파싱해 **solution 외 모든 필드가 동일한지** 검증.
  (`answer`·`content`를 고친 문항은 그 필드만 화이트리스트로 열고 나머지 동일성은 그대로 검사.)
- 경우의 수·확률 문항은 가능한 경우 완전탐색 코드로 교차검증.
- 그래프 판독 문항은 `archive/assets/images/…`의 원본 스캔을 확대해 직접 읽음.
- 마무리 후 `archive/tools/exam-lint.mjs`로 신규 경고가 0건임을 확인.

내부적으로 일치하도록 두었으나, **시험지로 출력하면 학생이 풀 수 없는 상태**이므로 재크롭이 필요하다.

### 2. 표준정규분포표 누락

23_제일고 확률과통계 q18은 $P(0\le Z\le1)=0.34$가, q24는 $P(0\le Z\le1.5)=0.43$이 있어야 풀 수 있는데
문제 본문에 제시돼 있지 않다(원본에는 표가 별도 이미지로 붙어 있었던 것으로 보인다). 값 자체는
표준 수치라 해설에서는 표를 인용해 계산했다. 본문에 명시할지는 결정 필요.

### 3. exam-lint 오탐 (참고)

`exam-lint.mjs`의 '추측성 표현' 패턴에 `가능성`이 들어 있어 **`미분가능성`**이라는 정상 용어가 걸린다.
이번에는 해설 문구를 `미분가능 여부`로 바꿔 피했으나, 패턴에 `(?<!미분)가능성` 같은 예외를 두는 편이 낫다.
