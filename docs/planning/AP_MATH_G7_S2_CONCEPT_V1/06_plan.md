# 06. 원과 부채꼴 — 면과 선의 직관적인 분할·이동 중심 재설계 v2.0

대상: `apmath/playground/labs/g7/원과_부채꼴_통합_마스터_스튜디오.html`  
근거: 기존 HTML의 장면/경계 코드 + 사용자가 제공한 교재 **색칠한 부분의 넓이 네 가지 방법** 이미지.  
현재 상태: **계획서**. 실행·실기기 테스트·완성 판정 아님.

## 0. 방향 전환

현재의 4모드/16시나리오는 '공식 설명·기출 버튼·애니메이션'을 먼저 배치한다. 개편은 **학생이 눈으로 선/면을 보고, 잘라보고, 옮긴 뒤 식을 이해하도록** 학습 순서를 바꾸는 것이다.

**목표는 기존 HTML 전체를 기계적으로 다시 작성하는 것이 아니다.** 기존 정확한 좌표·원호 함수·상태 관리·모바일 Pointer Events/도구 재배치·퀴즈/해설은 보존하고, **면의 영역/분할 모델과 경계선 모델, 장면 순서를 핵심부터 새로 설계**한다.

### 학생이 직접 보아야 할 것

- '색칠된 곳'이 **면인지** '둘러싼 곳'이 **선인지**를 명확히 구분한다.
- 전체 면과 빼는 면, 남는 면을 다른 색·경계·기호로 보여준다.
- 조각이 정말 독립된 도형이 되어 움직이고, 이동 후에는 원래 도형이 비워지는 것이 눈에 보여야 한다.
- 경계의 호와 직선은 각각 다른 색으로 강조하며 **둘레에 속하지 않는 내부 보조선은 계산에서 제외**한다.
- 공식은 **도형이 먼저 변한 뒤** 나타나고, 어떤 면·선을 세는지 색상과 일치해야 한다.

## 1. 가장 앞에 둘 필수 개념

| 학생 용어 | 정의·실제 조작 | 필수 확인 |
|---|---|---|
| 원의 중심·반지름·지름 | 중심을 고정하고 반지름을 끌어 원의 크기 바꿈 | 같은 원의 모든 반지름 길이는 같다 |
| 원주 | 원의 경계 곡선만 강조 | 원의 내부와 경계 구분 |
| 호 | 원 위 A→B 곡선, 해당 각의 범위 확인 | 호 길이와 현 길이 혼동 금지 |
| 현 | 원 위 두 점 A,B 잇는 선분 | 가장 긴 현은 지름 |
| 중심각 | 두 반지름 사이 각 | 같은 원에서 같은 중심각↔같은 호 길이 |
| 부채꼴 | 반지름 2개와 **그 사이의 호**로 둘러싸인 영역 | 둘레=호+반지름 2개 |
| 활꼴 | 현과 **그 현에 대응하는 호**로 둘러싸인 영역 | 현을 더한 부채꼴이 아님; 부채꼴과 삼각형 차이로 설명(작은 활꼴 조건) |
| 원의 둘레/넓이 | 원주만 색칠 vs 원 내부 면만 색칠 | 길이 단위 cm, 넓이 단위 cm² |

기본 암기: `원주=2πr`, `원넓이=πr²`, `호길이=2πr×(θ/360°)`, `부채꼴넓이=πr²×(θ/360°)=r×호길이/2`. '둘레'에는 반지름 2개가 실제 경계인 경우만 더한다.

## 2. 교재 사진 4유형: 반드시 실제 움직이는 도형으로 구현

사진 속 배치와 관측은 교육 유형의 근거이며, 숫자·축·정확한 중심/반지름·겹침 관계는 구현 과정에서 좌표로 재확인한다. **동일한 형태인 척 대략 그리는 도형 금지.**

### A. 전체 − 색칠하지 않은 부분 (교재 ①)

예시: 반지름 `a`인 **사분원과 그 안의 직각이등변삼각형** 사이의 색칠한 활꼴.

- Step 0: 사분원과 삼각형을 하나의 원래 도형 위에 겹쳐 놓는다. 색칠할 곳은 반투명 청록.
- Step 1: '전체=사분원' 클릭 → 사분원 영역을 파랑, 경계 호/반지름 표시.
- Step 2: '뺄 면=직각삼각형' 클릭 → 삼각형을 분홍 빗금으로 강조하고 **투명하게 걷어낸다**.
- Step 3: 남은 활꼴 면만 남기고 등식을 해당 색으로 매핑. 필요 시 두 구성 영역을 **별도 카드에 분리 복제해** 차이 비교.
- 수학 검증 예: `A=πa²/4−a²/2`; 실제 경계=호+현(삼각형의 대각선). 공식과 실제 그린 각도·반지름 일치.
- **금지**: 단순 색 번짐, 사분원·삼각형 그림만 옆에 붙임, 제거 대상과 남는 대상 동일 색.

### B. 보조선 → 두 조각 분리 → 같은 모양임을 증명 (교재 ②)

예시: 같은 반지름의 사분원 둘이 겹친 정사각형 안의 나뭇잎 렌즈.

- Step 0: 원래 렌즈 영역 단색+외곽 호 둘로 표시.
- Step 1: 두 공통 교점을 잇는 **대각선 보조선**을 그린다. 보조선은 점선 회색, 둘레가 아니다.
- Step 2: 대각선 양옆을 **두 독립된 활꼴 Region**으로 분할. 왼쪽/오른쪽을 서로 다른 반투명 색으로 칠하고 선택 가능하게 만든다.
- Step 3: 실제 영역 조각 하나를 평행이동하고 다른 한 조각과 포개어 **합동/같은 넓이**임을 확인한다(면적 보존). 각 조각은 `사분원−직각삼각형`.
- 계산 예: `A=2×(πa²/4−a²/2)=πa²/2−a²`.
- **둘레 주의**: 렌즈 경계에는 두 사분원호만 포함하며 내부 대각선은 제외. 반지름이 `a`이면 `L=πa`.
- **금지**: 대각선만 그리고 '×2' 글자 띄움, 단순 본체 좌우 이동.

### C. 적절한 선과 조각 이동 → 삼각형 등 단순한 도형 (교재 ③)

- Step 0: 원래 색칠 영역과 곡선·정사각형을 정확히 보여준다.
- Step 1: 어느 곡선이 어느 원의 호인지 구분하고 **보조선**을 추가한다.
- Step 2: **이동할 실제 영역**을 원래 형태에서 잘라내고 해당 부분을 비운 뒤 이동 경로를 표시한다.
- Step 3: 옮긴 조각이 다른 곡선 부분을 메우면서 단순한 삼각형·직사각형으로 환원되는 장면과 면적 보존 검증을 보여준다.
- 주의: 이 사진은 두 곡선의 교점과 중심점 배치에 따라 영역이 바뀐다. **좌표를 먼저 재구성해 등적임을 계산/기하적으로 증명하기 전에는 '항상 삼각형과 같다'고 일반화하지 않는다.**
- **핵심 비교**: 이동 전후 **넓이는 같을 수 있어도 둘레는 일반적으로 같지 않다**.

### D. 여러 단순 면의 합·차 (교재 ④)

- Step 0: 반원·부채꼴·그 외 제거할 반원의 **중첩 원본**을 보여준다.
- Step 1: 첫 번째 전체에 해당하는 큰 반원 면을 개별 추출.
- Step 2: 추가할 부채꼴 면을 별도 카드로 추출(반지름, 중심각 표시).
- Step 3: 빼야 할 반원 면을 분홍 빗금으로 표시하고 제거.
- Step 4: `색칠 영역 = 큰 반원 + 부채꼴 − 작은 반원`의 단계를 실제 병합/제거된 Region과 일치시킨다. **각 반지름·중심각은 원본 도형의 실제 제약에서 얻는다.**
- 겹침이 있는 경우 일반 덧셈/뺄셈에서 중복을 빼는지 별도로 검사한다. **도형 관계 없이 무조건 '큰반원+부채꼴−작은반원' 숫자를 갖다 붙이면 실패.**

## 3. 둘레 체험의 강제 기준

**둘레는 색칠 영역의 실제 외곽선을 따라 걷는 길이**다. 면의 색과 '더해야 할 길이'는 별도로 렌더링한다.

| 요소 | 기본 시각 색상(다크 칠판) | 길이 계산 |
|---|---|---|
| 둘레에 포함되는 호 | 하늘색 `#38bdf8` | 중심·반지름·쓸어간 각도로 길이 산출 |
| 둘레에 포함되는 선분 | 분홍 `#fb7185` | 두 끝점의 실제 좌표 거리(필요하면 실제 단위로 역환산) |
| 다음 독립된 호 / 대응되는 조각 | 초록 `#34d399` | 앞 구간과 개별 길이 확인 |
| 내부 대각선·보조선 | 흐린 회색 점선 `#94a3b8` | 둘레 합산 **0** |
| 색칠 면(넓이만) | 영역별 반투명 파랑/민트 | 둘레선과 다른 렌더 레이어 |

둘레 선택 시: ① 외곽선만 뚜렷하게 표시 → ② 외곽에 번호 ①②③ 배치 → ③ 같은 색의 `호/선분 길이` 범례 → ④ 누르면 개미/따라가기 커서가 실제 해당 경계를 이동 → ⑤ 각 값의 합이 최종 둘레.

**필수 코드 보정**: 기존 `drawTapeMeasure`의 `weight:0.46,0.27,...` 수동 배분을 없앤다. `weight_i=length_i/Σ length`로 매번 계산한다. 진한 칠판 바탕에 가까운 진한 라벨 글씨는 밝은 글씨 또는 배경과 대비되는 반투명 배경으로 바꾼다. 경로 `ptAt`과 `length`는 반드시 같은 곡선/선분 정의에서 산출한다.

## 4. 새 화면의 데이터/렌더 구조 (한 단원 내부 구현)

- `Geometry`: 원 중심·반지름·각도·사분원/반원·직선·점의 실제 수학 좌표.
- `Region`: 색칠/빼기/분할 조각의 path, signed area, 조각 ID. 영역 연산(intersection/difference/union) 또는 정확한 경계 분해를 사용한다.
- `BoundarySegment`: kind=`arc|segment`, endpoints/center/radius/angles, `length`, `belongsToPerimeter`, `color`.
- `Transformation`: 분할 후 조각마다 `translate/rotate` 행렬. 원래 공간에 해당 면의 빈자리가 남고, 이동 중 면적은 보존돼야 한다.
- `ProofStep`: 각 단계의 강조 Region/Boundary 목록, 해당 수식·설명·되돌리기.
- `State`: 기존 모드/서브·슬라이더·렌즈·모바일 터치 상태와 완전 호환.

**같은 데이터가 화면·애니메이션·면적 계산·둘레 계산에 사용되어야 한다.** 레이블만 바뀌고 그림과 계산이 따로 노는 현재 구조를 반복하지 않는다.

## 5. 학생에게 제시할 화면 구성

1. **개념 용어판** (원주, 현, 호, 부채꼴, 활꼴): 탭 클릭→도형의 해당 선/면만 강조.
2. **색칠 넓이 4유형**: 교재 예제와 동일한 접근에 `원본 → 보조선 → 조각 분리 → 이동/빼기 → 넓이 등식` 단계 버튼. 조각 자체도 직접 잡아서 옮겨보도록.
3. **둘레 추적**: 같은 그림에서 '넓이/둘레' 렌즈 분리, 경계선별 색상·길이·합계.
4. **기출/해설 및 기존 응용**: 네 유형 습득 후 현재 16시나리오의 심화 연결. 태극, 나뭇잎, 초승달, 굴리기와 목줄은 무조건 삭제하지 않고 유효성 검사 후 심화에 배치.

버튼을 누를 때마다 '무엇을 했는가', '왜 넓이가 보존되는가', '지금 둘레에 어느 경계가 포함되는가'를 학생이 스스로 보게 한다. 넓이 숫자만 보고 정답을 맞히는 구조는 기준 미달.

## 6. 검수 시나리오 / PASS 조건

- [ ] 4가지 넓이 접근 각각 최소 **원본 + 분할/보조선 + 실제 조각 이동/제거 + 결과**의 시각 단계.
- [ ] 실제로 움직이는 면이 조각별 독립 객체이며 이동 전 원래 영역에서 조각이 사라진다. 수식 카드·좌표 이동만으로 PASS 불가.
- [ ] ① 사분원−직각삼각형, ② 렌즈=두 활꼴, ③ 이동 전후 등적, ④ 반원·부채꼴 합차의 영역 연산이 실제 좌표와 면적으로 일치.
- [ ] A의 둘레는 '호+현', B 렌즈의 둘레는 '호+호'. B의 내부 대각선을 합산하면 즉시 FAIL.
- [ ] 둘레의 모든 구간에 선 종류·색·이름·실제 길이·이동 경로가 1:1 대응. 임의 `weight` 없음.
- [ ] 원근감/화면 크기 변경에도 수학 좌표가 어긋나지 않는다. 360/390/430px 모바일·태블릿, PC 검사.
- [ ] 중앙각/반지름 변경 시 면의 시각·수치·공식 모두 일치. 영역이 성립하지 않는 범위에서는 명시적 제한.
- [ ] 기존 4모드·16시나리오·퀴즈·해설·모바일 조작/툴바·다크 테마 손실 없음.
- [ ] 코드 정적 검사는 정적 검사라고 기록, **브라우저에서 실제 분할·애니메이션을 확인하기 전 완료 PASS 금지**.

## 7. 우선 구현 순서

**6-A** 기본 용어 및 선/면 선택 → **6-B** A형(전체-제외) → **6-C** B형(나뭇잎 실제 2조각) → **6-D** 둘레 색상/실경로/자동 비율 → **6-E** C형 실제 등적 이동 → **6-F** D형 합·차 → **6-G** 기존 16장면 정합/기출 연결.

**원칙**: 예쁘게 색상만 바꾸는 PR보다, **한 가지 유형의 실제 분할·넓이/둘레를 학생이 완전히 이해하는 화면을 통과시킨 후 다음 유형으로 확장**한다.
