# 06. 원·현·호·부채꼴·활꼴 — 개념·도형 연결 계획 v1.0

**기존 파일**: 원과_부채꼴_통합_마스터_스튜디오.html  
**원칙**: 교과서 정의·암기→움직이는 장면→반례→문제→심화. 기존 계산·애니메이션·해설 보존.

## 필수 개념

- 원주·중심·반지름·지름
- 현(양 끝점을 이은 선분)과 호(굽은 원주)의 구별
- 부채꼴(반지름 두 개+호), 활꼴(현+호)
- 중심각 θ, 호 길이 2πr×θ/360°, 부채꼴 넓이 πr²×θ/360° 및 S=rl/2

## 꼭 암기할 내용

- 같은 원에서 중심각과 호의 길이, 부채꼴 넓이는 정비례
- 현 길이는 중심각에 정비례하지 않는다
- 호 길이 단위와 넓이 단위는 다르다

## 연결할 움직이는 도형 / 데이터 시각화

- 현/호/활꼴/부채꼴을 탭하면 실제 해당 선/영역만 강조
- 중심각 60·90·120·180·360 변화에 따라 값 즉시 갱신
- 중심각 2배 실험에서 호·면적은 2배, 현 길이는 일반적으로 2배가 아닌 반례
- 기존 나뭇잎·태극·굴리기는 심화로 연결

## 완료 판정 기준

- 구성요소 네 종류를 학생이 그림으로 구분
- 서로 다른 반지름 원 사이 비례식을 잘못 적용하지 않도록 조건 표시
- 기존 모바일 터치·Canvas 기능 보존

## 실행 범위

개념/암기 카드와 도형의 상태값을 같은 데이터에 연결하고, 이미 존재하는 심화 모드는 삭제하지 않는다. 정적인 그림만 붙이거나 계산과 그림이 다른 상태는 FAIL. 모바일 조작과 다크 칠판 디자인을 보존한다.
