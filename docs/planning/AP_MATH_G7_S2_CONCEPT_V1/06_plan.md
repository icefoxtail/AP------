## A. 교육적 진단

현재 `원과_부채꼴_통합_마스터_스튜디오.html`은 4모드×4장면이다.

1. 기본 원리·정비례: 호/현/활꼴, 원넓이 직사각형, 부채꼴, 중심각 2배.
2. 색칠 넓이·등적변형: 나뭇잎, 원 안팎 정사각형, 공통 영역, 초승달.
3. 결합 둘레·원 안의 원: 파인 반원, 태극, 원 안의 원, 트랙.
4. 보조선·굴리기·목줄: 이등변 보조선, 직사각형 대각선, 굴리기, 꺾이는 목줄.

**문제는 특정 장면 부족만이 아니라 분류 기준 자체가 서로 다르다는 점**이다. 개념·문제 해결 기술·특수 도형 이름·응용 상황이 같은 층위에 있다. '나뭇잎'은 도형의 종류이지 넓이 해결 원리가 아니고, '굴리기'는 원의 기본형보다 훨씬 나중에 등장해야 한다. 화면 첫 단계에서 학생이 **어떤 선이 호/현/둘레이고, 어떤 면이 원/부채꼴/활꼴인지** 모른 채 계산을 보게 된다.

**새 분류 원칙**: '도형의 기본형(무엇인가?)' → '측정 대상(선인가 면인가?)' → '조작 원리(나누기·옮기기·더하기·빼기)' → '문제 응용'을 서로 다른 계층으로 둔다.

## B. 하나의 단원 / 6개의 학습 구역

메인 허브에는 **「원과 부채꼴」 카드 하나만 유지**한다. 단일 HTML/단일 학습 진입 화면에서 아래 구역으로 이동한다. 옛 장면 수(16)에 맞춰 채우지 않는다.

| 순서 | 구역 | 학생 목표 | 필수 기본형 / 장면 |
|---|---|---|---|
| 01 | **원 알아보기** | 원의 중심·반지름·지름·원주·호·현·중심각·부채꼴·활꼴의 정확한 뜻 | 원 1개에서 점/선/면을 직접 터치하면 부분 강조 |
| 02 | **기본형 익히기** | 하나의 단순 도형을 보고 둘레와 넓이를 정확히 구분 | 원, 반원, 사분원, 부채꼴, 활꼴 |
| 03 | **길이·둘레 이해하기** | 어떤 호·선분이 실제 외곽 경계인지 선택하고 더하기 | 원주, 호, 현, 부채꼴 호+2r, 반원 호+지름, 파낸 반원, 붙인 원호 |
| 04 | **넓이 원리 이해하기** | 원 넓이와 부채꼴 넓이가 왜 그런지 실제 면에서 확인 | 잘게 나눈 원의 부채꼴을 번갈아 재배열, 중심각 비례, 부채꼴의 넓이 |
| 05 | **색칠한 넓이 정복** | 교재 사진 4가지 방법을 실제 면 조각으로 조작·증명 | 전체-부분 / 보조선+쪼개기 / 조각 이동 / 면 더하기·빼기 |
| 06 | **응용·교과서 문제** | 기본 도형과 해결 원리를 스스로 골라 문제 해결 | 원 안의 정사각형, 나뭇잎·초승달·태극·트랙 등 적합한 예제 |

### 01. 원 알아보기: 이름부터 외우지 않고 눌러보며 배운다

- 원의 중심 O를 누르면 중심을 기준으로 반지름이 뻗는다.
- 두 점 A,B를 원주 위에서 이동하면 **호는 곡선**, **현은 선분**이 실시간으로 다른 색으로 강조된다.
- 부채꼴을 누르면 '반지름 두 개+호'가 닫힌 영역으로 표시된다.
- 활꼴을 누르면 '현+호'가 닫힌 영역으로 표시된다.
- 호·현·활꼴과 부채꼴의 뜻을 글·수식·실제 색칠 영역에서 **동시에** 볼 수 있어야 한다.
- 기본 개념과 직접 관련 없는 심화 문제 패널을 첫 화면에 노출하지 않는다.

### 02. 기본형 익히기: 항상 '둘레'와 '넓이'를 나란히

| 기본형 | 둘레에 속하는 선 | 색칠 영역·넓이 | 확인할 오개념 |
|---|---|---|---|
| 원 | 원주 전체 | 원판 | 원주(선)와 원판(면)을 구분 |
| 반원 | 180° 호 + 지름 | 반원 면 | 반원 둘레를 πr로 끝내지 않는다 |
| 사분원 | 90° 호 + 반지름 2개 | 사분원 면 | 1/4 원주만으로 둘레가 아니다 |
| 부채꼴 | 지정한 호 + 반지름 2개 | 두 반지름 사이 원판 일부 | 중심각/360°는 호와 넓이 각각에 적용 |
| 활꼴 | 해당 호 + 현 | 호와 현 사이 면 | 부채꼴과 같은 영역이 아니다 |

암기 수식: `원주=2πr`, `원넓이=πr²`, `호 길이=2πr×θ/360°`, `부채꼴 넓이=πr²×θ/360°=r×호 길이/2`.

**주의**: 중1 수업 화면에 삼각함수 공식은 제시하지 않는다. 현 길이 좌표 계산 등 내부 렌더링에 삼각함수를 써도, 학습 설명은 중등 수준의 도형 성질로 제한한다. 부채꼴의 `S=rl/2`를 '곡선 호가 실제 삼각형 밑변이라서'라고 설명하지 않는다. 중심각 비례 두 식에서 도출한다.

### 03. 길이·둘레: 외곽선을 걷게 만든다

- **길이 렌즈**: 색칠 면을 낮춘 뒤 실제 바깥 경계만 강조.
- 외곽 호는 기본 하늘색 `#38bdf8`, 외곽 선분은 분홍 `#fb7185`, 구별해야 할 두 번째 독립 호는 초록 `#34d399`. 내부 보조선·조각을 붙인 접합선은 회색 점선으로 둘레 **미산입**.
- 외곽 구간을 누르면 해당 선만 밝아지고 **같은 색**의 길이 카드·둘레식 항이 강조된다. '다음 구간'은 실제 원호/선분 위를 따라 이동한다.
- 둘레 줄자의 가로 막대 길이 비는 표시된 **실제 구간 길이 비례**로 자동 계산한다. 임의의 `weight:0.46`, `0.27` 등 상수를 금지한다.
- 구멍이 있는 면의 둘레는 바깥 경계뿐 아니라 **구멍의 경계도 포함**한다. 조각을 이어붙여 내부가 된 경계는 포함하지 않는다.
- 시험 포인트: 반원·사분원, 파낸 부분, 태극 경계, 운동장 트랙. 서로 다른 도형은 여기에서 **경계를 어떻게 셀 것인지**의 예로만 사용한다.

### 04. 넓이 원리: 실제 면이 변해야 한다

- **원의 넓이**: 원판을 8/16/32/64개의 부채꼴 조각으로 실제 분할하고 재배열해 높이 `r`, 윗변·아랫변이 각각 약 `πr`가 되는 모양을 보여준다. **유한 조각은 정확한 직사각형이 아니라 직사각형에 가까워짐**을 명시한다.
- **부채꼴 넓이**: 동일한 원에서 90°→180° 등 중심각을 바꾸면 해당 면 색칠량이 정비례해 변함을 표시한다. 호 길이와 면적의 관계 `S=rl/2`는 두 비례식에서 유도한다.
- '공식으로 계산한 면적'과 '도형에 실제 칠해진 면'이 따로 노는 장면은 불허.

### 05. 색칠한 넓이: 사용자 교재 사진 네 가지 동작

**풀이 이름은 유형 분류가 아니라 동일한 기본형 위에서 선택하는 '넓이 조작 방법'이다.**

1. **전체에서 빼기**: 사분원-삼각형. 전체 면을 선택하고 뺄 면을 따로 표시하여 실제로 걷어낸다. 남은 활꼴만 색칠하고 식의 각 항과 매칭한다.
2. **보조선으로 나누기**: 정사각형 나뭇잎 면. 대각선으로 진짜 두 활꼴 Region으로 자르고, 각각 분리·이동 후 합동/같은 넓이를 확인한다. 식 `2×(사분원-삼각형)`과 대응한다. **대각선은 나뭇잎 둘레가 아니다.**
3. **조각을 옮겨 간단한 도형 만들기**: 보조선을 그어 잘라낸 실제 곡선 조각을 빈자리 없는 상태로 옮겨 원래 면과 정확히 같은 면적의 간단한 도형으로 만드는 과정. 사진 유형 ③의 도형 좌표와 등적성은 먼저 독립 검증한다. **이동 전후 넓이 보존과 둘레 보존은 다르다.**
4. **전체를 몇 개로 분해해 더하고 빼기**: 반원·부채꼴·색칠하지 않은 반원을 독립된 면 Region으로 분리해 +/− 연산. 면의 중복·교집합은 실제로 계산/표시한다.

각 장면은 **원본 → 선택 → 보조선/자르기 → 조각 이동·빼기 → 최종 색칠면 → 식 연결**의 상태를 가지며, '도형은 그대로인데 수식 카드만 바뀜'은 FAIL이다.

### 06. 응용: 모양 이름에 속지 않고 구조로 푼다

- 나뭇잎은 '색칠한 넓이-두 활꼴'과 '둘레-두 호' 양쪽에서 재사용하는 **예제**이지 최상위 메뉴가 아니다.
- 태극은 '여러 반원호를 연결한 둘레'의 **예제**.
- 파낸 반원은 '전체-부분 면적'과 '안쪽 경계도 둘레에 포함'의 **예제**.
- 초승달·굴리기·목줄은 교과 핵심을 통과한 뒤 심화/탐구로 둘지 결정한다. 모든 과거 장면의 무조건 이전은 요구하지 않는다.
- 한 모양을 누르면 '이 도형은 어떤 기본형들의 합/차인가? 둘레는 어떤 경계인가?'가 먼저 제시된다.

## C. 화면 구조 (PC/모바일 동일한 학습 순서)

- 상단: `원과 부채꼴` 제목과 6개 학습 구역(모바일 가로 스크롤 탭).
- **중앙은 가장 크게 움직이는 단 하나의 도형 칠판**. 좌표 기준과 선·면 강조 일관성 우선.
- 칠판 바로 아래: `개념 보기 / 둘레 보기 / 넓이 보기` 렌즈. 학습 구역에 따라 비활성 처리하되 숨겨서 헷갈리게 하지 않는다.
- 학습 카드: **무엇을 보고 있는가 → 핵심 기억 → 왜 그런가 → 한 문제**. 애니메이션 중 현재 단계가 설명에 반영된다.
- 하단: `이전 단계 / 다음 단계 / 처음으로`, 반지름·중심각 슬라이더는 해당 개념 장면에서만 노출. 모바일 터치 44px 이상.
- **도형 조작과 페이지 스크롤은 충돌 금지**. 기존 모바일 최적화 경험은 참고하되 새로운 화면 구조에 맞게 새 테스트를 작성한다.

## D. 새 구현의 적정 범위

- **신규 HTML 소스에서 깨끗하게 구현**한다. 기존 파일은 별도 보존 후 비교 대상으로 활용한다. 기하 좌표식·순수 수학 함수 중 검증된 것만 가져온다.
- 계산을 위한 간단한 내부 모델: `Circle/Arc/Segment`(선), `Region`(색칠 면), `Piece`(분리한 면), `Step`(학습 동작).
- **범용 SVG/CAD/Boolean geometry 엔진을 먼저 개발하지 않는다.** 필요한 기하학 구성과 변환만 수학적으로 정확히 구현한다. 도형이 복잡해지면 필요한 경우에만 정확한 clipping/교차 연산을 도입한다.
- 도형의 면적, 둘레, 화면 패스, 애니메이션 단계는 **같은 수학적 정의**에서 계산한다.
- **기존 16시나리오 재수록이 합격 조건은 아니다.** 중복·학습 순서상 부적합한 것은 신규 화면에서 빼고 기존 페이지를 임시 보존한다. 다만 사용자 확인 전에 기존 운영 링크를 새 화면으로 무작정 교체하지 않는다.

## E. 요구되는 수학·시각 검증

1. 기본형 5종에서 호·현·반지름·원주/원판·활꼴을 서로 구분하여 클릭 가능.
2. 기본형별 둘레/넓이 수치, 실제 선/면, 단위가 정확히 대응.
3. 원 넓이 조각 8→64개 실제 움직임과 극한적 직사각형 접근 설명(정확한 직사각형이라고 거짓 표기 금지).
4. 색칠 넓이 4방법 모두 **실제 독립 Region** 분할·이동·뺄셈·합산 + 역재생.
5. 분할/이동 전후 보존되는 넓이와 달라질 수 있는 외곽 둘레를 구분.
6. 둘레의 모든 외곽 segment의 색/길이/범례가 일치, 임의 가중치 없음.
7. 모바일 360/390/430/768px, PC에서 조작·수식·버튼/스크롤·다크 칠판 가독성 검사.
8. 기존 운영 링크는 신규 단원이 실제 브라우저·수학 검수를 통과하고 전환 승인될 때 교체. 기준 미달 시 기존 원과 부채꼴 운영본을 유지.

## F. 최종 개발 패키지

**한 개의 새 「원과 부채꼴」 단원 화면 + 학습 구역 6개 + 공통 기본형 5종 + 면/경계 모델 + 네 가지 색칠 넓이 실험 + 실경계 둘레 체험**을 한 번의 개편 범위로 정의한다. 내부 구현은 기능별로 진행하더라도 유형별 조각 PR을 반복하지 않고, 최종 검증된 통합판만 운영 전환한다.

문서만으로는 구현 PASS가 아니다. **현재 단계는 설계 확정안이며 코드는 아직 변경하지 않았다.**
