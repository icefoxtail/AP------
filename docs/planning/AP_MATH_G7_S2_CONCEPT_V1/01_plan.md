# 01. 점·선·면·각 — 개념·도형 연결 계획 v1.0

**대표 화면**: points-lines.html  
**개편 목적**: 점·직선·반직선·선분·각·맞꼭지각·이등분선의 정확한 뜻을 먼저 보여준다.

## 필수 개념·암기

- 선분 AB=BA, 반직선 AB와 BA는 일반적으로 다름
- 맞꼭지각은 같음
- 평각 180°, 한 바퀴 360°.

## 도형의 필수 움직임

- 두 점 이동으로 직선·반직선·선분을 비교, 맞꼭지각 실시간 수치, 각의 이등분 도형.

## 꼭 보여줄 오개념·반례

- 반직선 방향 오개념, 선분과 직선 혼동, 이웃한 각을 맞꼭지각으로 착각.

## 완료 판정

기존 4모드와 조작 유지, 개념 설명과 도형을 첫 화면에 연결; 학생이 같은 반직선/다른 반직선을 조작으로 설명.

**수정 규칙**: 기존 동작을 삭제하지 않고 기본 개념의 진입 순서와 도형 연결을 보강한다. 기존 수학 공식·좌표 계산·모바일 인터랙션 보존, 실제 렌더링/수치 검증 전 PASS 금지.
