# 07. 다면체·정다면체 5종의 모든 필수 개념 — 개념·도형 연결 계획 v1.0

**기존 파일**: polyhedra.html / nets-folding.html / 다면체·회전체&겨냥도·전개도.html  
**원칙**: 교과서 정의·암기→움직이는 장면→반례→문제→심화. 기존 계산·애니메이션·해설 보존.

## 필수 개념

- 다면체·면(F)·모서리(E)·꼭짓점(V) 및 각기둥·각뿔·각뿔대
- 정다면체 조건: 모든 면이 합동인 정다각형, 꼭짓점에 모이는 면의 수가 같다
- 정다면체 다섯 종, 3D 회전, 전개도, 꼭짓점의 정다각형 모임
- 볼록 다면체 오일러 공식 V−E+F=2
- 꼭짓점 평면각 합이 360° 미만이라는 필요조건과 정다면체의 5개 존재

## 꼭 암기할 내용

- 정사면체: 정삼각형, (F,E,V)=(4,6,4), 한 꼭짓점 3면
- 정육면체: 정사각형, (6,12,8), 한 꼭짓점 3면
- 정팔면체: 정삼각형, (8,12,6), 한 꼭짓점 4면
- 정십이면체: 정오각형, (12,30,20), 한 꼭짓점 3면
- 정이십면체: 정삼각형, (20,30,12), 한 꼭짓점 5면

## 연결할 움직이는 도형 / 데이터 시각화

- 정다면체 5개 중 하나 선택→실제 회전 3D와 암기 카드(F/E/V, 면 도형, 꼭짓점 모임) 동시 출력
- 면·모서리·꼭짓점 렌즈를 탭하면 실제 구성 요소 한 개씩 강조 및 개수 확인
- 꼭짓점 선택→만나는 면 수 3/4/5 실시간 시각화
- 정삼각형 3~6개, 정사각형 3~4개, 정오각형 3~4개를 펴서 왜 360° 이상이면 접히지 않는지 실험
- 기존 정사면체·정육면체·정팔면체·정십이면체·정이십면체의 전개도·3D 접기 동작 연결
- 정육면체↔정팔면체, 정십이면체↔정이십면체 쌍대관계는 심화

## 완료 판정 기준

- 5종 도형·도형명·면 도형·F/E/V·꼭짓점 모임 수 모두 일치
- 암기 카드가 3D 모델과 같은 화면에 표시
- 정다면체 5개가 존재하는 이유와 불가능 예 설명
- 서로 다른 3D HTML의 기능은 삭제 없이 대표 화면에 링크

## 실행 범위

개념/암기 카드와 도형의 상태값을 같은 데이터에 연결하고, 이미 존재하는 심화 모드는 삭제하지 않는다. 정적인 그림만 붙이거나 계산과 그림이 다른 상태는 FAIL. 모바일 조작과 다크 칠판 디자인을 보존한다.
