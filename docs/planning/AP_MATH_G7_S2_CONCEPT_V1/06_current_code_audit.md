# 06. 원과 부채꼴 현재 코드 실측 감사 (2026-10-27)

**범위**: `apmath/playground/labs/g7/원과_부채꼴_통합_마스터_스튜디오.html` 현재 `main` blob `3f96a50cb557f9545b938c5e5c7a2ba49d304319`. 원본 HTML의 스크립트 영역·가장 최근 화이트 버전과 비교함. 브라우저 렌더링/사용자 기기 재현은 별도이다.

## 실제로 존재하는 구현 (보존 대상)

- `SUB_MENUS`: 4모드 × 4서브 = 16개 유형 (원 구성, 원 넓이 펼치기, 부채꼴, 나뭇잎, 태극, 파인 반원 둘레, 굴리기 등).
- `render()`: `showArea`, `showPerim`, `showAux` 별 레이어 상태를 이미 가진다. 기초 설계는 재사용한다.
- `pizza` 유형은 **16개 부채꼴 조각을 개별로 이동·회전시키는 실제 처리**가 있다. 단, 조각 16개로 만들어지는 곡선형 윤곽은 직사각형과 정확히 일치하지 않으므로 극한의 직관을 설명해야 한다.
- 일부 `leaf`, `yin`, `bitten`, `track`에 서로 다른 색의 호/직선 stroke가 있다.
- 이전 작업의 모바일 Pointer Events, 터치 패닝/핀치, 반응형 도구 DOM 이동·복귀는 별도 구현이므로 보존한다.

## 회귀 여부의 정확한 구분

- 최신 다크 테마 `main`과 앞선 화이트 버전 `3b346d5d32d66dc49da10562a8d85cc0021fad63`을 비교하면 `leaf`의 **조각 분리 기능은 그때도 구현돼 있지 않았다.** 따라서 최근 다크 테마 수정 때문에 잃은 기능이라고 단정할 수 없다.
- 다만 `drawTapeMeasure` 라벨 글씨는 현재 어두운 색이어서 **지금 다크 테마에서 가독성이 나쁘다.** 이 부분은 테마 변경과 함께 바로 고쳐야 한다.
- 더 오래된 외부 HTML/배포 화면까지는 이번 감사에서 전수 비교하지 않았으므로 **전체 개발 이력의 회귀가 없었다**고 주장하지 않는다.

## 보완 규칙

- 교재 이미지는 **유형·도형 관계의 시각적 참조**로 쓰고, 정확한 좌표·각·반지름은 다시 수학적으로 구성한다.
- 기존 잘 작동하는 장면(`pizza`, 조건 드래그, 3D와 무관한 원호 계산)은 최대한 재사용하되, 정적 수식에 그친 `leaf`의 면 분할은 새로운 기능으로 구현한다.
- 수식·도형·둘레는 모두 공유한 Geometry/Region/Boundary 정의에서 유도한다.
- 이 문서는 코드 수준 감사다. 실제 모바일 스크린샷·브라우저 시뮬레이션/수학 수치 비교를 수행하기 전 시각 PASS로 표시하지 않는다.
