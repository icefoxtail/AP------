# 10. 통계 — 자료의 정리와 해석(독립 영역) — 개념·도형 연결 계획 v1.0

**기존 파일**: 현재 중1 도형 허브의 전용 HTML 없음  
**원칙**: 교과서 정의·암기→움직이는 장면→반례→문제→심화. 기존 계산·애니메이션·해설 보존.

## 필수 개념

- 대푯값 평균·중앙값·최빈값
- 줄기와 잎 그림, 도수분포표, 계급값
- 히스토그램, 도수분포다각형
- 상대도수 = 도수/전체 도수, 상대도수의 합=1
- 통계적 문제 해결과 자료 해석

## 꼭 암기할 내용

- 중앙값은 크기순 정렬 후 선정
- 평균은 극단값 영향을 받을 수 있다
- 상대도수는 다른 규모 집단 비교에 적합
- 히스토그램과 막대그래프의 표현 대상·의미 구별

## 연결할 움직이는 도형 / 데이터 시각화

- 원자료 값 변화 → 대푯값 세 개 동시 갱신
- 자료→줄기와 잎 그림→도수분포표→히스토그램 동기화
- 서로 다른 집단의 도수 vs 상대도수 그래프 비교
- 계급 클릭 시 원자료까지 역추적

## 완료 판정 기준

- 중1-2 전체 범위에는 포함하되 3D 도형 실험실에 억지로 삽입 금지
- 도수합·상대도수합·그래프 실제 값 일치
- 통계 독립 탭 또는 허브 카드로 별도 연결

## 실행 범위

개념/암기 카드와 도형의 상태값을 같은 데이터에 연결하고, 이미 존재하는 심화 모드는 삭제하지 않는다. 정적인 그림만 붙이거나 계산과 그림이 다른 상태는 FAIL. 모바일 조작과 다크 칠판 디자인을 보존한다.
