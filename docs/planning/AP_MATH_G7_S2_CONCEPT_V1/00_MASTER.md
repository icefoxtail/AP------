# 중등 도형실험실 통합 정본

기준일: 2026-11-05  
범위: AP Math Playground 중등 도형실험실의 학습 경험과 품질 기준. 지금의 실행 우선순위는 **중1**이다. 중2·중3 확장은 중1을 정리하고 재설계를 진행한 뒤로 미룬다. 통계는 이 도형 학습 범위에 넣지 않는다.

이 문서는 흩어진 개념 계획·교재 조사·도형 사전·영상 설계와 선생님의 최근 화면 검토를 한곳에서 잇는 상위 정본이다. 아래에 과거 MASTER v1.1 전문을 이력으로 보존한다. 각 상세 문서의 수학적 근거와 이력을 지우지 않는다. **이 정본과 과거 계획이 충돌하면 최근 사용자 결정과 이 문서가 우선**하며, 상세 문서의 오래된 파일명·진행 상태·우선순위·색상·화면 구조는 현재 구현 사실로 간주하지 않는다. 다른 프로젝트의 승인·운영 규칙을 바꾸지 않는다.

## 1. 목표와 원칙

- 처음 배우거나 도형이 어려운 학생은 그림을 만지며 뜻을 이해하고, 이미 아는 학생은 필요한 기본·심화 유형으로 바로 갈 수 있다.
- 수량이나 속도보다 **정확성, 학생 이해, 실제 사용 경험, 시각적 완성도**가 우선이다. 형식적으로 장면 수만 늘려 완료 처리하지 않는다.
- 장면을 움직이며 탐구하는 경험을 보존하고 문제를 그 위에 연결한다. 선생님이 언급하지 않은 부분도 학생 관점에서 직접 보고 필요한 개선을 판단한다.
- 수학적 상태·그림·문제 조건·보기·정답·해설·단위가 서로 일치해야 한다. 계획·자동 검사 통과만으로 학생 경험이나 전체 수학 검수 완료라고 표시하지 않는다.
- 이미 유효한 자료와 검수 근거를 보존한다. 중복·불필요한 기초 내용과 내부 제작 문구는 실제 학습상 역할을 살핀 뒤 정리한다.

## 2. 학생이 배우는 구조

단원마다 **개념 / 기본 / 심화**를 구분한다. 이것은 난도와 학습 목적의 구분이지 강제 순서나 새 장면 수 목표가 아니다. 학생은 원하는 단계에 바로 들어가고, 기본·심화에서 막히면 관련 개념으로 돌아갈 수 있어야 한다. 개념을 따로 배울 수 있게 하되 기존 장면과 역할이 겹치면 재사용·통합하고, 기존 장면을 그대로 세 묶음에 복제하지 않는다.

1. **개념:** 이름과 정의, 조건, 무엇이 선이고 면인지, 성질이 왜 성립하는지 움직이는 도형으로 보여준다. 대표 반례와 흔한 오개념을 짚는다.
2. **기본:** 교과서 수준의 대표 유형으로 개념을 적용하고 그림·식·단위를 연결한다.
3. **심화:** 여러 성질을 결합하거나 새 단면·숨은 면·역산 등에서 판단한다. 필요한 개념과 기본 유형으로 연결한다.
4. **찾아보기:** 도형 사전의 정의·성질·판정 조건과 서술형 표현을 필요한 순간 찾아보고 실험실로 돌아오게 한다. 사전 설계가 구현·검수 완료라는 뜻은 아니다.

중1 계획의 아홉 주제는 점·선·각, 위치관계와 평행선, 작도, 합동, 다각형, 원과 부채꼴, 다면체, 회전체·단면·전개도, 겉넓이와 부피다. 이 목록은 학습 범위를 잡기 위한 것이며 과거 문서가 말한 파일 소유자나 신규 화면 부재를 현재 상태로 확정하지 않는다. 작도의 성립 불가능과 조건 불충분, 합동의 대응과 반례를 구분한다. 중2·중3에는 같은 원칙을 나중에 적용하되 범위·장면·일정은 별도 검토한다.

## 3. 그림과 조작의 공통 기준

- 기본 화면은 흰 바탕에 교과서처럼 선명하고 차분한 선을 우선한다. 기본 도형은 정돈된 비율과 익숙한 약간 위쪽 시점으로 처음부터 보기 좋게 배치한다. 황금비를 일괄 강제하지 않고 실제 화면과 수학적 의미를 보고 판단한다.
- 색은 필요한 부분을 구분할 때만 눈에 부담 없는 연한 강조로 사용한다. 색만으로 의미를 전달하지 않고 선·면·문구와 연결한다. 점·버튼·슬라이더도 차분하게 맞춘다.
- 선분·반지름·높이 등의 치수선은 실제 구간을 정확히 가리키고, 곡선 치수 표시는 도형 안으로 부자연스럽게 침범하지 않도록 한다. 숫자는 해당 선 위나 곁에 놓고 라벨끼리 겹치지 않게 한다. 작은 각호와 직각 표시를 상황에 맞게 사용한다.
- 선과 면은 서로 다르다. **둘레 원클릭은 실제 경계선**, 넓이 원클릭은 해당 면을 보여준다. 구멍이 있으면 안쪽 경계도 둘레이며, 내부 보조선이나 붙어서 내부가 된 접합선은 제외한다. 면의 분할·이동 전후 넓이와 경계 변화는 구별한다.
- 겉넓이는 한 번 눌러 전개·분해된 실제 외부 면과 식을 연결하고, 부피는 한 번 눌러 잘리거나 분해된 입체와 식을 연결한다. 구의 곡면은 억지 평면 전개도로 설명하지 않는다. 원래 입체는 별도 탭 없이 함께 보이고, 비교할 도형과 크기를 균형 있게 맞추며 애니메이션이나 화살표로 변화를 이해하게 한다.
- 반구 단독은 곡면이 구의 겉넓이 절반임을 설명하고 바닥 포함 여부를 분명히 한다. 원기둥 위 반구처럼 붙은 면은 내부 접합면이므로 외부 겉넓이에 더하지 않는다. 잘라 새로 생긴 단면은 실제로 드러난 경우 겉넓이에 포함한다.
- 잘린 면은 기본 시점에서 바로 보이도록 직접 회전해 가장 이해하기 좋은 각도를 고른다. 드래그 회전을 우선하며 앞·옆·위 버튼이나 단순 크기 배율 등 학습에 불필요한 조작은 정리한다.
- 전개도·겨냥도·원래 입체의 크기와 여백은 균형 있게 배치한다. PC·태블릿에서 그림과 관련 식이 함께 들어오고 모바일에서도 잘리거나 조작이 막히지 않아야 한다. 수식은 LaTeX/KaTeX 등으로 읽기 좋게 조판하고, 항목명 다음 줄에 식이 시작되게 한다. 도형 옆 중복 계산·설명은 학습상 필요할 때만 둔다.
- 팁은 항상 고정하지 않고 현재 장면·선택 상태에 맞게 필요한 때 보여준다. 예: 숨은 접합면, 새로 생긴 절단면, 선과 면, π항과 상수항의 구분.

## 4. 겉넓이·부피의 구성과 응용

교재의 학습 흐름을 출발점으로 **기둥 / 뿔 / 구 / 여러 가지 도형**의 네 큰 묶음을 검토한다. 원기둥·원뿔 등 혼합과 각뿔대는 관련 묶음 또는 네 번째 응용 묶음에 학습 목적에 따라 배치한다. 입체의 분류·관찰 자체는 겉넓이·부피와 구분한다. 삼각뿔·사각뿔 등 기본형을 빠뜨리지 않으며 붙인 사각기둥과 사각뿔은 보기 좋은 정사각형 밑면을 기본으로 검토한다. 실험 가능한 치수는 수학·그림이 성립하는 범위에서 자연스럽게 바꾸고 불필요한 3·6의 배수 제한을 기본값으로 삼지 않는다.

후속 후보는 수량 목표가 아니다. 원뿔 굴리기와 원기둥 속 같은 구 2개·3개 등은 기존 장면과 교재 근거를 먼저 대조한다. 원뿔 예시에서 모선 6, 밑면 반지름 1이면 미끄럼 없이 한 번 굴릴 때 진행한 호는 밑면 둘레 2π, 고정된 꼭짓점 주위 반지름 6인 원의 전체 둘레는 12π이므로 6바퀴다. 한 번의 자전과 전체 한 바퀴 이동을 구별하고 움직임으로 보여준다. 구 예시는 구가 원기둥의 밑면과 서로 접하는 같은 크기라면 높이 4r 또는 6r임을 보여주고 주어진 원기둥 부피에서 r을 찾는 흐름으로 검토한다. 각 후보는 실제 교과 적합성과 조건을 검증한 뒤 하나씩 진행한다.

## 5. 짧은 개념·문제 영상

영상은 긴 강의가 아니라 **짧은 쇼츠형 설명**이다. 기존 [영상 대본 지침](../../guides/APMATH_LAB_VIDEO_SCRIPT_GUIDE_CURRENT.md)의 8~15초·목표 12초, 핵심 하나, 짧은 자막, 그림과 설명의 시간 일치를 출발점으로 삼는다. 영상 후 같은 도형을 직접 움직일 수 있게 하고, 멈춤·느리게·다시 보기와 접근성을 살핀다. 문제 영상은 고정한 대표 예시와 실제 문항 조건·정답 공개 흐름이 맞아야 한다. 영상 길이의 과거 15~30초 제안보다 현재 쇼츠 기준을 우선한다.

기존 실험실 재생기와 두 12초 시제품의 근거는 [영상 인계](../../guides/APMATH_G7_EXAM_VIDEO_HANDOFF_CURRENT.md)에 있다. 별도 완성 영상 제작 도구 [HyperFrames](https://github.com/heygen-com/hyperframes)와 음성 후보 [VoiceStudio](https://github.com/debpalash/VoiceStudio)는 추후 비교·시범 검토한다. 한국어 수학 발음, 자막·그림 동기화, 라이선스 및 환경 요구는 실제 사용 전에 확인한다. 도구가 검증되거나 설치되었다는 뜻은 아니며, 학생의 직접 조작을 영상으로 대체하지 않는다.

## 6. 작업 순서와 개별 품질 통과

1. 현재 진행 중인 **중1 기존 도형 정리와 실제 화면 검수**를 마친다. 기존 작업의 실제 상태를 확인하고 미완료를 완료로 적지 않는다.
2. 기존 장면·문제 각각의 학습 목표를 살펴 개념·기본·심화로 분리하고 중복을 정리한다. 관련 개념과 문제의 연결을 설계한다.
3. 교재 대응표·사전·기존 계획과 대조해 빠진 유형만 우선순위를 정한다. 한 번에 많이 넣지 않는다.
4. 신규 장면 또는 문제 **하나씩** 만들고 수학·교육과정·학생 이해·그림·동작·문제/풀이·화면을 확인하여 품질 기준을 통과한 다음에 다음 항목으로 간다.
5. 중1이 충분히 정리된 뒤 중2·중3 확장을 다시 결정한다. 학생 배포는 별도 실제 상태를 확인하며 서두르지 않는다.

개별 검수에는 기본값과 변경값, 경계값, 직접 누르기·드래그·전개·분해·되돌리기, 문제 생성·정답 공개·해설의 일치, PC·태블릿 가로/세로·모바일 가독성과 입력을 포함한다. 모든 장면의 화면을 실제로 열어 살피고, 확인한 범위와 실행하지 못한 범위를 분리한다. 그림·시각 품질은 자동 검사로 대체하지 않는다. 완료 보고는 단원별 수정 사항과 확인 범위·남은 결함을 밝힌다.

이 문서는 **방향과 품질 기준**이다. 현재 작성 중인 로컬 화면이 main 또는 학생 사이트에 반영됐다는 뜻이 아니며, 어떤 검수·배포도 이 문서만으로 완료되지 않는다.

## 학생 화면 공통 학습 순서

1. **개념/용어 확인**: 학생이 가리키면 도형의 해당 점·선·면만 강조된다.
2. **필수 암기/성질**: 정의, 조건, 왜 성립하는지, 예외와 단위를 명확히 보여준다.
3. **선·면의 실제 변형**: 단순 도형 위치 이동이 아니라 해당 영역을 분할/이동/합성하고 경계선을 식별할 수 있어야 한다.
4. **오개념·반례**: 불가능과 조건 불충분, 겉으로 만나는 것과 실제 교점, 호와 현, 넓이와 둘레 등 혼동 해결.
5. **기본 확인 → 교과서 유형 → 기존 심화 장면** 순서로 진입한다.

## 면적과 둘레의 공통 시각화 계약

- **색칠한 영역은 기하적으로 정의한 면(Region) 자체를 렌더링**한다. 겹침과 뺄셈은 실제 영역으로 계산/표현한다.
- **둘레는 해당 색칠 영역의 실제 바깥 경계(Boundary)**만 따라 칠한다. 내부 보조선·직접 이어붙인 내부 접합선·색칠하지 않은 원주는 둘레에서 제외한다.
- 각 둘레 구간을 호/선분으로 구분해 색을 부여하고, 화면의 강조 구간 ↔ 범례 ↔ 길이 ↔ 둘레 계산식이 일치해야 한다.
- 조각 이동·회전 중 **조각별 면적 보존**과 합성 후 **전체 면적 일치**를 검증한다. 이동 전후 경계(둘레)는 달라질 수 있으므로 자동으로 보존된다고 말하지 않는다.
- `렌즈: 넓이/둘레/보조선`은 서로 다른 의미의 시각화 레이어다. 넓이 렌즈가 둘레 색칠만 보여주거나 둘레 렌즈가 면 색칠만 보여주면 실패.
- 실제 수학 좌표·각도·호 반지름을 단일 데이터 원천으로 사용한다. 임의 가중치/직접 그린 정적 대체 이미지 금지.
- 모바일 터치, PC 레이아웃, 기존 16개 원 시나리오 및 다른 도형 실험실 기능은 독립적으로 보존한다.
