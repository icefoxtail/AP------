## 변경 목적

현재 중1 실험실은 응용 도형과 3D 조작이 강하지만 개념 → 암기 → 도형으로 확인 → 반례 → 기본문제 → 심화 순서가 약하다. **기존 HTML·수학 계산·모바일 조작은 보존**하고, 우선 개념 소유자와 개념 화면의 순서를 확정한다. 문서만 추가하며 이번 PR에서 HTML은 변경하지 않는다.

## 단원 화면 공통 계약

1. 화면 순서: **정의/용어 → 필수 암기 → 직접 조작하는 도형 → 왜 그런지·반례 → 기본 확인 → 기존 기출/심화**.
2. PC에선 개념 카드·암기 카드와 움직이는 도형을 나란히 표시; 모바일에서는 터치 44px 이상·스크롤/드래그 충돌 방지.
3. 같은 색상은 같은 개념 요소에 사용하고, 선·면·숫자·공식은 **실제 상태값**과 동기화한다.
4. "작도 불가능"(조건 충족 불가)과 "유일한 도형으로 결정 불가"(조건 부족)를 혼동하지 않는다.
5. 정다면체 5종은 도형 선택 즉시 이름, 면 모양, F/E/V, 꼭짓점에 만나는 면 수, 전개도를 보여준다.
6. 기존 8개 실험실의 도형, 탭, 렌즈, 해설, 모바일 최적화·다크 테마는 보존. 기능 삭제/통합 엔진 재구축 금지.
7. 기하 개념과 통계는 학기 범위에 포함하되 별도 실험실 소유자로 구분한다.

## 기존 HTML 소유자

- 기본 도형: `points-lines.html`; 위치관계: `spatial-relations.html`
- 다각형: `polygons-area.html`; 원의 구성요소: `원과_부채꼴_통합_마스터_스튜디오.html`
- 다면체·정다면체: `polyhedra.html`; 전개도 3D: `nets-folding.html`
- 회전체·단면·겨냥도: `다면체·회전체&겨냥도·전개도.html`; 겉넓이·부피: `입체도형의 겉넓이와 부피.html`
- 3D 중복 내용은 한 대표 소유자를 정하고 다른 페이지에서는 **연결만 추가**, 삭제하지 않는다.
