## 학생 화면 공통 학습 순서

1. **개념/용어 확인**: 학생이 가리키면 도형의 해당 점·선·면만 강조된다.
2. **필수 암기/성질**: 정의, 조건, 왜 성립하는지, 예외와 단위를 명확히 보여준다.
3. **선·면의 실제 변형**: 단순 도형 위치 이동이 아니라 해당 영역을 분할/이동/합성하고 경계선을 식별할 수 있어야 한다.
4. **오개념·반례**: 불가능과 조건 불충분, 겉으로 만나는 것과 실제 교점, 호와 현, 넓이와 둘레 등 혼동 해결.
5. **기본 확인 → 교과서 유형 → 기존 심화 장면** 순서로 진입한다.

## 면적과 둘레의 공통 시각화 계약

- **색칠한 영역은 기하적으로 정의한 면(Region) 자체를 렌더링**한다. 겹침과 뺄셈은 실제 영역으로 계산/표현한다.
- **둘레는 해당 색칠 영역의 실제 바깥 경계(Boundary)**만 따라 칠한다. 내부 보조선·직접 이어붙인 내부 접합선·색칠하지 않은 원주는 둘레에서 제외한다.
- 각 둘레 구간을 호/선분으로 구분해 색을 부여하고, 화면의 강조 구간 ↔ 범례 ↔ 길이 ↔ 둘레 계산식이 일치해야 한다.
- 조각 이동·회전 중 **조각별 면적 보존**과 합성 후 **전체 면적 일치**를 검증한다. 이동 전후 경계(둘레)는 달라질 수 있으므로 자동으로 보존된다고 말하지 않는다.
- `렌즈: 넓이/둘레/보조선`은 서로 다른 의미의 시각화 레이어다. 넓이 렌즈가 둘레 색칠만 보여주거나 둘레 렌즈가 면 색칠만 보여주면 실패.
- 실제 수학 좌표·각도·호 반지름을 단일 데이터 원천으로 사용한다. 임의 가중치/직접 그린 정적 대체 이미지 금지.
- 모바일 터치, PC 레이아웃, 기존 16개 원 시나리오 및 다른 도형 실험실 기능은 독립적으로 보존한다.

1. 먼저 `06` 한 단원의 개념·도형 시나리오 데이터·선과 면 레이어를 정본으로 만든다.
