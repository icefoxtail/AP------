# 03. 삼각형 작도·왜 불가능한가 — 개념·도형 연결 계획 v1.0

**대표 화면**: 신규(전용 실험실 없음)  
**개편 목적**: 자·컴퍼스로 삼각형이 실제 성립하는가와 조건으로 유일하게 결정되는가를 분리한다.

## 필수 개념·암기

- 세 변 삼각부등식
- SSS·SAS·ASA
- SSA는 일반 합동조건이 아님(0·1·2개 가능)
- AAA는 크기 미결정.

## 도형의 필수 움직임

- 두 원 교점 0·1·2개와 SSS 작도
- 양 끝각 합≥180° 실패
- SSA 0·1·2개
- AAA 확대 축소.

## 꼭 보여줄 오개념·반례

- 삼각형이 안 만들어지는 경우와 여러 삼각형이 가능한 경우의 혼동
- SSA를 언제나 2개라고 단정.

## 완료 판정

새 화면은 가능/불가능/결정 불충분 3분류, 실제 원호·교점·조건·경고를 연동; 가짜 경고·정적 삽화 금지.

**수정 규칙**: 기존 동작을 삭제하지 않고 기본 개념의 진입 순서와 도형 연결을 보강한다. 기존 수학 공식·좌표 계산·모바일 인터랙션 보존, 실제 렌더링/수치 검증 전 PASS 금지.
