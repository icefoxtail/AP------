# 05. 다각형·대각선·내각·외각 — 개념·도형 연결 계획 v1.0

**대표 화면**: polygons-area.html  
**개편 목적**: 복잡한 별모양·넓이 응용보다 다각형 정의와 내각·외각 원리를 먼저 노출한다.

## 필수 개념·암기

- 한 꼭짓점 대각선 n-3
- 전체 n(n-3)/2
- 내각합 (n-2)×180°
- 볼록다각형 외각합 360°
- 정n각형 외각 360°/n.

## 도형의 필수 움직임

- n=3~12 가변 다각형
- 대각선의 중복 2번 카운트
- n-2개 삼각형 분할
- 한 바퀴 회전 외각합.

## 꼭 보여줄 오개념·반례

- 대각선 두 번 세기, 정다각형의 변/각 조건 누락, 외각합을 n에 따라 달라진다고 오해.

## 완료 판정

기존 복잡한 응용은 삭제 없이 심화로 이동; 필수 공식이 실제 도형 조작값과 일치해야 PASS.

**수정 규칙**: 기존 동작을 삭제하지 않고 기본 개념의 진입 순서와 도형 연결을 보강한다. 기존 수학 공식·좌표 계산·모바일 인터랙션 보존, 실제 렌더링/수치 검증 전 PASS 금지.
