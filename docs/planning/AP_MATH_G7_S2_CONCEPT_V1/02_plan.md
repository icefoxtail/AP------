# 02. 위치관계·평행선 성질 — 개념·도형 연결 계획 v1.0

**대표 화면**: spatial-relations.html;points-lines.html  
**개편 목적**: 평면 두 직선과 공간 두 직선의 위치관계를 분리하고 평행선 동위각·엇각의 성질·역을 연결한다.

## 필수 개념·암기

- 평면 관계 교차·평행·일치
- 공간에서 꼬인 위치 존재
- 두 직선이 평행할 때 동위각·엇각 같음
- 각이 같으면 평행이라는 역.

## 도형의 필수 움직임

- 3D 회전으로 꼬인 위치와 겉보기 교차 구별
- 평행선과 횡선 드래그로 대응각 쌍을 실시간 강조.

## 꼭 보여줄 오개념·반례

- 공간에서 만나지 않으면 무조건 평행이라는 오류
- 평행 가정이 없는데 각이 같다는 결론.

## 완료 판정

기존 공간관계 실험실 유지, 평행선 기초 조작을 앞에 연결; 학생이 각 쌍과 평행 조건을 판별.

**수정 규칙**: 기존 동작을 삭제하지 않고 기본 개념의 진입 순서와 도형 연결을 보강한다. 기존 수학 공식·좌표 계산·모바일 인터랙션 보존, 실제 렌더링/수치 검증 전 PASS 금지.
