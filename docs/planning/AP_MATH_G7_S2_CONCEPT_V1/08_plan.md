# 08. 회전체·겨냥도·전개도·단면 — 개념·도형 연결 계획 v1.0

**기존 파일**: 다면체·회전체&겨냥도·전개도.html / nets-folding.html  
**원칙**: 교과서 정의·암기→움직이는 장면→반례→문제→심화. 기존 계산·애니메이션·해설 보존.

## 필수 개념

- 회전체 정의와 회전축
- 직사각형→원기둥, 직각삼각형의 직각변 회전→원뿔, 반원 지름 회전→구
- 축에 수직인 단면과 축을 포함하는 단면
- 원기둥 전개도: 옆면 직사각형 너비=2πr
- 원뿔 전개도: 옆면 부채꼴 호 길이=밑면 원주 2πr
- 모선·높이의 정확한 차이

## 꼭 암기할 내용

- 구는 다면체가 아니다
- 원뿔 모선과 높이의 길이는 일반적으로 다르다
- 원기둥의 직사각형 옆면 가로 길이는 밑면 원주 2πr

## 연결할 움직이는 도형 / 데이터 시각화

- 회전축에 대해 0~360° 회전하면서 도형을 연속 생성
- 단면 방향 선택에 따른 3D 절단면 갱신
- 원기둥/원뿔 펼침에서 길이·호·면 대응 같은 색 매칭
- 겨냥도의 뒤쪽 모서리 점선 토글

## 완료 판정 기준

- 회전체 3종의 발생 도형과 실제 3D 일치
- 전개도 옆면과 밑면의 길이·호 길이 일치
- 기존 전개도·최단거리 심화는 제거하지 않고 연결

## 실행 범위

개념/암기 카드와 도형의 상태값을 같은 데이터에 연결하고, 이미 존재하는 심화 모드는 삭제하지 않는다. 정적인 그림만 붙이거나 계산과 그림이 다른 상태는 FAIL. 모바일 조작과 다크 칠판 디자인을 보존한다.
