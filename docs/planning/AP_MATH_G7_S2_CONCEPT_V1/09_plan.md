# 09. 입체도형 겉넓이·부피 — 개념·도형 연결 계획 v1.0

**기존 파일**: 입체도형의 겉넓이와 부피.html  
**원칙**: 교과서 정의·암기→움직이는 장면→반례→문제→심화. 기존 계산·애니메이션·해설 보존.

## 필수 개념

- 겉넓이=외부 면의 넓이 합, 부피=점유 공간
- cm²와 cm³의 의미·단위
- 기둥 부피=밑넓이×높이, 뿔 부피=밑넓이×높이÷3
- 원기둥 겉넓이=2πr(r+h)
- 원뿔 겉넓이=πr(r+l), 모선 l·높이 h 구별
- 구 겉넓이=4πr², 부피=4πr³/3
- 반구 곡면만 2πr², 바닥면 포함 3πr²

## 꼭 암기할 내용

- 기둥 : 뿔 부피 3:1은 같은 밑넓이와 높이에서 성립
- 겉넓이 계산 시 실제 드러나는 면만 센다
- 원뿔 높이는 겉넓이의 모선 자리에 쓰지 않는다

## 연결할 움직이는 도형 / 데이터 시각화

- 단위큐브 쌓기와 높이 변화→부피 숫자 동기화
- 원기둥·원뿔 전개도 펼침→구성 면 색칠과 면적 합산
- 동일 밑넓이·높이 기둥↔뿔 3:1 붓기
- 반구 바닥면 ON/OFF→2πr² vs 3πr²
- 구멍 뚫린 입체: 새로 드러난 안쪽 면 표시

## 완료 판정 기준

- 도형 조작·공식 결과·단위 완전 일치
- 반구의 바닥 포함/제외 명확
- 기존 복합 입체·아르키메데스 장면은 개념 이후 심화

## 실행 범위

개념/암기 카드와 도형의 상태값을 같은 데이터에 연결하고, 이미 존재하는 심화 모드는 삭제하지 않는다. 정적인 그림만 붙이거나 계산과 그림이 다른 상태는 FAIL. 모바일 조작과 다크 칠판 디자인을 보존한다.
