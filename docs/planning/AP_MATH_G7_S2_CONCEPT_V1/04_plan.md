# 04. 삼각형 합동·대응관계 — 개념·도형 연결 계획 v1.0

**대표 화면**: 신규(전용 실험실 없음)  
**개편 목적**: 두 삼각형 포개기로 합동을 이해하고 SSS·SAS·ASA가 왜 충분한지 확인한다.

## 필수 개념·암기

- 대응 꼭짓점과 대응 변·각 순서
- SSS, 두 변과 그 끼인각 SAS, 한 변과 양 끝각 ASA.

## 도형의 필수 움직임

- 겹치기 드래그
- SAS에서 끼인각 변경
- AAA는 같은 각인데 크기를 키워 반례
- SSA는 다른 삼각형 가능.

## 꼭 보여줄 오개념·반례

- SSA/AAA를 합동조건이라고 기억
- 넓이 같으면 합동으로 오해
- 대응 순서 오류.

## 완료 판정

각 조건별 1개 이상의 움직이는 예·반례, 학생이 조건을 클릭해 도형이 확정되는지 관찰.

**수정 규칙**: 기존 동작을 삭제하지 않고 기본 개념의 진입 순서와 도형 연결을 보강한다. 기존 수학 공식·좌표 계산·모바일 인터랙션 보존, 실제 렌더링/수치 검증 전 PASS 금지.
