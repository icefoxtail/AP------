# ALIVE LITE L4 확장 교육과정 HARD GATE v0.4

상위: ALIVE_GPT_LITE_MASS_EXPANSION_WORKER_CONTRACT_v0.3.md
적용: 모든 신규 L4 후보, 생성 문항, 학생용 해설. 기존 RPM 정본·original 변경 없음.

1. 생성 전에 실제 대상 교육과정/학년/학기/시험범위를 확정한다.
2. 신규 L4 발굴과 발문·보기·정답·해설은 목표 범위에 속하거나 이미 배운 선수개념만 사용한다.
3. 고1에는 고2 이후 선행 개념·미분·벡터·고등 삼각함수 공식 등을 끌어와 정답을 구하거나 해설하지 않는다. 중학교 닮음·피타고라스 등 이미 이수한 개념은 가능하다.
4. 문제 자체에 범위 밖 풀이를 필수로 요구하거나, 학생용 해설이 범위 밖 풀이를 사용하면 그 생성 후보를 반려하거나 해당 범위 안의 풀이로 다시 설계한다.
5. 신규 extension L4 후보에는 requiredConcepts, prerequisiteConcepts, curriculumScope, grade, term, curriculumGateStatus를 기록한다. 범위를 확인하지 못했을 때 PASS 금지.
6. 새 L4 후보는 기존 RPM L4와 별도 확장 레지스트리에만 저장한다. 교육과정 적합성이 확인되더라도 자동으로 canonical RPM L4로 승격하지 않는다.
7. 검수자는 문항과 해설의 범위 위반만 탐지하고 정상 작성자 메타는 반복 재분류하지 않는다. 범위 위반 문항은 수정 또는 제외하며, 다른 정상 문항 생산을 계속한다.
8. 출제량 목표 달성을 위해 상위 학년 개념을 도입하지 않는다. 교육과정 안에서 확장 가능한 유형 수가 적으면 shortage로 보고한다.
