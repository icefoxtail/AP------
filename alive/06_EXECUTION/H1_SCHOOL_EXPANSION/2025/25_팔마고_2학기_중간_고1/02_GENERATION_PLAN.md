# Generation plan

## Ownership and order

The locked source inventory is divided into seven non-overlapping Primary L2 batches. Each batch has one creator owner, and its exact source-qid set is frozen in `01_ADAPTIVE_BATCH_PLAN.json`. At most four CREATE workers run simultaneously. A completed L2 batch is frozen and handed to one independent REVIEW worker; the next pending L2 may start while that review proceeds. A source qid cannot be assigned twice. Scope is limited to this Palma exam; after it closes, stop for user quality review and wait before starting other schools.

## Candidate quality

For each eligible qid, the creator first explores relevant canonical RPM L4 structures and meaningful extensions, then records blueprint disposition before writing candidates. Every accepted candidate must change the mathematical decision, degrees of freedom, invariant, condition recovery, or intended student reasoning in a substantive way. Numeric/sign/name changes alone are instances of one blueprint, not new types. No output count is required.

Each candidate Markdown file will include student-facing prompt, choices or response contract, answer, full student-readable solution, canonical L1/L2 and verified RPM L3/L4, cross-concepts/conditions/integration only when real, independent difficulty fields, source qid and source SHA provenance, blueprint fingerprint, answer-position plan, and visual necessity/spec/status. Visual assets are produced only when mathematically necessary.

Source qids 11 and 16 remain HOLD because the locked source wording is ambiguous. The source file is read-only. q20's typo is recorded as provenance and will not be reproduced in generated copy.

## Review boundary

Review is performed by a different agent. For each batch, the reviewer receives a student-only packet containing the prompt, choices and required figures. The reviewer freezes an independent solution before seeing stored answers/solutions. Review then checks every choice, unique-answer cardinality, curriculum, L2/L3/L4 fit, explanation, novelty, difficulty, answer-position distribution and visual math fidelity. REJECT/HOLD candidates do not enter production; no regeneration loop is authorized.
