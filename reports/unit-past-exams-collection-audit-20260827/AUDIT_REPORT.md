## 우선순위별 발견사항

### P1 — 배포 전 수정 필요

1. **원래 오류 방지 로직이 아직 `origin/main`에 없음**
   - 로컬 변경은 `original/.../final/...` 같은 구형 경로를 `1final`/`2final` 후보로 보정한 뒤 문항 파일을 다시 읽음.
   - 이 변경과 캐시 버전 `20260827b`는 아직 미커밋 상태임.
   - 브라우저 검수는 이 로컬 변경을 포함한 화면에서 수행했으므로, 현재 배포 커밋이 같은 결과를 낸다고 볼 수 없음.

2. **일부 학교 자료 부족 시 전체 결과를 막던 문제** — 해결
   - 가능한 학교의 문제지는 유지하고, 부족 문항 수·학교별 자료 현황을 함께 표시한다.
   - `ok`는 후보 문제지 생성 가능 여부, `complete`는 요청 수 충족 여부로 분리했다.

3. **예방용 브라우저 QA가 CI에서 실행되지 않음** — 계약 연결 해결, 실제 브라우저 실행은 별도
   - `tests/archive-unit-past-exams-browser-qa-contract.test.js`가 `.mjs` 시나리오의 수집·핵심 selector·오류 검사를 CI에 연결한다.
   - 실제 브라우저 시나리오는 이번 로컬 검수에서 실행했으며, 전체 테스트의 기존 7건 실패는 별도 정리가 필요하다.

4. **메타데이터 누락을 실패시키지 않고 파일명으로 추론하던 문제** — 해결
   - 원본 시험지의 학년·과목·학교·연도·학기·시험 종류가 비어 있으면 인덱스 빌드 실패로 기록한다.
   - 후보가 아닌 기존 `similar/`, `types/` 레코드는 현재 데이터 구조를 보존하되 모아뽑기 범위에는 넣지 않는다.

### P2 — 기능 완성도 보강

1. 시험 시기(1/2학기, 중간/기말) 필터 — 해결.
2. 최근 3·5개년 학교별 `2/3개년`, `3/3개년` 충족률 — 해결.
3. 정답·해설 출력용 원본 학교/연도/시험 출처 전달 — 해결.
4. 단원 범위·연도 모드·특정 연도·최근 연도 수·시험 시기 selector 접근성 이름 — 해결.
5. 학교 검색·전체 선택·선택 해제 — 해결.

### P3 — 운영·표현 개선

1. 학교별 문제지 제목 번호가 학교마다 다시 시작하지 않고 전역 번호를 사용함.
2. 구현 계획서 상태 갱신 — 해결.
3. 최근 3개년 결과의 상단 합집합 연도와 학교별 실제 채택 연도 설명 — 해결.

## 증거 한계

- 학생 출제는 로그인 화면까지 확인했으며, 로그인 이후 반 배정·학생 수신은 확인하지 않음.

- 접근성은 DOM 이름과 키보드/반응형의 핵심 항목만 확인했으며 전체 WCAG 적합성 판정은 아님.
