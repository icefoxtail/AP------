2. 긴 풀이의 공백 밀도

왼쪽 순천고 q15는 빈 줄이 많아 풀이가 늘어진다. 오른쪽 금당고 q18은 거의 같은 해설 page layout에서 단계가 연속적으로 읽힌다.

3. 마지막 조각이 새 열이나 쪽으로 넘어가는 현상

순천고 q22는 두 열을 채워 이어진다. 금당고 q22는 대부분 17쪽에 들어가지만 끝의 짧은 조각만 18쪽으로 넘어간다.

4. 같은 문제가 아닌 대표 화면

두 문항은 내용이 다르며 같은 q 번호끼리의 수학 비교가 아니다. 이 줄은 재조판된 금당고에서 여전히 column balancing이 남는 것을 보여준다.
