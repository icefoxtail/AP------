[DeepSeek 해설 그림 필요 판정 — 시험지 하나, 판정만 한다]
위임 금지: 다른 모델·하위 에이전트에 넘기지 않는다. git 명령 금지. 그림을 만들거나 렌더하지 않는다. 판정만 한다.

[할 일]
아래 "대상 문항"마다 "학생 풀이를 돕는 해설 그림(SVG)이 필요한가"를 판정한다. 문항의 문제·정답·해설·기존 해설 그림 분류는 모두 아래에 들어 있다(파일을 따로 읽을 필요가 없다). 판단 기준은 "학생 풀이에 조금이라도 도움이 되면 만든다"이다.

[판정 값 — 정확히 이 중 하나]
- FIGURE: 해설 그림이 필요하다(기존 해설 그림 NONE 또는 MISSING_FILE). 함수·그래프·도형·좌표·통계 그래프·분포 곡선·수형도처럼 그림이 관계를 보여 주면 FIGURE다.
- REPLACE: 기존 해설 그림이 OLD_SVG 또는 OLD_PNG(구형)인데 그림이 필요한 문항. 구형은 새 엔진으로 다시 만든다. 그림이 필요 없는 순수 계산 문항이면 REPLACE가 아니라 EXEMPT다.
- KEEP_EXISTING: 기존 해설 그림이 NEW(신형)이고 해설과 맞는 문항.
- EXEMPT: 순수 계산이라 그림이 보탤 정보가 없다. 사유에 "무엇을 계산하는 문제라서 그림이 보탤 정보가 없다" 수준의 구체적인 한 줄을 쓴다. "그림이 필요 없다"만 쓰지 않는다.
- CONTENT: 문제·정답·해설이 서로 모순이거나 문항이 성립하지 않는다(근거 한 줄).

[과목별 기준]
- 함수·방정식·부등식·미분·적분·삼각함수·도형·좌표·원·이차곡선: 그래프나 도형이 풀이의 관계(교점·접선·넓이·구간·부호·대칭·보조선)를 보여 주면 FIGURE. 식 정리만으로 끝나는 계산(다항식 연산, 인수분해, 복소수 사칙, 극한·미분·적분의 기계적 계산)은 EXEMPT. 단, 극한·연속·미분계수·넓이처럼 그래프를 보면 이해가 되는 문항은 FIGURE다.
- 확률과 통계: 만든다 = 경우를 나열해 보여 주는 수형도, 정규분포·연속확률분포 곡선과 구간 넓이, 넓이로 푸는 확률밀도 그래프, 이산확률분포 막대, 칸 묶음을 강조하는 주사위 6x6 표, 사건 관계가 핵심인 벤다이어그램, 원순열 배치, 최단경로 격자. EXEMPT = 곱의 법칙·순열·조합·이항계수의 단순 계산(4x3, 5x4, 5P2 같은 것), 식만으로 끝나는 확률 계산, 해설에 이미 같은 나열이 있는 문항. 확률분포표·분할표 같은 표는 SVG가 아니라 해설 글 안의 표 엔진 몫이므로 EXEMPT로 하고 사유에 "표는 AP Table Engine"을 적는다. 해설 식을 그림으로 한 번 더 옮긴 것은 도움으로 보지 않는다.
- 해설 그림은 정답이 보여도 괜찮다. 풀이 과정 정보를 넣을 수 있으면 FIGURE다.

[출력]
결과를 JSON 파일 하나로 쓴다. 경로는 아래 `<OUT>/triage.json`. 형식(대상 문항 전부, 하나도 빠짐없이, 대상이 아닌 번호는 넣지 않는다):
{"items":[{"ord":3,"decision":"FIGURE","reason":"구체적인 한 줄 사유","family":"그래프"},{"ord":4,"decision":"EXEMPT","reason":"...","family":"계산"}]}
- ord는 대상 목록의 문항 번호(숫자)를 그대로 쓴다. decision은 위 5개 중 하나, reason은 비어 있지 않은 한국어 한 줄, family는 형태 한 단어(그래프·평면·입체·통계·확률·수식 등).
- 파일은 UTF-8로 쓴다. 셸 echo·리다이렉션·PowerShell을 쓰지 말고 Write 도구 또는 node/python의 파일 쓰기(encoding utf-8)를 쓴다. 쓴 뒤 다시 읽어 한글이 깨지지 않았는지, 문항 수가 맞는지 확인한다.
- 최종 메시지는 `<OUT>/triage.json` 경로 한 줄.
