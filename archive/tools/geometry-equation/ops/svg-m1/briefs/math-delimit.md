# 해설 수식 조판 복구 ($ 구분자 누락) + 지정 내용 결함 수정 (파일은 고치지 않고 수정안만)

이 시험지의 해설(solution)은 수식이 `$...$` 없이 적혀 있어 학생 화면에 `60^○`, `180^○-120^○` 같은 날것이 보인다(엔진은 `$` 밖의 `^`·`\circ` 등을 조판하지 않는다). 같은 저장소의 정상 시험지처럼 수식만 `$...$`로 감싼 해설로 바꾼다.

## 입력
- 시험지 JS: `{SRC}` (읽기만). 문항 묶음 `{PACKET}` (각 항목 `ord, content, choices, answer, solution, questionImage`; solution은 JS의 문자열 값 그대로).
- 참고할 정상 표기 예(읽기만): `/home/user/AP------/archive/exams/original/middle/m1/2mid/26_팔마중_2학기_중간_중1_기출.js`의 solution 몇 개.
- 지정 내용 결함 `{FLAGS}`(있으면): 이 문항들은 조판과 함께 내용도 고친다.

## 규칙
1. `$`가 하나도 없고 `\명령`·`^`·`_`·수식(등식, 각, 선분 이름, 분수 등)이 있는 solution만 대상. 이미 `$`가 있는 solution은 건드리지 않는다.
2. **문장(한글)은 그대로 두고 수식 덩어리만 `$...$`로 감싼다.** 예: `\angle EGF=120^\circ이므로` → `$\angle EGF=120^\circ$이므로`; `30\times0.2=6명` → `$30\times0.2=6$명`; `160\,\mathrm{cm} 이상` → `$160\,\mathrm{cm}$ 이상`; 선분·점 이름 `AB`, `GE=GF`도 수식이면 `$\overline{AB}$`가 아니라 원래 글자 그대로 `$AB$`, `$GE=GF$`처럼 감싼다(기호를 새로 바꾸지 않는다). `p\parallel q` → `$p\parallel q$`. 단위 `명`, `개`, `cm`(텍스트로 쓴 것) 등 한글·평문 단위는 `$` 밖에 둔다.
3. 줄바꿈(`\n`)과 문장 순서·숫자·정답은 바꾸지 않는다. 중괄호 없는 `\dfrac12` 같은 것은 `\dfrac{1}{2}`로 고친다. `$` 안에 한글을 넣지 않는다(필요하면 `\text{}` 대신 `$` 밖으로 뺀다).
4. FLAGS 문항은 수학적으로 옳은 근거로 해설 내용을 최소 수정한다(문체 유지, 정답 불변이면 정답 그대로).
5. 결과 문자열은 JSON 문자열 값으로 쓸 때 `\`가 올바르게 이스케이프되게 한다(파이썬 json.dump로 쓰면 자동).

## 출력 (이 파일 하나만)
`{OUT}` = content-check 형식 `[{"ord":N,"verdict":"DEFECT","finding":"수식 $ 구분자 복구(+내용 수정 요약)","patches":[{"field":"solution","old":"<packet의 solution 전체 그대로>","new":"<고친 solution 전체>"}]}]` — 대상 문항마다 하나. old는 packet의 solution과 **글자 하나까지 같아야** 한다(파이썬으로 packet을 읽어 그대로 넣는다).
작업은 python3 스크립트로 해도 되지만(스크립트·중간 파일은 `{SCRATCH}` 안에만), 각 문항의 수식 범위 판단은 직접 확인한다. 끝으로 OUT을 python으로 다시 읽어 old가 packet solution과 같은지, new의 `$` 개수가 짝수인지 검사한다.

## 금지
OUT과 SCRATCH 밖에 쓰지 않는다. git·다른 에이전트 호출 금지. 최종 답장 5줄 이내.
