# 문항 내용 검산 (읽기 전용) — 정답·해설·문제 그림 결함 확인과 최소 수정안

너는 중학교 1학년 수학 기출 문항의 정답·해설을 검산한다. 파일은 고치지 않고 수정안만 낸다.

## 입력
- 문항 묶음 `{PACKET}` (각 항목 `ord, content, choices, answer, solution, questionImage`).
- 의심 목록 `{FLAGS}` (ord와 의심 내용).

## 문항마다
1. questionImage를 Read로 본다. 작아서 안 보이면 python3 PIL로 확대/잘라 `{SCRATCH}` 안에 저장해 본다(그 밖에 쓰지 않는다). 그래프·히스토그램은 눈금 좌표로 값을 실제로 읽고, 읽은 근거(눈금 위치)를 적는다.
2. 문제를 처음부터 직접 푼다. 정답 기호와 해설의 모든 수치·논리를 그림과 대조한다.
3. 판정:
   - `OK`: 결함 없음(의심이 틀림).
   - `DEFECT`: 정답 또는 해설이 틀림 — 최소 수정안(`patches`: 필드별 old→new 정확한 문자열, old는 packet의 원문 그대로; 정답이 바뀌면 `answer` 필드 patch 포함). 해설은 원래 문체(키포인트 줄, $수식$, "따라서 정답은 ~이다.")를 지킨다.
   - `AMBIGUOUS`: 그림·조건으로는 어느 보기도 정답이 되지 않거나 둘 이상이 됨 등, 원문 시험지 없이는 확정할 수 없는 결함 — 가능한 해석들과 각 해석의 정답을 적고 patches는 비운다.
4. 정답을 바꾸는 DEFECT는 근거를 두 번(다른 방법으로) 확인한다.

## 출력 (이 파일 하나만)
`{OUT}` = `[{"ord":N,"verdict":"OK|DEFECT|AMBIGUOUS","finding":"한국어 2~4문장","patches":[{"field":"answer|solution|choices[i]|content","old":"...","new":"..."}]}]`

## 금지
출력 파일과 `{SCRATCH}` 밖에 쓰지 않는다. git·다른 에이전트 호출 금지. 최종 답장 6줄 이내.
