# 엔진 확장 E32: 평면 라벨·치수선·눈금 (중1·중2 평면도형에서 반복)

## 기능 (위에서부터; 하나 끝내고 커밋한 뒤 다음)
1. **좁은 영역 라벨 지시선 바깥 배치 + 영역 이름·값 라벨**: 영역이 좁거나 선이 가로질러 라벨이 안 들어가면 지시선으로 바깥에(`regions[].labelPlacement:"LEADER"`), 라벨 문구 "△ABC=6cm²"(이름+값, 단위 정체). 부채꼴/활꼴 영역 소속 판정 오류 수정(부채꼴 넓이 라벨이 활꼴로 오인). 실제: `26_팔마중2c-plane1/q7`(△ABC 6cm², AP로 나뉜 조각), `23_금당중기말-plane2/q11`(부채꼴 AOB 40cm²).
2. **치수선**: (a) 한 변 위 치수선 여러 단 쌓기(AE·EC·AC 동시, offset tier 자동), (b) 치수선 보조선이 호를 지나면 `DIMENSION_CROSSES_STROKE` — 호 교차는 허용하거나 경로를 비켜 그리기, (c) 도형 안쪽 대각선 치수선(마름모 BD·AC). 실제: `23_금당중기말-plane2/q13`(끈 6m·4m), `25_왕운중2d-plane1/q6`(중선 CD 바깥 치수선 D~C·G~C가 C 양쪽 변을 가로지름 — 치수선 끝 보조선 생략·짧게 옵션), `26_왕운중2c-plane3/q21`(AE=12를 안쪽 라벨로 우회한 게시본 — 치수선 3단으로 개선판).
3. **호 라벨**: TEXT 호 라벨(° 자동 접미 없이 "3:1"·"호 AB"·"5π"), 얇은 호 라벨 지시선(`arcs[].labelPlacement:"LEADER"`), 같은 호 여러 개 각각 라벨. 실제: `23_연향중기말-plane1/q21`(렌즈 안쪽 5π 호 4개 중 2개만 라벨, 반지름 10·중심 표시 없음).
4. **경로 전체 같은 길이 눈금**: 중간에 점이 있는 경로(B-E-D)에 눈금 하나를 경로 전체용으로(경로 중점이 내부 점과 가까우면 양쪽 조각에 같은 모둠 표식 또는 괄호형 표식) — 지금은 한 조각 위에만 찍혀 오독. 실제: `26_팔마중2c-plane2/q11`(BD=BC), `q13`(BC=AC) — 둘 다 라벨로 우회한 게시본, 눈금 개선판.
5. **반각과 전체각 라벨 동시**: 이등분된 두 반각(36°)과 전체각(72°)을 함께 라벨하면 지시선이 교차(LEADER_CROSSING) — 전체각 라벨을 바깥 링에 자동 배치 (`25_연향중2c-plane2/q14`는 ∠D=72°를 캡션으로만). **작은 부채꼴에 표식 여러 개**: 120° 각 표식 3개 + 변 라벨(9cm) + 부채꼴 이름 P를 함께 배치(라벨 완화·지시선). 실제: `23_왕운중기말-plane2/q16`.
6. 작은 것: 전체 넓이 라벨("△ABC=75cm²") 자리 — 치수선 TEXT 라벨 하단 여백 추정 부족으로 배치 실패, 평문 "ABC=75cm^2"로 우회(`25_연향중2c-plane3/q17`); 선분을 점으로 나눠 눈금을 달 때 전체 길이 라벨 자리(`q19` AB=5cm). 글자 없는 평면 그림(점 이름 없는 사다리꼴, 점·선만) PUBLICATION_TEXT_NOT_READY 거절 완화 — alt·caption이 있으면 허용(`25_연향중2c-plane1/q2`는 억지 라벨로 우회), TEXT 라벨(한글·"△ABC = 84"·"물") 글자가 수식 라벨보다 작고 옅고 가늘다 — 같은 굵기·크기·색으로(여러 검수에서 반복 지적, 기존 SVG 바이트 바뀌면 이 항목만 정답지 갱신 허용하지 말고 옵트인 필드로), `regions[].labelAt`(영역 라벨 위치 지정 — 내접원 안 작은 칸에 넓이 84가 떨어져 작은 삼각형 값으로 오독, `26_왕운중2c-plane4/q22`), 닫힌 둘레 총길이 라벨(둘레 87cm — `25_왕의중2b-plane1/q8`), 같은 길이 눈금 모둠 4개 이상(equalLengths 3묶음 한도), 부분 길이 expressionLabels의 자기 변 가로지르는 지시선(LEADER_CROSSING) 회피, 원 안 점선 반지름 위 길이 라벨(3cm) 자리, 합성 패널 간 같은 배율(`scaleGroup`).
