## 기능 (위에서부터; 하나 끝내고 커밋한 뒤 다음)
1. **수직선 자동 표기 숨김**: SET 줄이 자동으로 쓰는 부등식 라벨(-9/2<x<9/2) 숨기기 옵션(`rows[].hideSetLabel:true`), parameter 끝점의 "a=… 일 때의 그림" 노트 숨김(`parameter.hideNote:true`, 정답 a 노출 방지). 실제: `19_연향중1/q8`, `26_왕의중2a/q18`(움직이는 끝점 1/2-a).
2. **수직선 노트·라벨 안 분수 한 줄 표기**: "n=1/2일 때" 같은 노트가 NUMBER_LINE_LABEL_TOO_LARGE — 인라인 분수(작은 분수) 허용. 실제: 25_왕운중 1학기 중간 q20(`runs/25_왕운중2a-plane1/q20` plan 참고).
3. **두 점 사이 거리 괄호·이동 화살표**: `spans:[{from,to,label:"3",style:"BRACE"|"ARROW"}]`, 점 이름 한글 낱말(뉴욕·두바이·수현·태호), 점 위 값 라벨 위/아래 선택. 1학기 여러 문항이 캡션으로 우회 중(19_연향중 1학기 q9 등 — runs 폴더에서 `19_연향중1` 참고).
4. **통계: 떨어진 계급 합 괄호**: classSums가 이어지지 않은 계급들(찢어진 계급 양옆)도 묶음(`classes:[i,j]`) 허용. 실제: `23_연향중기말-stat1/q20` 계열 plan.
5. **통계: 범례 폭·제목 길이**: "수영(50명)" 같은 범례 폭 자동, 다각형 그림 제목/축 제목 길이 한도 완화(줄바꿈). 실제: 23_연향중 기말 q19·q20.
6. **통계: 점도표(dot plot)**: 수직선 위 자료 점 쌓기(`chartType:"DOT_PLOT"`, 값별 점 개수). 실제: 25_신흥중 2학기 기말 중1 q22(packet `25_신흥중_2학기_기말_중1_기출`).

7. **확률 표·수형도**: DICE_TABLE 칸 묶음별 다른 색(`highlightGroups:[{cells,tone:1|2}]` — `25_연향중2d-stat1/q11` 차 2·차 4), 모서리 변수 글자 숨김/한글(`colVar:null|"첫째 주사위"`), TREE 경로 확률(3개 곱) 라벨이 들어가도록 프레임 폭 자동 확장(`25_팔마중2d-stat1/q20` STAT_LABEL_OUT_OF_BOUNDS), 잎·경로 강조(`highlightPaths`).
