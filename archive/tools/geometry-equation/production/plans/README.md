# 게시된 해설 그림의 작도 원본(plan)

게시된 해설 SVG를 만든 `plan.json`을 그림별로 둔다. 경로는 `<시험지>/<SVG 파일 이름>.plan.json`이고, 같은 이름의 SVG는 `archive/assets/images/<시험지>/`에 있다.

- 쓰임: 이미 게시한 그림을 조금 고칠 때(라벨 자리, 축척, 색) 처음부터 다시 그리지 않고 이 plan을 고쳐 다시 렌더한다. 엔진 실행이나 화면 표시에는 쓰이지 않는다.
- 범위(2026-11-11): 학원 라인이 만든 1,075개(중2·중3 2학기 기말 852개, 고1·고2 2학기 기말 223개). 렌더 결과가 게시된 SVG와 내용이 같은 것만 골랐다. 여기 없는 그림은 plan이 남아 있지 않거나 게시 뒤 SVG가 따로 손질된 것이다.
- 이유: 2026-11-11 닮음비 교체 47개를 plan에 숨은 점 하나씩만 넣어 다시 렌더해 끝냈다. plan이 작업 워크트리의 `.tmp`에만 있어서 워크트리를 지우면 사라지므로 저장소로 옮겼다.
- 그림을 교체 게시하면 새 plan으로 이 파일도 바꾼다. 맞추지 못했으면 지운다(틀린 원본을 남기지 않는다).
- 고르는 도구: `archive/tools/geometry-equation/ops/svg-m1/academy-pipeline/planmatch.py`.
