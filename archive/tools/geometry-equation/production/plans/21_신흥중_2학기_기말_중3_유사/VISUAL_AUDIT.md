## 독립 BLOCKED 반례·수정 조건

1. **q19 문제·해설:** 원문 순서쌍 15개를 부등식 `x>y`로 각각 판정하면 참 5개뿐이다. 동점 `(95,95)`는 `x>y`를 만족하지 않는다. 따라서 실제 선택지 ⑤ `1/3`이 정답이고 현재 지정 ④는 오답이다.
2. **q20 문제·해설:** q19의 15쌍 중 `x≥80`인 8쌍을 분리하면 그 안에서 `y≥85`는 명시한 6쌍이다. 실제 정답은 ④ `3/4`이며 현재 ③ `5/8`은 틀리다.
3. **q21 문제·해설:** 정오각형 꼭짓점을 단위원의 각도 A90°, B18°, C−54°, D−126°, E162°에 두면 직선 BD와 CE의 교점 P=(0,−0.381966...)이다. 내적 공식으로 `∠BPE=108°`, `∠DPE=72°`를 직접 얻는다. 원주각 교차현 정리 `(호 BE+호 CD)/2=(144+72)/2`도 108°를 재확인한다. 원문 답 72°는 구하는 각의 보각이다.

## production·검증 기록

- **REQUIRED 11 / BENEFICIAL 12 / EXEMPT 17 / BLOCKED 6 = 46축.** 공식 실행형 plan **23개**(문제 11·해설 12). 실패한 q19 레거시 graph나 원문에 틀린 정답을 공식 경로에 복사하지 않았다.
- 모든 construction plan은 해당 축의 실제 `content` 또는 `solution`을 `sourceQuote`로 그대로 결속한다. 통계 chart는 계약상 별도 `sourceQuote` 대신 실제 `chart` 필드·출처 설명에 결속한다.
- `sourceConditions[].mappedTo`는 모든 보이는 점·선분·원·각·원호·길이 및 chart 데이터에 대한 **실존 그리기 필드**이다. 문제 그림에서 정답·해설 보조정보를 선노출하지 않는다. 면 채움은 없음.
- **공식 shallow/full lint 각 50/50 PASS**(두 학교 합계). 실제 그리기 필드 `mappedTo` 전수 대응 **668/668**, construction `sourceQuote` 실제 원문 결속 **44/44**, 통계 chart **6개**, 원본 SVG 픽셀점 대응 **42/42**, 독립 수학 식·반례 **144개 검사·불일치 0**(두 학교 합계). 검증 명령은 공식 `ops/claude-batch/plan-lint.cjs --shallow/--full`에 준한 기본 full 및 독립 검산 스크립트로 수행.
- **RENDER_NOT_RUN:** 공식 `production/render-plan.mjs`를 신흥중 q01 문제축에 직접 실행했으나 `status=FAILED`, `stage=measure`, `code=ARCHIVE_PREFLIGHT_FAIL`. 브라우저 지정 `/usr/bin/chromium`은 래퍼이고 실제 `/usr/lib/chromium/chromium`이 없어 **exit 127**. 정적 lint 성공은 실제 렌더 성공이 아니다.
- 병합 뒤 원격 `main` 파일별 Git blob SHA readback 결과는 PR 결과와 함께 최종 보고한다.
- q19·q20·q21의 6축은 원문 수정 전 시험지 **전체 완료 처리 금지**. Windows 큐는 접근·확인·수정하지 않는다.
