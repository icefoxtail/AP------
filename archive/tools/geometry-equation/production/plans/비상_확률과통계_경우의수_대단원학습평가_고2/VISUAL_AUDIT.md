## 원본 이미지·수학·그리기 필드의 독립 검산

1. **q05 문제 PNG**: 직사각형 격자의 4열×2행에서 가로·세로 도로 **22개가 모두 존재**한다(가로 4×3=12, 세로 5×2=10; PNG의 각 선분 중점 픽셀을 독립 검사). A는 좌하단, B는 우상단이다. 원본 이미지가 명확하므로 문제 그림을 재작성하지 않는다.
2. **q05 해설**: 총 최단 이동 6칸, 속력이 같아 각자 3칸 이동한 때만 만난다. 가능한 교차점은 P(1,2), Q(2,1), R(3,0)이다. 서로 다른 A→B 최단 경로 15개를 독립 열거해 **중간 교차점별 경로 3·9·3**, 경로 쌍의 만남 3²+9²+3²=99, 만나지 않는 쌍 15²−99=**126**으로 검증했다. 엔진 `lattice.grid`·`lattice.points`·`lattice.counts:true`가 점·도로·경로 수를 직접 계산하고 그린다. 그림 바깥 계산(두 사람 경로 쌍)과 개별 교차점 수를 혼동하지 않는다.
3. **q13 문제 PNG**: 원본은 계산기의 회색 표시창에 숫자 1이 입력된 장면이다. 회색은 그 기기의 실제 화면 묘사이며 새 SVG의 불필요한 면 채움이 아니다. `1`은 원본과 문제 글에 있으며, 해설은 [0]/[00] 자판 선택 1+5+6+1=13으로 완결된다.
4. 전 플랜에 흰색 배경 rect·기본 영역 fill 선언 **0**. SVG 실물 렌더/눈금·라벨 겹침/모바일·A4는 미실행이므로 **NOT_RUN**을 유지한다.
