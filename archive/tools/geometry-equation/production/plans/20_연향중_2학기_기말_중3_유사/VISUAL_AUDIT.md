## BLOCKED의 독립 근거와 후속 조치

1. **q03 문제·해설(2축):** AB가 지름이고 ADC=62°이면 작은 호 AC=124°, 작은 호 BC=56°다. E가 작은 호 BC 위면 BEC는 큰 호 BC를 보므로 152°, E가 큰 호 BC 위면 작은 호를 보므로 28°. 원본 레거시 plan은 A=180°, B=0°, C=304°, E=60°로 E를 *큰* 호에 놓는다. 발문에 `큰 호 BC` 또는 E의 위치를 명시해 해설 28°와 일치시키기 전에는 공식 제작을 보류한다.
2. **q17 해설(1축):** JS의 실제 보기 순서는 ①도서판매, ②앉은키·시력, ③주행거리·잔여연료, ④기온·빙과류, ⑤성적·신발크기다. 해설은 ②·③에 대한 문장을 서로 바꾸어 달았다. ③ 정답 자체는 타당하지만 설명 번호가 틀리므로 JS 수정 담당의 교정 필요. 그림으로 숨기지 않는다.
3. q09의 `T′`는 발문에 별도로 정의되지는 않는다. 기존 SVG의 T를 지나는 접선의 반대 방향 점으로 해석하여 q09 공식 plan에서 **T′를 실제 표시**했다. 해당 해석은 ∠DAT40°·∠BAT′70°와 일치한다. 기존 SVG의 T′ 글자 누락은 추후 실제 렌더 검수 항목이다.

## 정적 수학·시각 대조

- q18 기존 SVG에서 `data-role=point` 20개와 x/y 눈금 10~45(5 간격)을 확인했다. 원본 레거시 chart의 20개 순서쌍을 각 원본 SVG 점의 픽셀 좌표에서 선형 역변환해 20/20 일치 확인했다. `(y>x)` 집합 7개를 별도 확인하고 임의 학생 좌표를 만들지 않았다.
- q09 대표 원 좌표 A270°, B50°, C100°, D190°를 사용해 원주각 BCD110°·ABD40°와 A 접선의 두 각 DAT40°·BAT′70°를 삼각함수·원주각 정리로 독립 검산했다.
- `stat-chart-figure-v1`은 최상위 `sourceQuote` 필드를 허용하지 않는다. q18 원문은 이 감사와 `sourceConditions`의 개별 조건에 결속하며, 허용되지 않는 임의 JSON 키를 삽입하지 않는다.
