## 정확성·검증 범위

- **REQUIRED 11 / BENEFICIAL 16 / EXEMPT 23 / BLOCKED 0 = 50축.** 공식 실행형 plan **27개**(문제 13·해설 14). 나머지 축에는 임의 EXEMPT JSON을 만들지 않았다.
- q21의 점 20개는 원문 JS의 수학·영어가 아니라 **1·2학기 수학 점수 순서쌍**과 일치해야 한다. 원본 SVG 실제 픽셀점 20개와 비교한다. q20 원본 SVG의 음의 상관 개념 점군은 22개로, 점 순서와 수치 분포를 대조한다.
- 모든 construction plan은 실제 원문축 `content`·`solution`의 정확한 `sourceQuote`로, 통계 chart는 계약의 `chart` 및 `sourceConditions`로 결속한다. `mappedTo`는 보이는 점·선·호·라벨·점군의 **실존 그리기 필드**만 참조한다. 문제축의 새 정답 선노출·불필요한 면 채움 금지.
- **공식 shallow/full lint 각 50/50 PASS**(두 학교 합계). 실제 그리기 필드 `mappedTo` 전수 대응 **668/668**, construction `sourceQuote` 실제 원문 결속 **44/44**, 통계 chart **6개**, 원본 SVG 픽셀점 대응 **42/42**, 독립 수학 식·반례 **144개 검사·불일치 0**(두 학교 합계).
- **RENDER_NOT_RUN:** 공식 `production/render-plan.mjs`를 팔마중 q21 문제축에도 직접 실행했으나 `status=FAILED`, `stage=measure`, `code=ARCHIVE_PREFLIGHT_FAIL`. 브라우저 지정 `/usr/bin/chromium`은 실행 래퍼이고 실제 `/usr/lib/chromium/chromium`이 없어 **exit 127**. 정적 lint 성공은 실제 렌더 성공이 아니다.
- 병합 후 원격 `main` 변경 파일별 Git blob SHA readback 결과는 PR 결과와 함께 최종 보고한다.
- Windows 큐를 접근하지 않았으며 상태를 추정하거나 체크하지 않는다. 다른 학년·기출·원문 JS는 불변.
