## 독립 BLOCKED 수학적 반례·복원 조건

1. **q19:** 실제 20개 순서쌍을 하나씩 판정하면 (x≥80) 10개의 기말점수 합이 790이어서 **평균79**다. 동시에 (x<80,y<80)은 7개여서 **35%**다. 원문은 ④에 72, ⑤에 45%를 써 두 항목이 동시에 잘못된 객관식이다. ⑤ 또는 ④를 수정해 답이 하나로 유일하게 만들어야 한다.
2. **q20:** (x+y≥16)인 원문 순서쌍을 전수 계산하면 9개다(위 표에 모두 열거). 정답은 ⑤ (rac9{20})인데 ③ (rac7{20})으로 지정됐다. 해설에는 9개를 먼저 계산하고 원문 점 자체를 바꾸자는 미완성 생성 문장이 그대로 노출된다.
3. **q24:** 50명의 독서시간·국어점수 원자료나 실제 산점도 참조가 전혀 없다. ‘오른쪽 위’라는 전체 경향만으로 특정 점 E가 주변 학생보다 낮은지 판단할 수 없다. 예를 들어 양의 상관 점군에서 E=(8,90)이면 높은 편이고 E=(8,50)이면 낮은 편일 수 있다. 둘 다 전반적인 양의 상관과 양립하므로 ㄷ의 진위가 정해지지 않는다.

## 운영 생산·검증

- **REQUIRED 10 / BENEFICIAL 13 / EXEMPT 19 / BLOCKED 6 = 48축**, 공식 실행형 **23개**(문제11·해설12).
- 문제 03·04·05의 레거시 초안에 있던 결과각 선노출 또는 조건으로 결정되지 않은 개별 각 110° 표시를 교정했다. 합만 결정되는 q04의 각 x·y를 각각 110°로 고정하지 않았다.
- Construction의 `sourceQuote`는 해당 문제·해설의 원문 문자열 전체와 정확하게 일치한다. 실제 보이는 점·선·원·각·호·수치 및 통계 점마다 `sourceConditions[].mappedTo`에 존재하는 그리기 필드를 따로 결속했다.
- 두 학교 합계 공식 plan-lint **shallow 50/50 PASS, full 50/50 PASS**. 실재 그리기 필드 매핑 **763/763** 일치, construction 원문 결속 **44/44**, 통계 chart **6개**, 원본 SVG 점 좌표 아핀 대응 **37/37**(풍덕 q16 19점, 신흥 q17 18점), 독립 수학 증명·반례 **55건 불일치 0**, 구조·결속 검사 **1,372건 불일치 0**.
- **RENDER_NOT_RUN:** 신흥 q22 문제축에서 공식 `production/render-plan.mjs`를 직접 실행해 `status=FAILED`, `stage=measure`, `code=ARCHIVE_PREFLIGHT_FAIL` 재현. `/usr/bin/chromium` 래퍼가 실제 `/usr/lib/chromium/chromium` 실행 파일을 찾지 못해 **exit 127**. 정적 lint PASS는 SVG 렌더 PASS가 아니다.
- 병합 후 원격 `main`의 모든 변경 파일별 Git blob SHA readback은 최종 PR 결과와 함께 보고한다.
- 원문 BLOCKED 3문항이 남아 **시험지 전체 완료 처리·큐 완료 체크 금지**. Windows 큐에는 접근하지 않았다.
