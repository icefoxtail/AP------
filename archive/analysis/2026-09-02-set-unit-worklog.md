## 4. 멱집합 용어 재검토 및 수정

### 발견 결과

아카이브의 시험·유사 JS를 멱집합으로 검색한 결과, 수정 전 해당 문항은 2개였다.

1. 원본 23_금당고_2학기_중간_고1_기출.js q15
2. 유사 25_순천고_2학기_중간_고1_유사.js q2

### 교육과정 분류 원칙

멱집합을 독립된 공식 단원명처럼 사용하지 않는다. 학생용 설명에서는 먼저 다음 뜻을 직접 제시한다.

P(A) = {X | X⊆A}는 A의 모든 부분집합을 모은 집합이다.

따라서 분류는 집합의 연산·부분집합 기반 심화로 이해하고, 멱집합은 공식 세부단원 태그로 사용하지 않는다. 교육과정 원문 확인은 교육부 고시와 NCIC 원문을 기준으로 한다.

### 실제 수정

- 원본 금당고 q15
  - 원문 발문은 보존했다.
  - 내부 태그 멱집합을 제거했다.
  - 해설에 P(A)가 A의 모든 부분집합을 모은 집합이라는 문장을 추가했다.
  - production/candidate 동일 여부를 SHA-256으로 확인했다.
  - 파일: archive/exams/original/high/h1/2mid/23_금당고_2학기_중간_고1_기출.js
- 유사 순천고 q2
  - 집합 A의 멱집합을 집합 A의 모든 부분집합을 원소로 하는 집합으로 수정했다.
  - 해설에서 학생이 용어를 선행 학습했다고 가정하지 않도록 정의 중심 문장으로 수정했다.
  - 파일: archive/exams/similar/high/h1/2mid/25_순천고_2학기_중간_고1_유사.js

수정 후 시험·유사 JS 및 archive/question-index.js에서 멱집합 문자열은 0건이다. 원본 q15의 P(A) 표기는 문제 안에서 직접 정의되어 있으므로 남겨 두었으며, 이는 용어를 무정의로 요구하는 것과 구분한다.

7. JS 수정 후 반드시 질문 인덱스를 다시 만든다.
8. 정적 audit만으로 완료하지 말고 exam, sol, ans 3모드를 확인한다.
9. DB에 등록되지 않은 유사문항을 audit 통과시키기 위해 DB 레코드를 임의로 만들지 않는다.
