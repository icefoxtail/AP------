# **Q05**

* 형식: 서답형  
* 배점: 5

# **발문**

최고차항의 계수가 \$1\$인 삼차함수 \$f(x)\$에 대하여 함수 \$g(x) \= e^{f(x)}\$가 다음 조건을 만족시킨다.  
(가) 함수 \$g(x)\$는 \$x \= 1\$에서 극대이고, \$x \= 3\$에서 극소이다.  
(나) 방정식 \$g(x) \= e^k\$의 서로 다른 실근의 개수가 \$2\$가 되도록 하는 두 실수 \$k\$의 값의 합이 \$12\$이다.  
이때 \$\\ln g(4)\$의 값을 구하시오.

# **선지**

없음

# **정답**

\$8\$

# **해설**

합성함수의 미분법에 의하여  
\$\$g'(x) \= f'(x) e^{f(x)}\$\$  
모든 실수 \$x\$에 대하여 \$e^{f(x)} \> 0\$이므로 \$g'(x)\$의 부호는 \$f'(x)\$의 부호와 항상 일치한다.  
따라서 조건 (가)에 의하여 삼차함수 \$f(x)\$ 역시 \$x \= 1\$에서 극대이고 \$x \= 3\$에서 극소이다.  
\$f(x)\$의 최고차항의 계수가 \$1\$이므로  
\$\$f'(x) \= 3(x \- 1)(x \- 3\) \= 3x^2 \- 12x \+ 9\$\$  
적분(또는 다항식 계수 비교)하면 상수 \$C\$에 대하여  
\$\$f(x) \= x^3 \- 6x^2 \+ 9x \+ C\$\$  
한편 방정식 \$g(x) \= e^k \\iff e^{f(x)} \= e^k \\iff f(x) \= k\$의 서로 다른 실근의 개수가 \$2\$가 되려면 \$y \= f(x)\$와 직선 \$y \= k\$가 극대 또는 극소에서 접해야 하므로  
\$\$k \= f(1) \\quad \\text{또는} \\quad k \= f(3)\$\$
