# BASIC: 전체 문항을 기본 후보로 사용

2026-09-27 사용자 지시에 따라 BASIC의 기본 동작을 고정한다.

- 첫 진입, 학년 변경, 새 작업의 난이도 조건은 빈 배열이다. 빈 배열은 난이도 미지정 문항을 포함한 전체 난이도를 뜻한다.
- 특정 난이도는 사용자가 세부 조건에서 직접 선택했을 때만 적용한다. 1~5 전체를 선택한 것과 난이도 조건이 없는 것은 다르다.
- BASIC은 난이도·유형·템플릿 등의 메타가 없거나 분류 대기라는 이유로 문항을 제외하지 않는다. 기존 하·중·상을 임의의 숫자 난이도로 변환하지 않는다.
- BASIC의 원본 검증은 현재 catalog에 등록한 source bytes, UID, ordinal, fingerprint를 사용한다. optional metadata의 과거 승인 fingerprint가 현재 원본과 달라도 원본 자체가 현재 catalog와 일치하면 BASIC에서 사용할 수 있다.
- 명시적으로 확인된 원본·정답·해설 결함, 기본 범위 충돌 및 학년 충돌은 유지한다. 고급 필터는 그 필터에 필요한 메타와 원본 승인 연결을 확인한다.
- Source 복원에서 문제 본문, 보기, 정답, 해설, 이미지 및 레이아웃은 보존한다. optional metadata만 catalog의 snapshot 값으로 일치시킨다.
- 범위에는 실제 문항 수를 표시한다. 별도의 '자동 출제' 숫자는 표시하지 않는다.
- 새 작업은 전체 난이도로 돌아간다. 이미 만든 시험지와 새 버전에서 명시적으로 선택한 난이도는 작업 복원 시 보존한다. 아직 만들지 않은 이전 버전 작업의 암묵적 `[2, 3]` 기본값은 전체로 이행한다.

회귀 근거: `tests/archive2-compose-scope.test.js`, `tests/archive2-core.test.cjs`, `tests/archive2-worker-validation.test.mjs`.
