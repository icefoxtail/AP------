# ADR-006: 단원별 기출을 정식 작업 메뉴로 연결

2026-09-17 · Accepted

## 문제

기출·자료 검색 필터 오른쪽의 작은 링크는 단원별 문제지의 위치를 설명하지 못했다.
진입 후 작업 메뉴가 사라지고 출제 시 기존 아카이브 전체 화면으로 이동하여 맥락이 끊겼다.

## 결정

- 상단 작업 메뉴를 `기출·자료 → 단원별 기출 → 문제지 만들기 → 출제 내역`으로 통일한다.
- 기존 단원별 기출의 `ready=1` 진입에만 공통 메뉴를 적용한다. 기존 제작 화면은 보존한다.
- 문제지 목록의 행 전체를 클릭·키보드 조작 가능한 버튼으로 제공한다.
- 실제 시험지 확인 뒤 기존 반·학생 출제 패널을 같은 화면의 dialog에 삽입한다.
  기존 원본 출제의 embedding CSS/close/busy 처리를 재사용하며 assignment API는 변경하지 않는다.
- 평가 보관함은 기출 외 자료 검색 결과의 별도 안내로 연결한다. 화면 이동을 검색 필터에 섞지 않는다.

## 검증과 한계

PC 및 390px 브라우저에서 메뉴 왕복, 현재 위치, 문제지 행의 Enter 조작, 실제 미리보기,
기존 반·학생 패널, 시험지 복귀를 확인했다. 모바일 주 메뉴 높이는 44px이며 가로 잘림이 없다.
로컬 합성 학생 출제는 저장되며 PDF는 Browser Rendering binding 없는 fixture의 예상 실패다.
이 결정은 저장, 렌더, 문항 순서, 최신 연도 우선 선택, canonical UID Authority를 변경하지 않는다.
스크린리더 전수 검증이나 전체 WCAG 적합성을 주장하지 않는다.
