# 교육과정 외 풀이 전수 감사 (2026-07-18)

## 목적

고1·고2 해당 학기 시험 범위를 벗어난 기법이 해설에 쓰이면 안 된다. 사용자가 지목한 예: **시그마(∑), 케일리-해밀턴, 헤론의 공식, 로피탈 정리, 복소평면/극형식**. 아카이브 전체(원본·유사·유형 216+ 파일)의 모든 해설·발문을 학년별로 스캔해 범위 밖 기법을 찾아 고쳤다.

## 방법

`scan-curriculum.mjs`(scratchpad)로 학년(경로: `middle`=중, `h1`=고1, `h2`=고2)을 판정하고, 기법 마커(∑/케일리·해밀턴/헤론/로피탈/극형식·복소평면·드무아브르/미분·적분·극한/벡터 등)를 해당 학년에서 부적합한 경우만 추출 → 수기 판정. 최종적으로 아카이브 전체에서 **헤론·케일리-해밀턴·극형식/복소평면·로피탈 = 0건**, **고1·중학의 ∑ 기호 = 0건**을 확인.
