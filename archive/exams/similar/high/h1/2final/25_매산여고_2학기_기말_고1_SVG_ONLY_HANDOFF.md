## 실행 지시

1. `AGENTS.md`, `archive/AGENTS.md`, `docs/agents/visual-svg.md`, `docs/agents/typebank-figure-plan-execution.md`, `archive/tools/geometry-equation/production/AUTHOR_GUIDE.md`를 현재 브랜치 기준으로 읽는다.
2. 작업 전용 worktree를 사용한다. `main`·원본 기출·다른 학교/연도 시험지·문항 텍스트 변경 금지.
3. 각 변형의 **문제·해설 독립 46축**에 대해 기존 판정과 현재 JS의 수식/좌표/도형/라벨/정의역/경계를 1:1 대조한다. q03·q15의 `sourceDiagramModel`은 엔진 도식 데이터로 활용하되 새 변형의 실제 값과 반드시 일치시킨다.
4. 필요한 그림의 실행형 JSON **52개는** `archive/tools/geometry-equation/production/plans/<stem>/qNN-problem.plan.json` / `qNN-solution.plan.json`에 **모두 작성·lint 통과**했다. 실제 엔진 렌더 후 그림 요소와 원문을 반드시 대조하고 필요한 경우 해당 plan만 수정한다. 기존 기출 원본 14건도 같은 브랜치에서 작성 완료됐다(그중 문제 필수 2건은 기존 파일). 손 SVG·PDF PNG 잘라넣기·수동 SVG 조립 금지.
5. 공식 `plan-lint` **shallow/full**, 엔진의 **실제 SVG render**, 정적 `DRAWN_FEATURE_PARITY`, 이미지 문항 판독, 학생화면·A4 인쇄를 분리 기록한다. SVG 산출물이 실제로 없으면 JS의 `image`/`solutionImage`/plan 참조를 채우지 않는다. 새 SVG 파일은 배경 흰색 덮개·불필요한 면 채움·라벨 누락이 없어야 한다.
6. 수학을 변경하지 않은 범위에서 시각 연결 필드 및 필요한 `imageSize` 등만 수정한다. **그림·해설·레이아웃만 바뀐 경우 4칸의 `sourceGitBlobSha`는 최초 작성 시점의 결속 기록으로 유지한다**(현재 `docs/agents/common.md`의 문항별 발문·보기 text-v1 결속 규칙). 발문·보기가 변경되어야 할 수학 오류를 발견하면 작성 라인으로 돌려 교정·결속 판단을 요청한다. 해설 그림은 그 문항의 **풀이 순서**와 정확히 일치해야 한다. q18은 두 곡선이 `(-d,+d)`만큼 이동하므로 넓이가 `d×(직선 절편 차)`가 되는 근거를 명확히 그린다. 특히 유사2 q18의 `k`는 **아래쪽** 절편이다.
7. 작성 결과: 유사1 17건·유사2 17건·유사3 18건, **총 52건 shallow/full lint PASS**(엔진이 실제 사용한 2026-11-28 공식 검사). 기출 14건을 합한 전체 **66건도 shallow/full lint PASS**다. 이제 실제 render 수·필수 시각 결함·미실행 항목·수정 파일·커밋을 보고한다. 사용자 명시 승인 없이 `main` 병합·학생 배포 금지.
