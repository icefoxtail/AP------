# Q23 해설 SVG — 공식 엔진 기능 공백

- 현재 문항: \(f(x)= -x-1\) (\(x<-2\)), \(f(x)=|2^{1-x}-4|\) (\(x\ge-2\)).
- 필요한 시각 요소: 왼쪽 열린 점 \((-2,1)\), 오른쪽 닫힌 점 \((-2,4)\), 꺾임점 \((-1,0)\), 오른쪽 점근선 \(y=4\), 구간별 수평선 교점 수.
- 확인한 기존 capability: `piecewise-discontinuous-spike-v1`은 상수·일차·이차 조각을 다루지만 지수 절댓값 조각을 지원하지 않음. `exponential-affine-spike-v1`은 단일 지수함수는 그리지만 절댓값 꺾임·불연속 조각 접합을 지원하지 않음.
- 필요한 엔진 확장: **piecewise-exponential-absolute-spike-v1** 또는 기존 조각 그래프 문법에 `ABS_EXPONENTIAL` family를 추가하고, 각 조각의 실제 정의역과 열린/닫힌 끝점을 모델링. 공식 독립 관측기는 교점 개수 \(g(n)\)를 정수 \(-8\le n\le8\)에서 직접 계산해 도식과 대조.
- 기대 그래프 사실: 왼쪽 치역 \((1,\infty)\), 오른쪽 치역 \([0,4]\). \(g(n)=0\) 8개, 1개 5개, 2개 2개, 3개 2개; 결과 순서쌍 52개.
- 상태: `ENGINE_CAPABILITY_PENDING / NOT_RUN`. 기존 엔진을 수정하거나 잘못된 곡선으로 대체하지 않았음. 해설 본문 수식은 독립적으로 완결되나 그래프 실물 검수와 학생 화면 연결은 후속.
