# 제일고 고2 1학기 중간 유사 — 25문항, 문제·해설 2축 검수

- 원본: `../25_제일고_1학기_중간_고2_유사.js`의 `window.questionBank` 1–25번.
- 기준: 최신 `main`에서 같은 stem의 `*_plans/`가 없었고, 해당 두 시험지명을 포함한 열린 PR 검색에서도 중복이 없었다. 현재 배치에는 제일고 25문항만 포함한다. 매산고 22문항은 다음 묶음으로 남긴다.
- 원본 25문항의 `image`와 `solutionImage` 참조는 모두 없음. 기존 이미지 재현이 아니라 **원문 수학 조건과 저장 해설의 필요성**으로 두 축을 각각 판정했다.
- **EXEMPT**는 그림이 단순 식 또는 계산을 반복하거나 불필요한 장식이어서 생략한 것이다. **BENEFICIAL/REQUIRED**만 실제 실행 가능한 plan으로 작성했다. 문제용에는 풀이의 길이·정답 수치를 노출하지 않았다.
- 모든 표시 면은 원칙적으로 무채움. q12는 원문이 중앙 사각형 색칠을 요구하기 때문에 **첫 시행의 중앙 영역 한 칸만** 예외적으로 칠했다. 평면도형 각은 `style:ARC`라 각 부채꼴 채움이 없다.
- q12의 이후 반복에서 어느 작은 정사각형을 선택하는지는 발문에 명시되지 않아 **첫 시행만** 표현했다. 공비 1/9인 해설을 그림에 추론·고정하지 않았다. 이는 원문 편집 확인 사항이며, 엔진 미지원 상태와는 다르다.

## 실제 SVG에 그리도록 요청한 필드의 1:1 대조

각 행에서 **좌표/비율**은 실제 plan 좌표와 극좌표를 재산출하고, **선분/곡선**, **라벨**, **각·직각**, **영역**은 원문 조건 및 해설에서 요구하는 값과 대응시켰다. 현재 JS에는 그림 파일이 없어 이미지 픽셀 비교 대상은 없다.
