## 실제 엔진 필드와 원문 대조 — q08 해설

| 원문 조건·풀이 요소 | 엔진 출력의 실제 도형 필드 |
| --- | --- |
| a=3−√2 | r1 label a, dot P0 value 3-sqrt(2), x=168.695825 |
| b=1+√3 | r2 label b, dot P1 value 1+sqrt(3), x=327.304175 |
| c=2 | r3 label c, dot P2 value 2, x=226.010465 |
| d=√10−1 | r4 label d, dot P3 value -1+sqrt(10), x=248.464789 |
| 네 행의 공통 눈금 | r1~r4 axis x1=44 x2=460, 모두 같은 매핑; 168.695825<226.010465<248.464789<327.304175 |

소문자 a,b,c,d는 값이 있는 POINTS의 점 이름으로 쓰지 않고, 엔진이 지원하는 별도 행 라벨로 표시한다. 각 행에 점 하나라 라벨의 소속이 명확하다. 정확한 원문식 4개를 각각 숫자 근삿값이 아닌 엔진 값 필드에 입력했다. 문제 그림은 답을 미리 노출하므로 만들지 않았다.

필드 대조 근거는 공식 `number-line-v1.mjs`의 `solveNumberLineFigure` 모델과 `numberLineFigureSpec`의 `rows[].axis`, `rows[].dots`, `labels` 결과이다. 이 모듈과 공식 lint·합성 모듈의 Git blob은 실행 시 최신 main 파일 blob과 일치함을 별도 확인했다. 정밀한 좌표·대소관계는 도형 spec PASS이며 **실제 렌더 PNG 눈 검수 PASS를 뜻하지 않는다**.
