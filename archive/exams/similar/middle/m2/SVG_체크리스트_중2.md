기준일: 2026-11-12

> 문항별 문제 그림과 해설 그림을 따로 추적합니다. 상태는 JS/메타/참조 경로를 코드로 읽어 기록했으며 이미지 렌더링·시각 QA는 하지 않았습니다. 이 문서 작성을 위해 SVG를 만들거나 수정하지 않았습니다.

## 상태 표기

- **필요·미제작**: 시각 요소가 문항/해설에 필요하나 유사 JS에 연결된 완성 그림을 확인하지 못함.
- **미확인**: 그림/조건이 누락 또는 불명확하여 필요 여부나 구체 내용을 확정할 수 없음. 완료로 취급하지 않음.
- **불필요(문자 충분)**: 읽은 글·식으로 조건이 전달되어 별도 그림이 없어도 됨.
- **자산 코드 있음·렌더 QA 미완**: 코드/참조가 존재하지만 최종 표시나 변형 적합성은 확인하지 않음.

## 범위

- 포함: 현재 M2 작업 소유가 확인된 12개 시험지(시험지별 작업 브랜치 7개, 누적 브랜치 5개). PR 번호는 작업 브랜치 출처입니다.

## 확인 한계

- 분류는 유사 JS의 문항/해설 텍스트와 이미지 속성 및 이미 기록된 원본 참조를 코드로 확인해 작성했습니다. 스캔 원본과 실제 렌더 화면은 열어 보지 않았습니다.
- “자산 코드 있음”은 참조/HTML 코드가 있다는 뜻입니다. 일부 원본 SVG 경로는 메타에만 있고 현재 체크아웃에 파일이 없습니다. 파일의 시각 품질, 렌더 결과, 변형 문항과 일치 여부를 보증하지 않습니다. 별도 시각 검수 후에만 갱신하세요.
- 특히 향림중 Q22, 팔마중(25기말) Q14, 동산중 Q19, 연향중 Q18은 그림/선지 정보가 불충분하여 미확인으로 남겼습니다. SVG 제작은 후속 작업입니다.
