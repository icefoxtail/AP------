[서·논술형 2] $$x = \frac{1}{\sqrt{2}-1}, \quad y = \frac{1}{\sqrt{3}-\sqrt{2}}$$ 일 때, $x-y$의 값을 구하시오. [6점]
정답
$1-\sqrt{3}$
해설
합차 공식을 이용하여 두 분모를 각각 유리화한 후 뺄셈을 수행한다.


1단계: $x$의 분모를 유리화한다. $$x = \frac{1}{\sqrt{2}-1} = \frac{\sqrt{2}+1}{(\sqrt{2}-1)(\sqrt{2}+1)} = \frac{\sqrt{2}+1}{2-1} = \sqrt{2}+1$$


2단계: $y$의 분모를 유리화한다. $$y = \frac{1}{\sqrt{3}-\sqrt{2}} = \frac{\sqrt{3}+\sqrt{2}}{(\sqrt{3}-\sqrt{2})(\sqrt{3}+\sqrt{2})} = \frac{\sqrt{3}+\sqrt{2}}{3-2} = \sqrt{3}+\sqrt{2}$$


3단계: $x-y$의 값을 계산한다. $$x - y = (\sqrt{2}+1) - (\sqrt{3}+\sqrt{2}) = \sqrt{2} + 1 - \sqrt{3} - \sqrt{2} = 1 - \sqrt{3}$$


따라서 $x-y$의 값은 $1-\sqrt{3}$이다.

* 형식: 서술형
* 배점: 7
발문
[서·논술형 3] $(x+a)(x-2)$를 전개하면 $x^2 + bx - 8$일 때, 빗변의 길이와 밑변의 길이가 각각 $a+b$, $a-b$인 직각삼각형의 넓이를 구하시오. [7점]
정답
$4\sqrt{2}$
해설
다항식의 전개식을 통해 $a$와 $b$를 구한 후, 피타고라스 정리로 직각삼각형의 높이를 구하여 넓이를 계산한다.


1단계: 다항식을 전개하여 $a, b$의 값을 구한다. $$(x+a)(x-2) = x^2 + (a-2)x - 2a$$ 우변의 $x^2 + bx - 8$과 계수를 비교하면


* 상수항: $-2a = -8 \implies a = 4$
* $x$의 계수: $b = a - 2 = 4 - 2 = 2$ 따라서 $a = 4, b = 2$이다.


2단계: 직각삼각형의 변의 길이를 구한다.


* 빗변의 길이: $a + b = 4 + 2 = 6$
* 밑변의 길이: $a - b = 4 - 2 = 2$


3단계: 피타고라스 정리를 이용하여 높이를 구한다. 높이를 $h$라 하면 $$h^2 + 2^2 = 6^2$$ $$h^2 + 4 = 36 \implies h^2 = 32$$ $h > 0$이므로 $$h = \sqrt{32} = \sqrt{16 \times 2} = 4\sqrt{2}$$


4단계: 직각삼각형의 넓이를 계산한다. $$\text{넓이} = \frac{1}{2} \times \text{밑변} \times \text{높이} = \frac{1}{2} \times 2 \times 4\sqrt{2} = 4\sqrt{2}$$


따라서 직각삼각형의 넓이는 $4\sqrt{2}$이다.
