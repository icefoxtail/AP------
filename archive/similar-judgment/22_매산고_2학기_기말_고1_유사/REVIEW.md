$f_1(3) = f_2(3) = 3$인 두 일차함수는 기울기를 각각 $a_1, a_2$ ($a_1 \ne 0, a_2 \ne 0$)라 하면 $f_1(x) = a_1(x - 3) + 3$, $f_2(x) = a_2(x - 3) + 3$ 로 나타낼 수 있다. $f_1(8) = 5a_1 + 3 = 8 \implies a_1 = 1$, 즉 $f_1(x) = x$이다. $a_2 = t$ ($t \ne 0$)라 하면 $(f_2 \circ f_2)(x) = t^2(x - 3) + 3$이 $f_1$ 또는 $f_2$와 같아야 하므로 $t^2 = 1$ 또는 $t^2 = t$ $t \ne 0$이므로 $t = 1$ 또는 $t = -1$이다. (실제로 $t = 1$이면 $f_1 = f_2 = I$로 네 합성 모두 $f_1$, $t = -1$이면 $f_1 \circ f_1 = f_2 \circ f_2 = f_1$, $f_1 \circ f_2 = f_2 \circ f_1 = f_2$가 되어 모두 성립한다.) 따라서 가능한 $f_2(8) = 5t + 3$의 값은 $8$과 $-2$이다. $\therefore 8 \times (-2) = -16$
