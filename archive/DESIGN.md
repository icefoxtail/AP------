# JS 아카이브 디자인 (Archive 2.0)

> 이 문서는 `archive/`의 교사용 화면(`workspace.html`, `unit-past-exams.html?ready=1`)의 디자인 기준이다.
> `apmath/DESIGN.md`는 APMS(학원 관리) 화면용이라 별개다. 서로 색·글꼴을 맞추지 않는다.
> 값은 `archive/archive2-tokens.css` 한 곳에서 정의한다. 화면 CSS에 색 숫자를 직접 쓰지 않는다(그림자·반투명 막은 예외).

## 사용자 결정 (2026-11-10)

- 색이 칙칙하고 밋밋하며 화면마다 모양이 달랐다. **아카이브만의 새 디자인**(APMS와 공유하지 않음)으로 바꾼다.
- 시안 A(찾기 중심)와 B(단원 중심)를 **섞는다**. 홈 위쪽에 "학교 기출 찾기"와 "단원별로 난이도 골라 주기"를 나란히 둔다.
- **단원별 기출은 독립 메뉴**다. 난이도는 **1~5단계를 유지**한다(단계를 줄이지 않는다).
- 이유: 교사는 휴대폰·갤럭시 탭, 원장은 PC로 쓴다. 한 화면에서 "찾기"와 "단원 고르기"가 둘 다 보여야 교사가 메뉴를 헤매지 않는다.

## 색

| 용도 | 값 |
| --- | --- |
| 바탕 | `#FFFFFF` |
| 글자 | `#17171C` (보조 `#5A5A63`, 흐린 글자 `#6B6B74`) |
| 선 | `#E6DAD5` (옅은 선 `#F0E8E5`) |
| 입력·컨트롤 테두리 | `#8A8A93` (강조는 글자색 2px) |
| 주홍(브랜드) | `#CF3518`: 왼쪽 메뉴 바탕, 링크, 유사문제 표시 |
| 진한 주홍 글자 | `#A82A10` / 주홍 옅은 바탕 `#FFF1EB` (그 위 글자 `#7A1E0A`) |
| 중립 칩 바탕 | `#F6F1EF` / 선택된 줄 바탕 `#F1EEFF` |

학년 색은 **학년 버튼·학년 표시·시험 책등**에만 쓰고 글자는 흰색이다: 중1 `#2F7D32`, 중2 `#0B7A8F`, 중3 `#2A6FDB`, 고1 `#6B4FD8`, 고2 `#A8268F`, 고3 `#1F2937`.

- 글자 대비 4.5:1 이상. 주홍 바탕 위의 작은 링크는 흰 글자 + 밑줄이다(`#FFE4DB`는 대비가 모자라 쓰지 않는다).
- **밝은 화면 하나만 있다.** 다크 모드 규칙을 두지 않는다(`color-scheme: light`). 이유: 시안이 밝은 화면만 정의했고, 어두운 화면에서 학년 색·주홍의 대비를 따로 맞출 근거가 없다.

## 글꼴

- 제목·큰 숫자: `Black Han Sans` (weight 400만 있다. 굵게 만들지 않는다).
- 본문: `Noto Sans KR` 400/500/700.
- **`Black Han Sans`는 20px 이상 제목과 18px 이상 숫자에만 쓴다.** 단위·라벨·20px 미만 한글(예: "22" 뒤의 "문항", "1차", "열기")은 `Noto Sans KR` 700이다. 이유: 작은 글자에서 획이 뭉개진다.
- 학년을 고르는 **버튼**은 어디서나 학년 색 2px 테두리 + 반지름 10이고, 선택되면 학년 색으로 채우고 흰 글자다(select 상자는 그대로).
- Google Fonts `<link>`(`display=swap`)로 불러오고 시스템 한글 글꼴(맑은 고딕, Apple SD Gothic Neo)을 대체로 둔다. 글꼴 파일을 저장소에 넣지 않는다.

## 모양

- 주 버튼: 글자색 바탕 + 흰 글자 알약(반지름 22~28). 보조 버튼: 글자색 1.5px 테두리 + 흰 바탕 알약. 링크형: 주홍 글자.
- 학년 버튼 반지름 10. 카드 반지름 12 + 1px 선(그림자 없음). 강조 패널·대화상자 2px 글자색 테두리 + 반지름 16.
- 누를 수 있는 것은 모두 44px 이상(단, 컴포즈 데스크톱의 촘촘한 탭 `.mode-switch`·`.part-select`는 36px이고 태블릿·휴대폰에서 44px가 된다). 휴대폰 입력 글자 16px 이상. 포커스는 3px 외곽선.
- **이 디자인의 고유 표현 두 가지**
  - **학년 색 책등 + 큰 연도 숫자**: 시험 한 줄 왼쪽에 학년 색 블록을 두고 연도 2자리를 `Black Han Sans`로 크게 쓴다. (색 띠만 두른 카드가 아니라 책등이다.)
  - **선택한 칸은 글자색으로 채운다**: OMR 답안을 칠하듯 선택된 칩·탭·전환 버튼은 `#17171C`로 채우고 흰 글자를 쓴다. 옅은 파란 바탕으로 표시하지 않는다.

## 메뉴

- PC·가로 태블릿(폭 961px 이상): 왼쪽 메뉴, 폭 232px, 주홍 바탕. 맨 위 "JS 아카이브". 글자만 있는 44px 알약 6개, 현재 화면은 흰 바탕 + 진한 주홍 글자 + `aria-current="page"`.
  `홈 / 학교별 기출 / 단원별 기출 / 문제지 만들기 / 빠른 평가 / 보관함 · 출제 내역`
  맨 아래: 로그인 상태(로그인 전이면 "선생님 로그인", 로그인 후에는 이름·"로그인됨"), 작은 링크 "아카이브 1.0", "자료 점검", "유형·개념으로 문항 찾기".
- 휴대폰(폭 960px 이하): 위 머리줄 56px(홈은 "JS 아카이브" + 로그인, 다른 화면은 화면 이름) + 아래 고정 메뉴 5칸(글자만, 60px, 현재 칸은 글자색 바탕 흰 글자): `홈 / 학교별 / 단원별 / 만들기 / 보관함`.
  빠른 평가는 홈 화면과 "문제지 만들기" 화면 위쪽의 링크로 간다. 그 밖의 도구 링크는 홈 맨 아래에 있다.
- "보관함 · 출제 내역"은 메뉴 하나다. `view=saved`(보관함)와 `view=recent`(출제 내역) 모두 이 항목을 현재 화면으로 표시하고, 두 화면 맨 위에 같은 2칸 전환이 있다.
- 메뉴 구성과 현재 화면 판정은 `archive2-navigation.js` 한 곳이다. 단원별 기출 페이지도 같은 파일·같은 CSS(`archive2-navigation.css`)를 로드한다.

## 단원×단계 표 (단원별 기출, 2026-11-10 사용자 결정)

- 학년 버튼(학년 색) → 과목 전환 → **행 = 단원, 열 = 1~5단계(+ 단계 미지정 문항이 있으면 미지정 열)** 표 한 장이다. 칸의 숫자는 그 단원·단계의 기출 문항 수이고, 단계는 숫자 그대로 쓴다(상·중·하로 바꾸지 않는다). 이유: 교사가 단원을 여러 개 골라 난이도별로 한꺼번에 주는 일이 많은데, 예전 3단계 진행은 단원 하나씩만 골랐고 단계별 개수도 고르기 전에는 보이지 않았다.
- **칸 상태는 세 가지**다.
  - 빈 칸: 문항이 있으면 흰 바탕 + `--control-line` 2px 알약, 문항이 0이면 흐린 글자 `0`이고 누를 수 없다.
  - 선택: 글자색(`--ink`)으로 채우고 흰 글자(OMR 칠하기). 칸마다 N문항을 정했을 때는 `뽑는 수/있는 수`(예 `10/103`)로 쓴다.
  - 모자람: 선택된 칸에서 문항이 N보다 적어 있는 만큼만 넣은 칸. `--brand` 주홍 테두리 + `8/8`처럼 숫자로도 알린다(색만으로 알리지 않는다). **막지 않는다.**
- 단원을 **체크**하고 위쪽 단계 버튼을 누르면 체크한 단원 전체에 그 단계를 켜고 끈다(체크가 없으면 보이는 모든 단원). 휴대폰에서는 표가 단원 카드로 접히고 단계 칸 5개가 한 줄이며, 그 위에 같은 단계 버튼 줄이 생긴다.
- 폭 1360px 이상에서는 표 오른쪽에 요약 패널(문항 수·권 수·단원별 합계·문항 수/정리 순서 설정·`문제지 보기`), 그보다 좁으면 아래 고정 띠(`177문항 · 4권` + `문제지 보기`)가 뜨고 설정은 표 위에 접어 둔다. 휴대폰의 띠는 아래 메뉴 바로 위에 붙는다.
- 위쪽 탭 `기출` | `유사문제` | `유사문제 먼저, 기출 다음`: 뒤의 둘은 **자리만** 있고 누를 수 없다(`aria-disabled`, 흐린 글자). 유사문제의 단계 작업이 끝나면 연다.
- 이 화면에는 Font Awesome 아이콘을 쓰지 않는다. 늘이기·줄이기 버튼의 +/−와 펼침 화살표는 CSS로 그린다.

## 금지

- 제목 위의 작은 영문 머리말(eyebrow).
- 왼쪽에만 색 띠를 두른 카드·알림.
- 딱딱한 오프셋 그림자(부드러운 팝업 그림자만 허용).
- 유니코드 문자 아이콘(✕ ▶ ⌕ ▾ → 등). 닫기는 글자 "닫기"나 그린 SVG, 펼침 표시는 CSS로 그린 화살표를 쓴다.
- 그라데이션 배경.

## 알려진 남은 것 (다음 단계)

- 학교별 기출·문제지 만들기·보관함의 **화면 안 구성**은 아직 옛 구성이다. 색·글꼴·버튼 모양만 이 디자인으로 통일했다. 단원별 기출은 위 "단원×단계 표"로 바뀌었다.
- 단원별 기출의 이전 화면(세분 출제, `ready=1` 없이 여는 쪽)에는 Font Awesome 아이콘(`fa-*`)이 남아 있다. 새 표 화면에는 없다.
