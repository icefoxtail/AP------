# JS 아카이브 디자인 (Archive 2.0)

> 이 문서는 `archive/`의 교사용 화면(`workspace.html`, `unit-past-exams.html?ready=1`)의 디자인 기준이다.
> `apmath/DESIGN.md`는 APMS(학원 관리) 화면용이라 별개다. 서로 색·글꼴을 맞추지 않는다.
> 값은 `archive/archive2-tokens.css` 한 곳에서 정의한다. 화면 CSS에 색 숫자를 직접 쓰지 않는다(그림자·반투명 막은 예외).

## 사용자 결정 (2026-11-10)

- 색이 칙칙하고 밋밋하며 화면마다 모양이 달랐다. **아카이브만의 새 디자인**(APMS와 공유하지 않음)으로 바꾼다.
- 시안 A(찾기 중심)와 B(단원 중심)를 **섞는다**. 홈 위쪽에 "학교 기출 찾기"와 "단원별로 난이도 골라 주기"를 나란히 둔다.
- **단원별 기출은 독립 메뉴**다. 난이도는 **1~5단계를 유지**한다(단계를 줄이지 않는다).
- 이유: 교사는 휴대폰·갤럭시 탭, 원장은 PC로 쓴다. 한 화면에서 "찾기"와 "단원 고르기"가 둘 다 보여야 교사가 메뉴를 헤매지 않는다.

| 바탕 | `#FFFFFF` |
| 글자 | `#17171C` (보조 `#5A5A63`, 흐린 글자 `#6B6B74`) |
| 선 | `#E6DAD5` (옅은 선 `#F0E8E5`) |

| 진한 주홍 글자 | `#A82A10` / 주홍 옅은 바탕 `#FFF1EB` (그 위 글자 `#7A1E0A`) |
| 중립 칩 바탕 | `#F6F1EF` / 선택된 줄 바탕 `#F1EEFF` |

학년 색은 **학년 버튼·학년 표시·시험 책등**에만 쓰고 글자는 흰색이다: 중1 `#2F7D32`, 중2 `#0B7A8F`, 중3 `#2A6FDB`, 고1 `#6B4FD8`, 고2 `#A8268F`, 고3 `#1F2937`.

- 글자 대비 4.5:1 이상. 주홍 바탕 위의 작은 링크는 흰 글자 + 밑줄이다(`#FFE4DB`는 대비가 모자라 쓰지 않는다).
- **밝은 화면 하나만 있다.** 다크 모드 규칙을 두지 않는다(`color-scheme: light`). 이유: 시안이 밝은 화면만 정의했고, 어두운 화면에서 학년 색·주홍의 대비를 따로 맞출 근거가 없다.

## 글꼴

- 제목·큰 숫자: `Black Han Sans` (weight 400만 있다. 굵게 만들지 않는다).
- 본문: `Noto Sans KR` 400/500/700.
- **`Black Han Sans`는 20px 이상 제목과 18px 이상 숫자에만 쓴다.** 단위·라벨·20px 미만 한글(예: "22" 뒤의 "문항", "1차", "열기")은 `Noto Sans KR` 700이다. 이유: 작은 글자에서 획이 뭉개진다.
- 학년을 고르는 **버튼**은 어디서나 학년 색 2px 테두리 + 반지름 10이고, 선택되면 학년 색으로 채우고 흰 글자다(select 상자는 그대로).
- Google Fonts `<link>`(`display=swap`)로 불러오고 시스템 한글 글꼴(맑은 고딕, Apple SD Gothic Neo)을 대체로 둔다. 글꼴 파일을 저장소에 넣지 않는다.

## 모양

- 주 버튼: 글자색 바탕 + 흰 글자 알약(반지름 22~28). 보조 버튼: 글자색 1.5px 테두리 + 흰 바탕 알약. 링크형: 주홍 글자.
- 학년 버튼 반지름 10. 카드 반지름 12 + 1px 선(그림자 없음). 강조 패널·대화상자 2px 글자색 테두리 + 반지름 16.
- 누를 수 있는 것은 모두 44px 이상(단, 컴포즈 데스크톱의 촘촘한 탭 `.mode-switch`·`.part-select`는 36px이고 태블릿·휴대폰에서 44px가 된다). 휴대폰 입력 글자 16px 이상. 포커스는 3px 외곽선.
- **이 디자인의 고유 표현 두 가지**
  - **학년 색 책등 + 큰 연도 숫자**: 시험 한 줄 왼쪽에 학년 색 블록을 두고 연도 2자리를 `Black Han Sans`로 크게 쓴다. (색 띠만 두른 카드가 아니라 책등이다.)
  - **시험 줄 = 책등 + 제목 + 버튼 + 유사문제 칸** (2026-11-10 사용자 요청: 기출을 찾으면 그 유사문제도 옆에 보인다). 한 줄에 시험 하나이고 학교별 기출과 홈 "최근 연 기출"이 같은 함수(`examRowMarkup`)로 그린다. 왼쪽 학년 색 책등(연도 2자리 + 학년), 제목(학교 + 시기; 연도·학년은 책등에 있다), 과목 · 문항 수 · 범위, 버튼 `시험지 해설 정답 반에 출제`, 맨 오른쪽 유사문제 칸. 유사문제 칸은 짝이 1개면 주홍 옅은 바탕(`--brand-soft`)에 `열기`·`출제`, 2개 이상이면 `보기`(대화상자), 없으면 흐린 글자 "유사문제 없음"(버튼 없음). 줄 폭이 920px 이상이면 칸이 오른쪽, 560~920px이면 줄 아래 띠, 그보다 좁으면(휴대폰) 책등+제목 / 버튼 한 줄 / 유사문제 띠 순서이고 "없음" 띠는 숨긴다. 폭 판단은 화면이 아니라 줄 목록(container query) 기준이다.
  - **보관함 줄 = 책등 + 제목 + 버튼 + 출제 이력** (2026-11-10 사용자 요청: 보관함에서 문제지를 보면 누구에게 언제 냈는지 바로 알고 다시 낼지 판단한다). 시험 줄과 같은 CSS 구성요소(`.exam-row`)를 쓰고 한 줄에 저장한 문제지 한 권이다. 책등에는 학년 색 위에 학년, **문항 수(큰 숫자)**, 작은 글자 "문항"을 쓴다(학교 기출의 연도와 헷갈리지 않게 연도는 쓰지 않는다). 제목 아래에 `과목 · 저장 날짜 · (묶음이면 "2권 중 1권")`, 버튼은 `시험지 해설 정답 반에 출제`이고 이름 바꾸기·수정본 만들기·보관·휴지통으로·상세 보기는 `더보기` 안에 둔다. 줄 맨 아래 같은 카드 안에 옅은 칩 바탕의 **출제 이력**이 붙는다: "출제 N회" 요약, 최근 3건을 `반 · 날짜 · 제출 n / m` + `학생별 확인`으로 한 줄씩, 그 앞의 것은 `이전 출제 N개 더 보기`로 접는다. 취소된 출제는 흐린 글자 + "취소됨", 이력이 없으면 흐린 글자 "최근 90일 안에 출제한 기록이 없습니다.", 불러오는 중이거나 실패한 상태는 **목록 위 한 줄**("출제 이력은 최근 90일까지 보입니다" 자리)에만 "출제 이력 확인 중…" / "출제 이력을 불러오지 못했습니다. `다시 시도`"로 말하고, 카드 안 이력 칸은 그동안 숨긴다(목록은 그대로 쓸 수 있다). 펼친 "이전 출제" 버튼은 `접기`가 된다. 목록을 먼저 그린 뒤 이력을 채우고, 화면에 "출제 이력은 최근 90일까지 보입니다"를 밝힌다. 출제 내역 화면(`view=recent`)의 줄도 같은 구성요소이고 책등에는 출제 날짜(월·일)와 대상 학년을 쓴다. 정보는 한 줄 `반 · 제출 n/m · n문항 · 과목`만 두고, 시험지 학년은 대상 학년과 **다를 때만** "시험지는 고2"로 쓰며, 출제 번호는 줄의 `title`과 학생별 확인 대화상자에만 둔다. PDF는 준비 중·실패일 때만 상태와 `PDF 다시 준비`를 보인다.
  - **선생님 로그인이 없을 때는 오류가 아니다**: 보관함·출제 내역은 API를 부르지 않고 안내 하나만 보인다("선생님 계정으로 로그인하면 … 볼 수 있습니다." + `선생님 로그인` 버튼, 그 아래 줄에 "로그인한 뒤 이 화면으로 돌아오면 됩니다."). 빨간 알림·토스트를 쓰지 않고, 로그인한 뒤 돌아오면 저절로 다시 그린다. 서버가 401/403을 줘도(만료) 같은 안내다. 5xx 같은 진짜 오류는 알림 하나 + `다시 시도`이고 토스트와 본문에 같은 문장이 겹치지 않게 한다. 화면에 "불러왔습니다" 같은 성공 문장은 띄우지 않는다.
  - **선택한 칸은 글자색으로 채운다**: OMR 답안을 칠하듯 선택된 칩·탭·전환 버튼은 `#17171C`로 채우고 흰 글자를 쓴다. 옅은 파란 바탕으로 표시하지 않는다.
  - **출제 패널** (`archive2-assign.js`·`archive2-assign.css`, 2026-11-10): 보관함 줄의 `반에 출제`를 누르면 화면 안에서 연다. 강조 패널·대화상자 모양(2px 글자색 테두리 + 반지름 16)을 그대로 쓰고, PC(960px 이상)는 오른쪽에서 나오는 폭 440px 패널(보관함 목록이 옆에 흐리게 보인다), 태블릿(600~959px)은 폭 480px 패널, 휴대폰(600px 미만)은 전체 화면 시트다. 위에 제목 + 문제지 이름·문항 수 + `닫기`, 가운데가 스크롤, 아래 **요약과 `출제하기` 검정 타원 하나**(52px)가 고정이다. 반은 학년으로 묶는다: 문제지와 같은 학년(학년 색 칩 + "반")은 펼쳐서 먼저, 다른 학년은 `다른 학년 반 n개`(CSS 화살표)로 접는다. 반 줄은 체크 + 반 이름(작은 글자로 담당 선생님) + 명단 수이고, 체크한 반 밑에 "전체 22명에게 출제" + `학생 고르기`(펼치면 빠른 선택 `전체` / `아직 안 본 학생만` 두 버튼 + 두 칸 체크 목록, 빼면 "19명에게 출제 (3명 제외)")가 붙는다. 이미 낸 반은 줄 밑에 경고 글자("11월 10일에 이미 냈습니다.")이고 기본은 체크 해제다. 출제일은 날짜 입력(기본 오늘). 요약 숫자는 20px 이상이라 `Black Han Sans`("41명 2개 반" 또는 "문제지 2권 × 2개 반 = 4건, 학생 41명"). **결과표**는 반(과 문제지)마다 한 칸이고 **글자로 상태를 말한다**: `출제됨`(초록 글자)·`출제됨 · PDF만 준비 실패`(`PDF 다시 준비`)·`실패`(이유)·`취소된 출제`("이 출제는 취소된 상태입니다." + `새로 출제`)·`결과 확인 필요`(옅은 노란 바탕, `확인하기`)·`보내지 않음`. 왼쪽 색 띠는 쓰지 않는다. 진행 중에는 닫기 버튼이 흐려지고 "출제 중에는 닫을 수 없습니다"가 아래에 나온다. 모든 터치 영역 44px 이상, 포커스는 3px 테두리, 새 색은 없다(토큰만).

## 문제지 만들기 한 화면 (2026-11-10 사용자 결정)

- **한 화면에서 왼쪽은 조건, 오른쪽은 결과와 마무리다.** 교사가 학년·단원·단계·문항 수를 고르고 `문제지 만들기`를 누르면 같은 화면 오른쪽에 결과가 나오고, 거기서 바로 출력·저장·반에 출제한다. 조건을 고치려고 화면을 오가지 않는다. 이유: 예전에는 조건 화면과 결과 화면이 따로 놀아서 문항을 뽑고 나면 조건이 접히고, 출력·저장·출제 버튼이 오른쪽 탭·위쪽 패널·휴대폰 하단에 흩어져 있었다.
- **왼쪽(조건)**: ① 학년 버튼(학년 색, 학교별 기출·단원별 기출과 같은 구성요소) ② 과목(고1 2과목은 2칸 전환, 고2·고3 여러 과목은 칩 + `전체 과목`, 중학교는 한 줄 글자) ③ 범위(단원 목록은 높이를 제한하고 안에서 스크롤, 연속 범위는 접힘) ④ 난이도 단계 `전체 1 2 3 4 5`(기본 전체) ⑤ 문항 수 `− 숫자 +`(배분 방식에 따라 "단원마다"·"전체"·"조건에 맞는 문항 전부"라고 옆에 쓴다) ⑥ `더 자세한 조건`(접힘: 배분 방식, 학교·연도·시험 시기, 교육과정, 개념·유형·풀이, 승인된 분류만, 범위별 계획표, 작업 백업·불러오기) ⑦ **"N문항 가능 · 요청 M문항"** 요약과 검은 타원 `문제지 만들기`(이 화면의 주 버튼 하나).
- **조건을 바꿔도 자동으로 다시 뽑지 않는다.** 교사가 고정·교체한 문항이 사라지기 때문이다. 이미 뽑은 결과가 있을 때 조건을 바꾸면 결과는 비우고(예전 동작) 오른쪽에 "조건이 바뀌었습니다. 문제지 만들기를 누르면 새로 뽑습니다"를 보인다. 결과가 있는 동안 왼쪽 버튼은 보조 버튼 `같은 조건으로 다시 뽑기`다.
- **모자라도 막지 않는다**(단원별 기출과 같은 원칙). 버튼은 눌리고, 있는 만큼만 뽑고, 결과 위에 어디가 얼마나 모자랐는지 알린다(주홍 옅은 바탕). 조건에 맞는 문항이 **0개**일 때만 버튼을 막고 "고른 조건에 맞는 문항이 없습니다"라고 말한다.
- **오른쪽(결과)**: 요약(문항 수·권 수·단원/단계 구성) → 권 고르기(여러 권일 때만) → 문항별 고정·교체 목록 → 미리보기(접을 수 있음, 접으면 그리지 않는다) → `출력 설정`(접힘) → 마무리 버튼 `출력` `보관함에 저장` **`저장하고 반에 출제`**(검정, 하나뿐인 주 버튼; PC에서는 화면 아래에 붙어 따라온다). 저장한 뒤의 "마지막 저장본"(권별 출제·출력)은 결과 맨 위에 있고 그 안의 `이 저장본 출제`는 보조 버튼으로 보인다. 결과 전에는 안내문과 이전 작업·학교별 기출에서 넘어온 범위 안내를 보인다.
- **휴대폰·태블릿(1100px 미만)**: 조건이 위, 결과가 아래 한 줄. 아래 메뉴 바로 위에 검은 고정 띠(`.cz-bar`, 단원별 기출의 `.ug-bar`와 같은 구성): 결과 전 "N문항 가능" + `문제지 만들기`, 결과 후 "20문항 · 1권" + `출력` + `더보기`(보관함에 저장 · 저장하고 반에 출제 · 작업 백업). 이때 본문의 주 버튼은 숨겨서 주 버튼이 둘로 보이지 않는다.
- **빠른 평가(`?view=compose&recipe=`)**는 같은 화면을 쓰되 문항 수·배분을 잠그고 저장·백업·새 작업·저장하고 출제를 없앤다(`applyFiveMinuteViewGuard`). 마크업을 바꿀 때는 `tests/archive2-compose-one-screen.test.js`의 가드 선택자 검사를 같이 고친다.

## 메뉴

- PC·가로 태블릿(폭 961px 이상): 왼쪽 메뉴, 폭 232px, 주홍 바탕. 맨 위 "JS 아카이브". 글자만 있는 44px 알약 6개, 현재 화면은 흰 바탕 + 진한 주홍 글자 + `aria-current="page"`.
  `홈 / 학교별 기출 / 단원별 기출 / 문제지 만들기 / 빠른 평가 / 보관함 · 출제 내역`
  맨 아래: 로그인 상태(로그인 전이면 "선생님 로그인", 선생님이 아닌 계정이면 "선생님 계정으로 로그인해 주세요", 선생님 계정이면 이름·"로그인됨". 판정은 `archive2-session.js` 한 곳이고 단원별 기출 페이지도 같은 규칙을 쓴다), 작은 링크 "아카이브 1.0", "자료 점검", "유형·개념으로 문항 찾기".
- 휴대폰(폭 960px 이하): 위 머리줄 56px(홈은 "JS 아카이브" + 로그인, 다른 화면은 화면 이름) + 아래 고정 메뉴 5칸(글자만, 60px, 현재 칸은 글자색 바탕 흰 글자): `홈 / 학교별 / 단원별 / 만들기 / 보관함`.
  빠른 평가는 홈 화면과 "문제지 만들기" 화면 위쪽의 링크로 간다. 그 밖의 도구 링크는 홈 맨 아래에 있다.
- "보관함 · 출제 내역"은 메뉴 하나다. `view=saved`(보관함)와 `view=recent`(출제 내역) 모두 이 항목을 현재 화면으로 표시하고, 두 화면 맨 위에 같은 2칸 전환(`보관함 | 출제 내역`)이 있다. 보관함 안의 `내 보관함 / 보관 / 휴지통`은 전환이 아니라 상태 필터이고 `status` 주소 값으로 따로 남는다(그래서 3칸으로 늘리지 않았다).
- 메뉴 구성과 현재 화면 판정은 `archive2-navigation.js` 한 곳이다. 단원별 기출 페이지도 같은 파일·같은 CSS(`archive2-navigation.css`)를 로드한다.

## 단원×단계 표 (단원별 기출, 2026-11-10 사용자 결정)

- 학년 버튼(학년 색) → 과목 전환 → **행 = 단원, 열 = 1~5단계(+ 단계 미지정 문항이 있으면 미지정 열)** 표 한 장이다. 칸의 숫자는 그 단원·단계의 기출 문항 수이고, 단계는 숫자 그대로 쓴다(상·중·하로 바꾸지 않는다). 이유: 교사가 단원을 여러 개 골라 난이도별로 한꺼번에 주는 일이 많은데, 예전 3단계 진행은 단원 하나씩만 골랐고 단계별 개수도 고르기 전에는 보이지 않았다.
- **칸 상태는 세 가지**다.
  - 빈 칸: 문항이 있으면 흰 바탕 + `--control-line` 2px 알약, 문항이 0이면 흐린 글자 `0`이고 누를 수 없다.
  - 선택: 글자색(`--ink`)으로 채우고 흰 글자(OMR 칠하기). 칸마다 N문항을 정했을 때는 `뽑는 수/있는 수`(예 `10/103`)로 쓴다.
  - 모자람: 선택된 칸에서 문항이 N보다 적어 있는 만큼만 넣은 칸. `--brand` 주홍 테두리 + `8/8`처럼 숫자로도 알린다(색만으로 알리지 않는다). **막지 않는다.**
- 단원을 **체크**하고 위쪽 단계 버튼을 누르면 체크한 단원 전체에 그 단계를 켜고 끈다(체크가 없으면 보이는 모든 단원). 휴대폰에서는 표가 단원 카드로 접히고 단계 칸 5개가 한 줄이며, 그 위에 같은 단계 버튼 줄이 생긴다.
- 폭 1360px 이상에서는 표 오른쪽에 요약 패널(문항 수·권 수·단원별 합계·문항 수/정리 순서 설정·`문제지 보기`), 그보다 좁으면 아래 고정 띠(`177문항 · 4권` + `문제지 보기`)가 뜨고 설정은 표 위에 접어 둔다. 휴대폰의 띠는 아래 메뉴 바로 위에 붙는다.
- 위쪽 탭 `기출` | `유사문제` | `유사문제 먼저, 기출 다음`: 뒤의 둘은 **자리만** 있고 누를 수 없다(`aria-disabled`, 흐린 글자). 유사문제의 단계 작업이 끝나면 연다.
- 이 화면에는 Font Awesome 아이콘을 쓰지 않는다. 늘이기·줄이기 버튼의 +/−와 펼침 화살표는 CSS로 그린다.

## 금지

## 알려진 남은 것 (다음 단계)

- 학교 기출·유사문제 줄의 출제와 단원별 기출의 출제는 아직 기존 출제 대화상자(옛 iframe)를 연다. 문제지 만들기는 위 "문제지 만들기 한 화면"으로 바뀌었다(보관함·출제 내역은 보관함 줄 구성, 학교별 기출은 시험 줄 구성, 단원별 기출은 "단원×단계 표", 보관함·문제지 만들기의 출제는 "출제 패널").
- 단원별 기출의 이전 화면(세분 출제, `ready=1` 없이 여는 쪽)에는 Font Awesome 아이콘(`fa-*`)이 남아 있다. 새 표 화면에는 없다.
