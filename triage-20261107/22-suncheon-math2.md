# 22 순천고 고2 2학기 기말 수학II 판정

원문·정답·해설과 Q03·Q21 원본 그림을 직접 읽었다. 함수 관계가 이해에 조금이라도 도움이 되면 그림을 계획하라는 사용자 지시에 따른다. 기존 Q11·16·22 해설 SVG는 실제 그림 확인 환경이 없어 보존·미판정. 열린 PR #1225의 자산 복사와 PR #1405 메타 이력 보존. 시도·현재 소유 UNKNOWN, 신규 입력 NOT_RENDERED다.
