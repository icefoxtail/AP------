## 사용자 지시와 검수 기준
사용자 지시: “유리함수, 무리함수, 함수는 그래프 필요한 경우는 백프로 만들어야해. 학생 도움이 조금이라도 된다면.” 따라서 함수·유리함수·무리함수에서 그래프가 학생 이해에 조금이라도 도움이 되면 판정표에 제작 계획과 이유를 적습니다. 기존 그림이 있다는 이유만으로 제외하지 않습니다. 이 기준은 사용자의 명시 지시이므로 검토 시 반영해야 합니다.

수학적 정확성과 검증 기준은 그대로 유지합니다. 구체적인 수학 오류, 계약 위반 또는 품질 결함은 여전히 반려 사유이며, 그래프의 교육적 역할과 정답 노출 여부도 문항별로 확인합니다.
