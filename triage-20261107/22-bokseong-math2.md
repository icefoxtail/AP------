# 22 복성고 고2 2학기 기말 수학II 판정

원문·정답·해설과 Q13·14·15 원본 그림을 직접 읽었다. 학생 이해에 조금이라도 도움이 되는 함수 관계는 그림을 계획하라는 사용자 지시에 따른다. 기존 소유·시도 수 UNKNOWN을 유지하고 원본과 승인 이력을 보존한다. 새 입력은 NOT_RENDERED다.

| 문항 | 판정 | 이유 / 학생에게 보여 줄 관계 |
|---|---|---|
| Q01 | OPEN | 접점과 접선의 기울기 관계 계획 필요. |
| Q02 | OPEN | 극대·극소와 수직 이동 관계 계획 필요. |
| Q03 | OPEN | 위치·속도·가속도의 변화 관계 계획 필요. |
| Q04 | EXEMPT | 부정적분식의 직접 미분 계산. |
| Q05 | EXEMPT | 원시함수의 두 끝값 차 계산. |
| Q06 | OPEN | 두 교점 사이 영역을 계획했으나 자동 프레임에서 영역이 지나치게 작아 가독성 보완 필요. |
| Q07 | FIGURE | 속도 그래프의 양·음 영역을 부호 있게 합해 순변위를 구하는 관계. |
| Q08 | OPEN | 사차곡선의 두 접선과 삼각형 관계 계획 필요. |
| Q09 | OPEN | 같은 끝점 높이와 내부 수평 접선 관계 계획 필요. |
| Q10 | FIGURE | 증가 조건 경계에서 도함수가 한 점에서만 0이 되는 예시. |
| Q11 | OPEN | 절댓값과 수평선 교점 수 변화 계획 필요. |
| Q12 | OPEN | 도함수 적분과 주어진 점의 관계 계획 필요. |
| Q13 | OPEN | 원본 도함수 모양과 이동 적분구간의 최솟값 관계 계획 필요. |
| Q14 | OPEN | 원본 세 곡선 및 이등분 영역을 보존해 표현할 방법 필요. |
| Q15 | OPEN | 원본 사차곡선의 두 영역 상쇄 관계 계획 필요. |
| Q16 | OPEN | 원함수 극값과 도함수의 부호 변화 관계 계획 필요. |
| Q17 | OPEN | 매개변수에 따른 구간 최솟값 조건 계획 필요. |
| Q18 | CONTENT/OPEN | 원문에 직사각형 변이 좌표축에 평행하다는 조건이 없어 대각선만으로 넓이를 정할 수 없고 정답 필드도 비어 있음. 해설에도 같은 한계가 기재되어 있어 원문은 수정하지 않는다. |
| Q19 | OPEN | 짝함수 사차곡선과 수평선 교점 수 관계 계획 필요. |
| Q20 | OPEN | 할선 양 끝 간격과 중점 자취 관계 계획 필요. |
| Q21 | OPEN | 원기둥 겉넓이 제약과 부피 최댓값 관계 계획 필요. |
| Q22 | OPEN | 정적분 자기 일치 조건과 이차함수 관계 계획 필요. |

입력 작성: Q07·10. OPEN은 미완료 또는 엔진 표현·원문 확인이 필요한 문항이다.
