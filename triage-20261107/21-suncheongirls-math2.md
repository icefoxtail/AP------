# 21 순천여고 고2 2학기 기말 수학II 판정

원문·정답·해설 및 Q09·10·13·15·17·19·23 원본 그림을 직접 읽었다. 함수 관계가 이해에 조금이라도 도움이 되면 그림을 계획하라는 사용자 지시에 따른다. Q09·15 원본은 필기 겹침 HOLD 이력을 보존한다. 누적 시도·현재 소유 UNKNOWN, 신규 입력 NOT_RENDERED다.

| 문항 | 판정 | 이유 / 학생에게 보여 줄 관계 |
|---|---|---|
| Q01 | OPEN | 삼차함수 극값과 세 교점의 수평선 범위 계획 필요. |
| Q02 | EXEMPT | 미분계수의 정의와 입력 배수 계산. |
| Q03 | EXEMPT | 분수식 약분·부정적분·대입 계산. |
| Q04 | OPEN | 대칭구간에서 홀함수 적분이 상쇄되는 관계 계획 필요. |
| Q05 | OPEN | 사차함수 전역 최댓값과 부등식 관계 계획 필요. |
| Q06 | OPEN | 접선 기울기와 함수값 조건 관계 계획 필요. |
| Q07 | EXEMPT | 반복 미분·적분과 등차합 계산. |
| Q08 | FIGURE | 속도 부호 변화와 두 구간의 이동거리 합 관계. |
| Q09 | CONTENT/OPEN | 원본 그림의 필기 겹침 HOLD 보존. 발문은 보행자를 진우와 민기로 다르게 불러 이름 일치 여부 확인 필요. |
| Q10 | OPEN | 원본 위치 그래프 보존, 영점과 기울기 부호 변화 관계 계획 필요. |
| Q11 | OPEN | 속도 곡선과 수평선의 양의 교점 개수 관계 계획 필요. |
| Q12 | EXEMPT | 다섯 번 미분과 대입 계산. |
| Q13 | OPEN | 원본 구간별 도함수 그림 보존, 구간 적분과 함수값 변화 관계 계획 필요. |
| Q14 | OPEN | 평행이동·대칭과 주기 적분 관계 계획 필요. |
| Q15 | OPEN | 원본 그림의 필기 겹침 HOLD 보존, 곡선 차와 적분 부호 관계 계획 필요. |
| Q16 | FIGURE | 연속성과 함수값 범위에서 이어지는 네 조각과 대칭 면적. |
| Q17 | OPEN | 원본 삼차함수 그림 보존, 적분함수 접선 기울기 관계 계획 필요. |
| Q18 | OPEN | 삼차함수 극값과 수평선 세 교점 관계 계획 필요. |
| Q19 | OPEN | 원본 정사각형 및 두 곡선 보존, 세 영역의 등차 관계 계획 필요. |
| Q20 | OPEN | 절댓값 함수의 접선 기울기와 교점 조건 관계 계획 필요. |
| Q21 | EXEMPT | 반복 미분 및 경계값 대입으로 상수를 구하는 계산. |
| Q22 | OPEN | 사차 짝함수의 대칭과 극점 관계 계획 필요. |
| Q23 | OPEN | 원본 증감표 보존, 극값과 절댓값 적분 관계 계획 필요. |

입력 작성: Q08·16. OPEN은 미완료 또는 기존 이력·엔진 표현·원문 확인이 필요한 문항이다.
