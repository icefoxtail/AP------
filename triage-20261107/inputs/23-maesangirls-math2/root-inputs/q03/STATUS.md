23 매산여고 고2 수학II Q03. ROOT 승인 수학 계획에 따른 로컬 제작 입력 초안.

원문 근거 인용(정확): 그래프에서 $0\lt x\lt4$와 $4\lt x\le5$에서 $f'(x)\gt0$이고 $f'(4)=0$이지만 부호는 바뀌지 않으므로 $f$는 $[0,5]$에서 증가한다.

표현 한계: 원본 f′ 그래프 자체를 복원하지 않으며 미지의 함수식과 높이는 표시하지 않는다. 알려진 열린구간 부호만 표현한다.

검증 상태: JSON 문법 및 작성한 수직선 입력의 제한 개수·필수 형태를 로컬 정적 점검했다. 실제 production validator/engine 실행, 렌더링, 브라우저·시각 검사, 독립 전체 수학 검증, 원격 보존, 구현 인계는 실행하지 않았다. READY 또는 시각/production PASS가 아니다. 원본·엔진·원격 상태는 변경하지 않았다.
현재 초안 보완: 부호 행에는 (-5,-4), (0,4), (4,5]의 양수와 (-4,0)의 음수를 표시한다. 알려진 x=5도 양수 구간에 포함하고, x=4의 f′(4)=0은 부호 유지로 표시한다. 원본 f′의 미지 높이·함수식은 재구성하지 않았다.
