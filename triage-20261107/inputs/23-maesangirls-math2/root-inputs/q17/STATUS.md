23 매산여고 고2 수학II Q17. ROOT 승인 수학 계획에 따른 로컬 제작 입력 초안.

원문 근거 인용(정확): 따라서 출발 후 서로 다른 두 시각에서 만나려면 $-8\lt k\lt 0$이어야 한다.

표현 한계: 정수 k의 허용 범위만 보이는 보조 수직선이다. h(t) 곡선의 t>0 반직선 요구를 나타내지 않는다.

검증 상태: JSON 문법 및 작성한 수직선 입력의 제한 개수·필수 형태를 로컬 정적 점검했다. 실제 production validator/engine 실행, 렌더링, 브라우저·시각 검사, 독립 전체 수학 검증, 원격 보존, 구현 인계는 실행하지 않았다. READY 또는 시각/production PASS가 아니다. 원본·엔진·원격 상태는 변경하지 않았다.
현재 초안 보완: 최종 수직선 입력은 h(0)=0, h(2)=-8, t>0에서 (0,2) 감소 및 (2,∞) 증가, -8<k<0과 가능한 정수 -7..-1을 나타낸다. k=-4는 예시다. 원래 h(t) 반직선 곡선은 표현하지 않는다.

입력 단계 재검사 결과 (2026-11-08; 전체 작업 최종 판정 아님):
실제 `expandNumberLineFigure` 입력 검사: PASS.
