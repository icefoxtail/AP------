# 22 풍덕중 2학기 기말 중3: 원문 판정 초안
기준: 원문 JS와 19개 연결 PNG, 기존 해설 SVG 6개 직접 확인. 기존 SVG는 구형이며 보존. 필요한 문항에만 새 엔진 그림을 계획한다. 입력 3종 작성과 입력 계약 검사 완료. 렌더·인계 미실시.

| 문항 | 판정과 표현 계획 |
|---|---|
|1|계획: 같은 호의 중심각 x와 원주각 26°를 색으로 연결, x=52°.|
|2|계획: 25°·50° 원주각이 보는 호 두 개와 2cm:x를 색으로 연결, x=4.|
|3|계획: 내접사각형의 마주보는 각 120°/60°, 90°/90°를 표시.|
|4|그림 불필요: 원의 성질을 고르는 독립 문장.|
|5|계획: 접점 A의 접선과 현 AB가 만드는 각과 반대편 원주각 56°를 연결.|
|6|계획: 교차현 AC·BD와 호 BC 120°, AD 100°를 강조하여 x=110°. 기존 SVG 보존.|
|7|계획: 지름 AB로 직각을 나타내고 호 AC:CB=5:4와 15:x=5:4 표시.|
|8|계획: 세 호 AB:BC:CA=3:4:5와 호 BC 120°, 원주각 60°를 표시.|
|9|계획: 두 원의 공통현과 내접사각형을 구별, 83°·80°로 x=97°, y=100°를 단계 표시. 기존 SVG 보존.|
|10|계획: 반원과 같은 호 AD·DC, 각 26°, 교차현과 호 CB 76°를 표시해 x=64°. 기존 SVG 보존.|
|11|계획: 두 접선 30°, 작은 호 AB 150°, 큰 호 ACB 210° 및 호 AC 70° 표시해 x=35°. 기존 SVG 보존.|
|12|그림 불필요: 일곱 개 자료의 최빈값 3을 직접 세면 된다.|
|13|그림 불필요: 통계 개념 설명의 참거짓 판정.|
|14|그림 불필요: 원문 막대그래프에 수치가 이미 명확하고 15개 자료의 평균·중앙값을 계산한다. 원문 그래프 보존.|
|15|그림 불필요: 두 자료의 중앙값 조건을 정렬해 8≤a≤12 도출. 원문 조건 상자 보존.|
|16|그림 불필요: 평균·표준편차 원문 표 대조로 판정.|
|17|그림 불필요: 4회 및 5회 총점의 차로 98점 계산.|
|18|그림 불필요: 모든 자료의 평행이동에서 편차와 분산 불변.|
|19|계획: 원에 내접한 육각형과 호를 표시해 세 원주각이 각 호를 두 번씩 포함함을 표현, 합 360°.|
|20|계획: 지름 CB, 접선 PAT와 AP=AC, 직각 및 θ/2를 표시해 θ=60°. 기존 SVG 보존.|
|21|계획: 교차현 AC·BD, 호 BC=72°와 호 AD=108°, 각 관계를 시각화해 54°. 기존 SVG 보존.|
|22|원문 그래프가 세 분포를 직접 제시하므로 별도 새 그림 불필요. 분산 A=11/7, B=4/7, C=19/7 계산.|
|23|그림 불필요: 편차 다섯 개의 합 0으로 x=3, 표준편차 √6.|
|24|그림 불필요: 같은 평균에서 편차 제곱 합 비교로 분산 23/2.|
|25|계획: 원문 20점 산점도와 기준선 y=x를 함께 표시해 아래쪽 아홉 점과 45%, 양의 상관관계를 보여준다. 입력 좌표는 실제 원본 점을 확대 대조 후 확정.|

대상 14문항: 01–03, 05–11, 19–21, 25. 3종 작성 및 실제 입력 계약 검사를 완료했다. Q09 도형 배치는 기존 그림의 근삿값을 사용하며 83°, 80° 등 각도 오차는 약 0.001° 이내다. Q25 원문 20점과 x>y 9점을 확인했다. 렌더 검수는 실시하지 않았다. 기존 소유권 및 거절 사항을 다시 확인하고 파일 중복 변경을 피한다.


검증: 원 구성 13문항 construction.validate/execute와 입력 컴파일·도형 재고 검사 PASS, Q25 현행 통계 차트 solveStatChart PASS(20점), 42개 JSON 문항·caption 결속 일치. 렌더/최종검수/인계/원격 저장 NOT_RUN. Q09 배치는 원본 도형을 따른 근사 모델이다.
