# 19 연향중 2학기 기말 중3: 문항 판정과 입력 계획

- 기준 main 원문 JS blob: 01f91abec634beca65f2a5deed19fa0b3dbdab4b. 23문항의 발문·보기·정답·해설, 연결 PNG 22개를 확인했다. 기존 그림과 자산은 변경하지 않는다.
- 실제 파일의 s01·s02·s03 PNG는 해설 그림이 아니라 문제 그림이다. 이 입력은 현행 원문 및 정답을 바탕으로 새 엔진 해설을 계획한다.
- Q01: 직각삼각형의 빗변과 각 A·C의 삼각비 표시.
- Q02: AB·AC를 이용해 BC를 구하고 수선 DE에서 x와 B의 여각 관계 표시. D의 위치는 임의 예시이며 조건으로 추가하지 않는다.
- Q03: 실제 직육면체 5×3×4와 밑면·공간 대각선, 직각삼각형 AEG 표시. 입체 엔진 계약 실행 확인.
- Q04: EXEMPT. 제공된 특수각 삼각비를 대입해 보기의 참·거짓을 판정하는 문제로 별도 그림의 실익이 없다.
- Q05: 반지름 1과 여각 a,b의 삼각비 관계. 위치는 a=30°인 예시 구성이나 a의 실제 값으로 제시하지 않는다. 원문의 사분원을 단위원으로 확장한 보조 해설이다.
- Q06: 원문의 나무와 수평거리 20m, 각 33°. 문제의 cos33°=0.8, tan33°=0.6은 지시된 근삿값이므로 계산에는 이를 사용하고 좌표의 정밀 실측과 혼동하지 않는다.
- Q07: 두 대각선과 45°를 이용한 사각형 넓이. 예시 배치의 분할 비율은 주어진 조건이 아니다.
- Q08: 이등변삼각형의 높이, 내접원, 넓이와 반둘레로 반지름 표시.
- Q09: 같은 길이의 현과 중심에서 내린 수선을 나타내고 삼각형 OCD 넓이를 구한다. N은 원문에 없는 보조 수선의 발이다.
- Q10: 중심에서 같은 거리에 있는 현의 길이와 이등변삼각형의 각 표시.
- Q11: 내접원의 접점에서 같은 외부점의 두 접선 길이 표시.
- Q12: 직사각형 안의 원과 사선 접점 P, 위아래 접점 T,L을 표시해 접선 길이와 피타고라스 관계 설명.
- Q13: 세 접선의 길이와 두 세로 접선 사이의 직각삼각형 표시.
- Q14: 같은 호 AB를 보는 원주각 55°와 중심각 110° 표시.
- Q15: 세 같은 호와 두 할선의 바깥각, 원주각 x 표시.
- Q16: 두 보조 패널로 보기 ②의 같은 지름을 보는 두 직각과 보기 ⑤의 같은 현을 보는 각을 표시. 원문 보기 전체와 다른 보기 판정은 보존한다.
- Q17: 교차하는 현의 각, 호 AC와 호 BD의 관계 표시. 도형 반지름은 정규화 좌표이며 5cm라는 조건으로 표시하지 않는다.
- Q18: 접선과 현이 이루는 각 및 내접사각형의 대각 관계 표시.
- Q19: HOLD_SOURCE. 현행 해설에 중3 교육과정 밖 코사인 법칙이 있다. 닮음과 피타고라스만 사용해 동일한 ②를 구하는 격리 수정안은 검산됐으나 현행 main 미반영이다. 해설의 원문 결속을 확인한 뒤 별도 입력을 작성한다.
- Q20: 접선과 할선, 삼각형 APB의 넓이를 표시.
- Q21: 삼각형의 높이 AH와 연못 구간 AB, 45°·30° 각 표시.
- Q22: 물 표면의 현 BC, 보조 중심 O와 반지름으로 지름 표시.
- Q23: 반원 문제를 원 전체로 확장한 보조 그림에서 상반원 호와 두 할선을 강조한다. 원문 PNG를 변경하지 않는다.

## 현재 단계
Q01·02·03·05·06·07·08·09·10·11·12·13·14·15·16·17·18·20·21·22·23의 21세트는 ROOT 작성 로컬 입력 초안이다. 평면 구성 19세트는 구성 실행·입력 컴파일과 표시 각도 수치 확인, 입체 Q03은 입체 계약 실행, Q16은 두 패널 구성·컴파일과 합성 계약을 각각 확인했다. 렌더·독립 최종검수·원격 보존·구현자 인계는 아직 하지 않았다. Q04는 EXEMPT이고 Q19는 HOLD_SOURCE이므로 시험지 전체 완료가 아니다.
