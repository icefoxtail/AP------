추가 Q13·16·18: 원문 Q13 정십각형과 Q16 직사각형 식탁 PNG를 직접 열어 확인했다. Q13은 외접원 지름과 직각 원주각의 관계가 풀이에 필요하므로 원문을 보존하면서 대표 삼각형을 보조적으로 표시하는 3종을 작성했다. 실제 construction DAG, 직각 내적 0 및 색상 검사 PASS; 전체 표시 계약은 NOT_RUN. Q16은 원문 식탁 그림과 180도 회전 2중복 설명만으로 충분하여 추가 SVG를 만들지 않는다. Q18은 기존 텍스트 기반 q18_solution.svg를 원격 바이트 확인 후 직접 열어 본 결과 신엔진 provenance 표시가 없어 기존 SVG를 보존하고 조건부확률 나무 3종을 별도로 작성했다. Q18 입력 함수 PASS. 모두 외부 소유 확인 전 인계하지 않는다.

후속 시험지 전수 판정: Q01~20의 원문·정답·해설을 직접 읽었다. Q05·06·09·19의 main 게시 신엔진 SVG 실물을 Git blob 확인 후 직접 열어 확인하고 보존했다. Q13·16 원문 PNG 및 Q18 기존 도식도 직접 확인했다.
