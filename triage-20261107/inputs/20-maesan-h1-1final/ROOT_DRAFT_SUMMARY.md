# 20 매산고 고1 1학기 기말 로컬 입력 결과

OPEN Q03-Q20의 현재 item/plan/publish 54 JSON을 각 동결 매니페스트와 실제 입력 검사 결과에 결속했다. Q01·02는 이번 ROOT 원문 판정에 따른 EXEMPT이며 신규 입력을 만들지 않았다. 18개 STATUS 기록을 바이트 보존 방식으로 덧붙여 최종 패키지 72파일을 구성한다.

범위 제한: Q12의 a=2는 가능한 예시이며 a=-2도 가능하다. Q14는 포물선 없는 부분 구성, Q18은 u=k² 표현, Q20은 매개변수만 표시한다.

실제 적용 가능한 입력 단계만 보고한다. 전체 수학·교육·시각 검수와 render/prepare/build/CI/publication/handoff는 NOT_RUN. 기존 SVG/PNG와 950개 보호 로컬 파일, 실패 보고서 및 수정 전 이력을 보존했다. 원격 쓰기 없음, owner UNKNOWN, LOCAL_ONLY / DRAFT_ONLY / NOT_READY.
