# 22 금당고 고2 2학기 기말 수학II 판정

원문·정답·해설과 Q11·Q16 원본 그림을 직접 읽었다. 함수 관계가 이해에 조금이라도 도움이 되면 그림을 계획하라는 사용자 지시에 따른다. 기존 해설 SVG(Q08·14·17·20)는 보존하며 실제 그림 확인 환경이 없어 개선 여부 미판정. PR #601 출고와 열린 PR #1225 자산 작업 이력을 보존한다. 시도 횟수·현재 소유 UNKNOWN, 모든 신규 입력 NOT_RENDERED.

|---|---|---|
| Q01 | OPEN | 평균값 정리의 할선과 평행 접선 관계를 나타낼 계획 필요. |
