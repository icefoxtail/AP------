# 20 매산여고 고2 2학기 기말 수학II 판정

원문·정답·해설과 Q08·Q10 원본 그림을 직접 읽었다. 함수 관계가 이해에 조금이라도 도움이 되면 그림을 계획하라는 사용자 지시에 따른다. Q08 원본은 보기 그림까지 포함하므로 보존한다. 기존 출고·검수 및 PR #1405 메타 이력 보존. 시도·현재 소유 UNKNOWN, 신규 입력 NOT_RENDERED다.
